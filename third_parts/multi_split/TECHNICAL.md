## 1. 识别系统概览

工具通过**两级识别**确定规格字符串属于哪种钢材类型：
1. **第一级** — 前缀匹配判定类型
2. **第二级** — 正则表达式提取数值参数

### 1.1 前缀映射表

识别函数 `_detect_profile_type()` 按以下优先级依次检查前缀（大小写不敏感）：

| 优先级 | 前缀集合 | 判定类型 | 材质含义 |
|:------:|---------|:--------:|---------|
| 1 | `BH`, `HA` | **`BH`** | 焊接H型钢 (Built-up H-beam) |
| 2 | `I`, `HI` | **`I`** | 工字钢 (I-beam) |
| 3 | `BT` | **`BT`** | 焊接T型钢 (Built-up T-section) |
| 4 | `PL`, `-` | **`PL`** | 钢板 (Steel Plate) |

关键实现逻辑：

```python
def _detect_profile_type(spec: str) -> str | None:
    if pd.isna(spec):
        return None
    s = str(spec).strip().upper()    # 统一转大写，去除首尾空格

    for pfx in {"BH", "HA"}:
        if s.startswith(pfx):
            return "BH"

    for pfx in {"I", "HI"}:
        if s.startswith(pfx):
            return "I"

    for pfx in {"BT"}:
        if s.startswith(pfx):
            return "BT"

    for pfx in {"PL", "-"}:
        if s.startswith(pfx):
            return "PL"

    return None  # 无法识别 → 不拆分，原样保留
```

**优先级含义**：`BH300*200*6*8` 只被识别为 H 型钢，不会被误判为其他类型。

### 1.2 正则表达式数值提取

#### 四参数规格 (H型钢 / 工字钢 / T型钢)

```
正则: ^([A-Za-z]*)\s*([\d.]+)\s*\*\s*([\d.]+)\s*\*\s*([\d.]+)\s*\*\s*([\d.]+)

分组:  group(1)      group(2)   group(3)   group(4)      group(5)
含义:  前缀字母       H (高度)   B (宽度)   tw (腹板厚度)  tf (翼缘厚度)
```

**容错设计**：
- `\s*` — 允许前缀和数字间、数字和 `*` 间有任意空白：`BH 300 * 200 * 6 * 8` 也能正确匹配
- `[\d.]+` — 同时匹配整数和小数：`6.5`、`10` 均可
- `^` — 锚定开头，防止 `XXBH300*...` 等脏数据误匹配

**匹配示例**：

| 输入字符串 | 提取结果 |
|-----------|---------|
| `BH300*200*6*8` | `[300, 200, 6, 8]` |
| `HA250*150*5*6` | `[250, 150, 5, 6]` |
| `I400*200*8*10` | `[400, 200, 8, 10]` |
| `BT200*150*6*8` | `[200, 150, 6, 8]` |
| `i250*125*5*7` | `[250, 125, 5, 7]` (小写i也能匹配) |

#### 两参数规格 (板材)

```
正则: ^([A-Za-z]*|-)\s*([\d.]+)\s*\*\s*([\d.]+)

分组:  group(1)       group(2)       group(3)
含义:  前缀(PL/-/空)  厚度或宽度之一  厚度或宽度之二
```

**额外回退** — 匹配无前缀的裸数字格式 `10*2000`：
```python
# 如果前缀正则不匹配，尝试裸数字格式
m2 = re.match(r"^([\d.]+)\s*\*\s*([\d.]+)", s)
```

| 输入字符串 | 提取结果 | 说明 |
|-----------|---------|------|
| `PL10*2000` | `[10, 2000]` | 标准板材 |
| `-15*3000` | `[15, 3000]` | 短横线前缀 |
| `PL2000*10` | `[10, 2000]` | 自动排序(小值在前) |
| `6*284` | `[6, 284]` | 无前缀裸数字 |
| `pl5*1500` | `[5, 1500]` | 小写也能识别 |

## 2. 各类型处理算法

### 2.1 H 型钢 (BH/HA) — 四参数拆分

焊接 H 型钢由 **一块腹板 + 两块翼缘** 组成。

**输入规格**：`BH{H}*{B}*{tw}*{tf}` 或 `HA{H}*{B}*{tw}*{tf}`

```
                      ┌─────────────┐
                      │   翼缘 tf   │ ← B (翼缘宽度)
           ┌──────────┼─────────────┼──────────┐
           │          │   腹板 tw   │          │ ← H (总高度)
           └──────────┼─────────────┼──────────┘
                      │   翼缘 tf   │
                      └─────────────┘
```

**拆分公式**：

```
腹板 (web):
  新规格  = tw                      # 腹板厚度
  新宽度  = H - 2 × tf              # 腹板高度 = 总高 - 上翼缘厚度 - 下翼缘厚度
  数量    = 原数量 (不变)
  零件类型 = 原零件类型 + "H腹板"
  标记    = "拆"

翼缘 (flange):
  新规格  = tf                      # 翼缘厚度
  新宽度  = B                        # 翼缘宽度
  数量    = 原数量 × 2              # 翼缘有对称的两块
  零件类型 = 原零件类型 + "H翼缘"
  标记    = "拆"
```

**数值示例**：

| 输入 | → 腹板 | → 翼缘 |
|------|--------|--------|
| `BH300*200*6*8` | 规格=6, 宽度=**284**, 数量=1 | 规格=8, 宽度=200, 数量=**2** |
| `HA200*100*4*6` | 规格=4, 宽度=**188**, 数量=1 | 规格=6, 宽度=100, 数量=**2** |

> 腹板高度计算：300 − 2×8 = 284

### 2.2 工字钢 (I/HI) — 四参数拆分

拆分逻辑与 H 型钢完全相同，仅标注文字不同。

**输入规格**：`I{H}*{B}*{tw}*{tf}` 或 `HI{H}*{B}*{tw}*{tf}`

```
腹板 (web):
  新规格  = tw                      # 腹板厚度
  新宽度  = H - 2 × tf              # 腹板高度
  数量    = 原数量 (不变)
  零件类型 = 原零件类型 + "工腹板"

翼缘 (flange):
  新规格  = tf                      # 翼缘厚度
  新宽度  = B                        # 翼缘宽度
  数量    = 原数量 × 2              # 翼缘有两块
  零件类型 = 原零件类型 + "工翼缘"
```

**数值示例**：

| 输入 | → 腹板 | → 翼缘 |
|------|--------|--------|
| `I250*150*5*7` | 规格=5, 宽度=**236**, 数量=1 | 规格=7, 宽度=150, 数量=**2** |
| `HI300*200*8*10` | 规格=8, 宽度=**280**, 数量=1 | 规格=10, 宽度=200, 数量=**2** |

> 腹板高度计算：250 − 2×7 = 236

### 2.3 T 型钢 (BT) — 四参数拆分

T 型钢由 **一块腹板 + 一块翼缘** 组成（与 H 型钢的**关键差异**）。

**输入规格**：`BT{H}*{B}*{tw}*{tf}`

```
                      ┌─────────────┐
                      │   翼缘 tf   │ ← B (翼缘宽度)
           ┌──────────┼─────────────┼──────────┐
           │          │   腹板 tw   │          │ ← H (总高度)
           └──────────┘             └──────────┘
```

**拆分公式** (*与 H 型钢的差异用 **粗体** 标出*)：

```
腹板 (web):
  新规格  = tw
  新宽度  = H - tf                  ← **仅减一块翼缘厚度**
  数量    = 原数量 (不变)
  零件类型 = 原零件类型 + "T腹板"

翼缘 (flange):
  新规格  = tf
  新宽度  = B
  数量    = 原数量 × 1              ← **翼缘不翻倍（只有一块）**
  零件类型 = 原零件类型 + "T翼缘"
```

**H 型钢 vs T 型钢对比**：

| 属性 | H 型钢 (BH/HA) | T 型钢 (BT) |
|------|:-------------:|:-----------:|
| 翼缘数量 | 2 块 (对称) | 1 块 |
| 腹板高度公式 | H − 2×tf | H − tf |
| 翼缘数量倍数 | ×2 | ×1 |

**数值示例**：

| 输入 | → 腹板 | → 翼缘 |
|------|--------|--------|
| `BT200*150*6*8` | 规格=6, 宽度=**192**, 数量=1 | 规格=8, 宽度=150, 数量=1 |

> 腹板高度计算：200 − 8 = 192

### 2.4 板材 (PL/-) — 两参数排序

板材的拆分最简单：**只做厚度和宽度的排序，不增加行数**。

**输入规格**：`PL{a}*{b}` 或 `-{a}*{b}` 或 `{a}*{b}`

```
板材 (原地修改，不拆分):
  新规格  = min(a, b)               # 小值作为厚度
  新宽度  = max(a, b)               # 大值作为宽度
  数量    = 原数量 (不变)
  零件类型 = 不变
  不增加行                           # 原地修改该行
```

**为什么要排序**：在钢结构制造中，`PL10*2000` 和 `PL2000*10` 表示同一块板（厚度10mm，宽度2000mm）。工具将它们统一为 `厚度×宽度` 格式（小值在前），便于后续数控下料程序处理。

**数值示例**：

| 输入 | → 新规格 | → 新宽度 | 说明 |
|------|:------:|:------:|------|
| `PL10*2000` | 10 | 2000 | 已经是有序的，不变 |
| `PL2000*10` | 10 | 2000 | 自动调换顺序 |
| `-15*3000` | 15 | 3000 | 短横线前缀 |
| `6*284` | 6 | 284 | 无前缀裸数字 |

## 3. 处理流水线

完整的处理流程分为两步：**表头检测** 和 **逐行拆分**。

### 3.1 表头自动检测 (`detect_data_region`)

从 Excel 读取原始数据后，自动检测标题行和数据区域：

```
算法步骤:
  1. 扫描表格上半部分的行 (最多一半行数)
  2. 统计每行的非空单元格数量
  3. 第一个非空率 ≥ 87.5% (即: total_cols - total_cols // 8) 的行为标题行
  4. 标题行以上为无用行（如总标题、说明等），标题行以下为数据行
  5. 空标题单元格自动生成 "按A列" / "按B列" 等名称
  6. 标题行内含 Chr(10)(\n) 换行符会被自动清除
```

**容错示例**：

```
输入 Excel:
  第1行:  "钢结构零件汇总表"  (空)     (空)    → 无用行，跳过 (非空率 33%)
  第2行:  "规格"     "宽度"    "数量"    "类型"  → 标题行 (非空率 100%) ← 选中
  第3行:  "BH300*..."  "300"    "1"     "H钢"   → 数据行
  第4行:  "PL10*2000"  "10"     "5"     "钢板"  → 数据行
```

此算法来自 VBA 原始代码，容忍总标题行、空行等常见 Excel 格式。

### 3.2 逐行拆分 (`split_profile_df`)

```
对每一行数据:

  1. 读取规格列的值
  2. 调用 _detect_profile_type() 识别类型
  3. 判断类型是否在用户启用的 modes 列表中:

     ┌─ 是 H/I/BT 且在 modes 中:
     │    _parse_four_num() 提取 4 个数值
     │    创建腹板行 (row1) + 翼缘行 (row2)
     │    标记 "拆"
     │    ↓
     │    原行被替换 (不保留)
     │
     ├─ 是 PL 且在 modes 中:
     │    _parse_plate() 提取 2 个数值
     │    排序后写回规格和宽度列
     │    原地修改 (不增加行)
     │    ↓
     │    该行被修改
     │
     └─ 其他:
          原样保留
```

**输出**：
- 所有被拆分的行获得 `"拆"` 标记列（仅在存在至少一个拆分行时显示此列）
- 板材行原地修改，不增加行数
- H/I/BT 行被替换为腹板行和翼缘行，不保留原行

### 3.3 Excel 级输出 (`split_profile_excel`)

```
1. 从 Excel 文件中读取指定的原始子表
2. 调用 detect_data_region() 检测表头，转换为 DataFrame
3. 调用 split_profile_df() 执行拆分逻辑
4. 在原 Excel 文件中新增 "{sheet_name}_拆板后" 子表
5. 原表完全不动 (只读不写)
6. 若目标子表已存在，先删除再写入 (覆盖)
```

**处理前后对比示例**：

```
输入: project.xlsx                输出: project.xlsx
┌─────────────────────┐          ┌─────────────────────┐
│ 整理表              │          │ 整理表 (不变)       │
│ ┌────────────┐      │          │ ┌────────────┐      │
│ │BH300*200*6*8│     │          │ │BH300*200*6*8│     │
│ │I250*150*5*7 │     │          │ │I250*150*5*7 │     │
│ │PL10*2000    │     │          │ │PL10*2000    │     │
│ │L50*5        │     │          │ │L50*5        │     │
│ └────────────┘      │          │ └────────────┘      │
└─────────────────────┘          ├─────────────────────┤
                                 │ 整理表_拆板后 (新增)│
                                 │ ┌────────────┐      │
                                 │ │6  H腹板    │      │
                                 │ │8  H翼缘 ×2 │      │
                                 │ │5  工腹板   │      │
                                 │ │7  工翼缘 ×2│      │
                                 │ │10 板材     │      │
                                 │ │L50*5 原样  │      │
                                 │ └────────────┘      │
                                 └─────────────────────┘
```

## 4. 不处理的规格类型

以下规格字符串**不会被拆分**，整行原样保留：

| 示例 | 原因 |
|------|------|
| `L50*5` | 角钢 — 前缀 `L` 不在任何识别集合中 |
| `HN300*150` | 热轧 H 型钢 — 前缀 `HN` 不识别 (只识别 `BH`/`HA`) |
| `HW200*200` | 同上 — 前缀 `HW` 不识别 |
| `HM250*175` | 同上 — 前缀 `HM` 不识别 |
| `C200*70*20*2.5` | C 型钢 (槽钢) — 前缀 `C` 不识别 |
| `方管100*100*5` | 方矩形管 — 无匹配前缀 |
| `D108*4` | 圆管 — 前缀不匹配且非 `{a}*{b}` 格式 |
| 纯数字 `10` | 无前缀且不匹配 `{a}*{b}` 双数字格式 |

**唯一被识别并处理的前缀**：`BH` / `HA` / `I` / `HI` / `BT` / `PL` / `-`

## 5. 数量处理规则

| 类型 | 原数量 | 腹板数量 | 翼缘数量 | 说明 |
|:----:|:-----:|:------:|:------:|------|
| BH/HA | N | N | **N × 2** | 翼缘有对称两块 |
| I/HI | N | N | **N × 2** | 同上 |
| BT | N | N | N | T 型钢仅一块翼缘 |
| PL | N | — | — | 板材不拆分，原地修改 |

**数量计算细节**：
- 若数量列值为非数字字符串，捕获异常，保持原值不变
- 计算结果若为整数则输出整数（如 `2` 而非 `2.0`）

## 6. 标注列 (零件类型) 处理

拆分后的零件类型列自动附加后缀，指示该行是腹板还是翼缘：

| 原始值 | H型钢 → 腹板 | H型钢 → 翼缘 | 工字钢 → 腹板 | 工字钢 → 翼缘 |
|--------|:----------:|:----------:|:----------:|:----------:|
| `"H钢"` | `"H钢H腹板"` | `"H钢H翼缘"` | — | — |
| `"工钢"` | — | — | `"工钢工腹板"` | `"工钢工翼缘"` |
| `""` (空) | `"H腹板"` | `"H翼缘"` | `"工腹板"` | `"工翼缘"` |

| 原始值 | T型钢 → 腹板 | T型钢 → 翼缘 |
|--------|:----------:|:----------:|
| `"T钢"` | `"T钢T腹板"` | `"T钢T翼缘"` |
| `""` (空) | `"T腹板"` | `"T翼缘"` |

- 板材的零件类型：**不附加任何后缀**
- 未被拆分的行：零件类型完全不变
