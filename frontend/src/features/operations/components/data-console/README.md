# 数据管理台面板

## 现有实现

- `ProductionTaskPanel.tsx`：只通过生产流程与任务业务接口展示项目、阶段、任务状态、错误、取消和重试，不直接修改数据库行。
- `ObjectsPanel.tsx`：按中文存储区展示已登记文件；管理员可上传、下载、移动和软删除，所有操作继续走文件业务接口。
- `presentation.tsx`：集中保存状态、任务和存储区的中文解释。底层标识只作为接口值，不直接充当生产人员界面文案。

## 业务边界

数据管理台只管理现有生产任务和已登记文件，不展示数据库表结构、消息队列内部行或未接入的基础设施能力。生产阶段推进仍在生产流程页面完成。
文件列表和下载始终使用数据库登记的 `original_name`；内部存储 key
只用于定位与管理员更改路径，移动文件不得改变原名。未登记对象没有可信
登记名称时才回退到对象自身文件名。
