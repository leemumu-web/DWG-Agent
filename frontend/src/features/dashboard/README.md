# 工作台

## 现有实现

`DashboardPage.tsx` 只查询 `linux_production` 生产流程和后端流程模板，展示真实项目汇总、最近项目、新建项目入口与六段可展开生产操作手册。手册按准备资料、上传冻结、分类核数、整批拆板、Excel 查询核重和下载异常处理说明实际动作与核验边界；`styles.css` 负责响应式布局，`index.ts` 对外导出页面。

## 业务流与边界

输入是工作流分页、模板和当前登录人，输出是操作员的生产起点。卡片数字直接采用后端生产流程摘要，不承担任务恢复或数据库统计真相。
查询失败时页面保留新建与操作说明并展示明确错误，不用零值掩盖服务异常；任务和已登记文件管理归数据管理台。
操作手册解释现有能力，不替代服务器阶段状态：Excel 第二阶段先做服务端预检，再由专用队列生成读取表与正式深化表；仍未实现的后续阶段显示等待上线时，不提供模拟按钮或虚假完成路径。
