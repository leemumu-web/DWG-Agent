# Remnant inventory E2E

`search.spec.ts` 在浏览器中模拟材质、库存和详情 API，验证 `/remnants` 的必填查询、同系列开关、可用优先顺序、占用人展示、真实原图格式标签和他人预占下载限制。导入、刷新恢复和人工确认流程由同目录后续 `import.spec.ts` 覆盖。

该分区负责锁定工人实际可见的查询与操作反馈，避免后端契约可用但网页缺少必要控件。测试边界只包含浏览器交互和模拟 API 契约，不访问真实业务文件，也不得把模拟响应当成 ODA 转换、MySQL 并发或权限安全的生产证据；真实外部依赖由后端集成测试、样本校准及最终验收门禁负责。
