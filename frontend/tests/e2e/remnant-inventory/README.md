# Remnant inventory E2E

`search.spec.ts` 在浏览器中模拟材质、库存和详情 API，验证 `/remnants` 的必填查询、同系列开关、可用优先顺序、占用人展示、真实原图格式标签和他人预占下载限制。`import.spec.ts` 覆盖混合文件选择、批次 URL 刷新恢复、逐图失败重试、批量厚度、候选证据/警告、人工校正和选中项部分确认。`auto-import.spec.ts` 覆盖自动导入页签、文件夹递归路径、项目编号预填/修改、批次恢复和文件上限。`materials.spec.ts` 验证管理员能看到已停用材质并将其重新启用。`global.spec.ts` 覆盖全部余料视图、归档/已使用筛选和一键导出。

该分区负责锁定工人实际可见的查询与操作反馈，避免后端契约可用但网页缺少必要控件。测试边界只包含浏览器交互和模拟 API 契约，不访问真实业务文件，也不得把模拟响应当成 ODA 转换、MySQL 并发或权限安全的生产证据；真实外部依赖由后端集成测试、样本校准及最终验收门禁负责。
