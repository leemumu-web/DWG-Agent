# CAD 智能生产平台关键技术创新与阶段成果汇报

我们建设的 CAD 智能生产平台，已经从若干独立的图纸和表格处理工具，发展为贯穿生产资料接收、图纸转换、自动分流、BH 和 BOX 拆板、BH 左右进识别、Excel 两阶段加工、数据沉淀、权限控制和余料管理的生产前置平台。

这套系统解决的核心问题，不只是减少人工点击和重复录入，而是让每一份源文件、每一次处理、每一个结果和每一项异常都有来源、有状态、有责任人、有明确去向。过去依赖个人经验、本机目录和口头交接的生产资料，正在转变为公司能够统一管理、持续积累和安全接续的数据资产。

项目形成了一条贯穿各模块的设计原则：自动化必须建立在充分证据之上。能够确认的工作由系统自动完成，证据不足的工作明确交给专业人员判断；系统不以表面的“全部成功”为目标，而以结果可信、过程可查、问题可接管为目标。这是本项目最重要的产品理念，也是各项技术突破能够真正进入生产流程的基础。

## 一、建立可信、统一的生产资料入口

系统把一个源 Excel 和一批 DWG 作为生产入口。DWG 始终保留为原始依据，后续分类、拆板、左右进读取和图纸流转统一使用服务器转换出的 DXF，不再让人工上传的 DWG 与 DXF 混用，从源头避免版本错配。

资料进入流程前，系统会重新检查文件是否可读、同名关系是否正确、转换结果是否完整，并为文件生成唯一数字指纹，随后冻结本批输入。这样，一张图从哪里来、转换成了什么、后续使用的是哪个版本，都可以重新核对。单批输入已经按最多 5,000 张图纸进行设计，为大型项目的集中处理预留了能力。

这一设计的突破，在于把“上传一批文件”变成“建立一批可信生产资料”。后续所有自动处理都从同一批冻结资料出发，减少重复上传、错用旧图和中途替换文件造成的风险。

## 二、实现拆板前的全自动识别与分流

传统图纸分类通常依赖文件名、目录名和操作人员经验，数量一多就容易发生错分、漏分和目录标准不一致。平台现在直接读取图纸右上信息表中的截面和规格，识别 BH、BOX、PL、PX、RHS 等类型，不再根据文件名和材料表中的零散文字猜测图纸类别。

对于企业自定义或低频型材，系统可以在安全规则内发现新的类型，同时拒绝把材质牌号、螺栓规格、比例等内容误认为构件类型。每张图的原始规格、规范规格、类型来源、分组、判断依据和下游资格都会被保存。证据充分的图纸自动进入下一工序，存在冲突或无法读取的图纸进入待确认区域，不会被包装成自动成功。

这项能力已经在两组真实 Tekla 项目中完成 243 张 DXF 的自动分类，总耗时 58.420 秒，平均约 4.16 张每秒，其中包括 208 张 BH、32 张 BOX 和 3 张 PL。243 张图分类前后逐文件对比均无内容变化，说明系统能够在保持源图完整的前提下，用不到一分钟完成数百张既有项目图纸的识别和分流。

## 三、形成 BH 和 BOX 两套专业自动拆板能力

BH 和 BOX 没有被强行放进一套通用拆板规则。BH 重点处理腹板、上下翼板、变截面、斜腹板、坡口、孔洞和多段翼板；BOX 按四块板件的制造关系处理腹板、翼板、投影和轮廓。两类构件分别建立专业规则，由上游分类结果决定进入哪一套流程，既避免互相干扰，也便于后续持续升级。

每张自动通过的图纸都会同时形成正常拆板版和余量增长版两份完整 DXF。余量版由同一份已确认结果派生，只调整制造规则允许调整的板端。文件生成以后，平台还会重新打开两份图纸，核对单位、实体、图层、孔洞、余量和成对完整性。两份文件必须同源、同时通过、同时发布，任何一份缺失或无法证明，都不能进入正式结果包。

批量拆板允许部分成功，并对每 30 张图和最后尾批进行数量核对。一张异常图不会拖住整批资料，可靠结果可以先进入后续 Excel；同时，异常结果不会混入正式交付，原图和原因会完整保留给人工处理。

现有发布成果中，BH 的 20 张来源图全部自动接纳；BOX 的 20 对权威前后样例完成规则校准和独立验收。两个领域合计形成 40 张来源图的 40 组正式配对结果。BH 真实样例还形成 48 个圆孔的对称识别证据，其中 24 个左孔标红、24 个右孔保持白色。自动拆板由此从“算法可以输出文件”，进步为“平台可以交付经过独立确认的制造结果”。

## 四、突破 BH 左右进的批量识别与安全计算

BH 构件的总长不能直接代表腹板和上下翼板的实际下料长度。过去，这些左右退进量通常需要人工逐图量取、抄写并再次录入 Excel，既重复，又容易发生板件角色错配。

系统先定位构件主视图，再识别腹板、上翼板和下翼板，最终按照图纸的水平生产方向计算左右进。对于斜切、坡口和圆弧，不沿斜线量取视觉长度，而是使用实体轮廓在水平方向上的真实边界。内部竖线、焊缝线、投影线和加劲板边线不会被误认为板件端边，只有翼板材料真实断开时才会形成多段翼板。

这一模块把生产安全放在覆盖率之前。单位、圆弧或板件归属无法确认时，系统拒绝输出；最终数值严格向下取整，避免浮点误差或四舍五入造成下料偏短。

现有正式回归覆盖 199 张真实 BH 图，两种读取方式均实现 199 张全部通过，共形成 420 条板件结果，199 张图全部确认为毫米单位，没有出现无效数值和板件证据缺失。发布记录还包含 80 项自动检查和 432 个确定性有效 BH 组合。这项突破已经把逐图量取转变为可批量执行、只需处理异常的专业工序。

## 五、完成 Excel 第一阶段的统一整理与质量核验

Excel 第一阶段负责把不同来源的清单整理成稳定、统一、可以复算的数据底稿。系统可以处理标准 Tekla 工作簿、旧版 Excel、DWG 初始表和常见文本清单，固定生成原表、清洗表、构件表、整理表、part 和处理报告六张表。

原始资料得到完整保留，业务数据在新的工作表中统一整理。BH、BOX、BT 等制造型材会展开为腹板和翼板，普通板材和标准型材按照统一规则分类汇总。重量计算统一查询公司五金手册；相同规格出现不同重量时，系统明确提示冲突，不随机选择其中一个结果。同时，系统会核对单重、数量、总重、构件数、净重、理论重和毛重之间的关系，把隐藏在大表中的质量问题主动暴露出来。

最终工作簿保留现场人员可以查看和复算的公式，关键尺寸和重量则以高精度形式进入统一数据中心。这样，Excel 既是一份可直接使用的生产文件，也成为能够查询、复核和统计的数据产品。

首都体育学院 B7 样本由 485 条父零件形成 527 条整理数据、122 条 part 下料数据和 3,637 个可复算公式，项目净重为 122,013.557 千克、理论毛坯重为 124,507.840 千克、表毛重为 124,831.881 千克，与 22 条已确认规则对比为 0 失败。003 郑州宝冶样本形成 7,399 条整理数据、3,017 条 part 下料数据和 53,796 个公式，并主动发现 7 条警告和 1 条严重源重量链异常。成果既体现了数千行清单的处理规模，也体现了系统发现真实数据问题的能力。

## 六、打通 Excel 第二阶段与图纸识别结果

Excel 采用两阶段设计。第一阶段建立稳定的清单和重量基线，第二阶段再把 BH 图纸中识别出的左右进写入下料数据。这样，清单整理不会被一张异常图拖垮，图纸深化也不能绕过稳定基线直接覆盖表格；发生问题时，可以明确区分是清单问题、缺图问题、规格问题还是读取问题。

第二阶段读取的是拆板前的完整 BH 构件图，因为左右进需要看到腹板和翼板相对于构件两端的位置。系统同时核对自动分类得到的规格、左右进识别得到的规格和 Excel 中记录的规格，并检查腹板、上下翼板是否齐全。只有三方一致时，才按照“下料长度＝原模型长度－左进－右进”更新整理表、part、理论单重和理论总重，并把结果同步到统一数据中心。

项目没有 BH 时，第二阶段原样形成正式结果；Excel 中有 BH 但缺图时，保留原长度并给出告警；图纸存在但读取或规格匹配不可靠时，左右进和下料长度留空，明确交给人工补录；图纸存在但 Excel 没有对应零件时，系统记录问题。旧任务和旧文件不能覆盖当前正式结果。识别结果由此不再停留在一张诊断表中，而是真正进入了生产清单和公司数据。

## 七、建立统一数据中心和可靠的任务接续机制

平台已经不再依赖某个工程师的本机目录保存项目状态。当前系统形成了 48 张业务数据表、183 条服务路径和 211 项操作，统一管理项目、文件、任务、工作流、分类、拆板、Excel、余料、用户和审计关系。大型图纸和表格保存在专门的文件存储中，业务关系、文件位置、数字指纹和处理状态保存在统一数据中心，既避免大文件影响业务查询，也保留了完整关系。

这套设计让公司拥有明确的生产事实源。过去依赖人员记忆回答的“哪个文件最新”“这张图为什么没有拆板”“这份 Excel 对应哪批图”，现在可以沿着项目、阶段、文件和结果关系直接查询。一张源 DWG 可以追溯到转换后的 DXF、分类结果、拆板两套图纸、Excel 两阶段结果和下载记录；一行 Excel 数据也可以追溯到批次、构件、零件和质量状态。

长时间运行的图纸任务可以安全重试和恢复。每次重试都有新的处理代次，上一轮任务不能覆盖当前结果；任务提交、领取、执行和文件保存都有独立状态，某一步失败后可以继续处理或补偿，不必整批从头再来。不同工程师也能够围绕同一个项目接续工作，企业知识从个人记忆转变为可查询、可交接的组织资产。

## 八、形成面向协作和责任追溯的权限体系

权限系统同时考虑公司管理职责和项目内部分工。全局设置超级管理员、管理员、操作员和只读用户；项目内部再区分项目负责人、工程师和复核人。超级管理员是唯一受保护的恢复根，不能被普通操作禁用、删除或降级。文件、任务和结果的权限跟随项目关系，而不是只跟随最初上传人，同一项目的工程师可以安全接续，非项目成员无法越权查看。

权限判断落实在实际操作入口，而不只是隐藏页面按钮。即使拿到短期下载地址，仍然需要有效登录和文件权限；永久清理要求管理员权限、完整备份下载、处理范围复检和明确确认。用户、角色、文件、任务、复核、Excel 和余料的关键变更都会留下记录。

这套权限设计的价值，不是给系统增加门槛，而是让平台能够从少数人使用扩展到跨项目、跨岗位协作，同时守住数据范围、责任边界和交接连续性。

## 九、把余料从个人台账转变为公司材料资产

余料库统一管理材质、厚度、长宽、项目编号、库位、备注、多个零件编号和原始图纸。现场人员可以按业务条件直接查询余料，不再依赖文件名、个人 Excel 和口头询问。

余料按照可用、已预占、已使用和已归档进行状态流转。同一块余料在多人同时预占时只允许一人成功；只有预占人或管理员可以释放和领用；删除只允许作用于已归档记录，同时保留原图、导入记录和删除前信息。库存变化从个人修改表格，转变为受控、可追溯的公司业务过程。

余料导入兼顾历史资料和标准化未来。普通 DWG 或 DXF 可以先提取候选信息，再由人员确认厚度、材质、项目和零件号；带标准余料信息块的图纸可以直接读取规格、材质和编号。信息缺失、重复或不合法时，系统明确提示人工处理，不从文件名和普通文字补猜正式字段。

单批自动导入最多 100 张图纸，个别失败不会影响同批其他图纸；批量归档一次最多 200 条，也会逐条返回成功或失败原因。余料由此形成可以查询、预占、领用、归档和导出的共享库存，为后续余料优选和材料利用分析打下基础。

## 十一、阶段价值与当前边界

目前，系统已经完成生产前半程的平台化闭环，覆盖源 Excel 和 DWG 接收、服务器转换 DXF、自动分类分流、BH 和 BOX 自动拆板、Excel 第一阶段、BH 左右进识别、Excel 第二阶段、统一数据管理、权限审计和余料管理。

短期看，图纸不再逐张依靠人工判断类型和建立目录，可靠的 BH 和 BOX 不再逐张选择拆板程序，BH 左右进不再逐图量取和抄写，Excel 不再依靠个人公式和临时表格维持，同一批资料也不再在不同阶段反复上传和人工确认版本。系统同时把缺图、规格冲突、重量异常、单位不确定和拆板结果不成对等问题提前暴露出来，减少错误向后传递。

中期看，分类类型、零件和构件、重量质量、拆板处置、项目进度和余料库存都已经成为可查询数据，可以进一步形成项目周期、自动通过率、异常原因、材料利用和库存周转等管理指标。

长期看，后续自动排版和生产计划需要的不是一批无序文件，而是已经分类、拆板、校验、赋予零件身份并受到权限管理的可信输入。本项目已经把这套前置基础建成，未来能力可以继续复用现有文件、任务、工作流、数据和权限体系。

当前边界同样明确。自动拆板目前只覆盖 BH 和 BOX，Excel 第二阶段目前只深化 BH；尚未形成完整的人工拆板回流工作台；CAM 工作包、Windows SinoCAM 自动排版、排版结果接纳和最终交付仍待完成；余料库尚未与排版结果和自动选料形成闭环。平台在正式扩大部署前，还需要继续完善加密访问、外部只追加审计、集中监控告警以及业务数据和文件的联合备份恢复。

目前最重要的成果，是我们已经把一批相互分散的生产文件，转化为能够沿明确流程流动的可信数据。自动化处理确定的部分，专业人员处理真正需要判断的异常，统一数据中心保存组织记忆，权限体系保障协作边界，余料库继续沉淀材料资产。这套设计既取得了可量化的阶段成绩，也为后续自动排版、余料优选、生产计划和经营分析建立了可以持续复用的基础。

## 十二、总结

**目前已经实现：**Excel 清单的第一阶段自动处理，能够完成清单整理、型材拆分、重量计算、质量核验和标准结果输出；拆板前不同图纸类型的自动预分类，能够将 BH、BOX 图纸送往对应流程；BH 和 BOX 的自动拆板及配套人机交互，能够展示自动结果、隔离异常图纸并支持人工复核处置；BH 左右进的智能读取，并在第一阶段 Excel 正式结果的基础上完成第二阶段回填，形成可用于下料的长度和重量数据；余料库的集成统一管理，实现余料导入、确认、查询、预占、领用、归档和追溯。上述能力已经由统一数据、权限和项目流程串联，形成了当前可用的生产前置处理体系。

**当前尚未上线：**BOX 左右进智能读取和 CAM 自动导入尚未接入正式生产流程。同时，Excel 的 Part 表部分还不完善，需要继续优化。
