# 余料候选扩展、全局查看与 Excel 导出设计

## 背景

现有余料导入解析器只接受少量固定格式：材质主要覆盖 `Q355B` 一类牌号，未标注零件编号仅覆盖南京项目的固定前缀，项目标题还要求出现三位数字和“计划”。精武路样本包含更广泛的材质、零件编号和中文标题，因此大量有效文字落入 `UNRECOGNIZED_TEXT`。

现有网页只能在同时填写材质和厚度后查询余料，无法直接浏览全库，也没有全量 Excel 导出。

## 已确认需求

- 扫描 DXF 中的全部空间区域，不按 CAD 当前视口或空间聚类过滤。
- 扩展材质和零件编号识别；结构相似的文字均进入候选。
- 项目标题以包含中文为主要判断依据；多个候选交给工人选择。
- 独立文字清洗后若仅包含连续 2～3 个中文字符则忽略，例如“余料”“未到料”。
- 一张余料图可以关联多个零件编号，候选默认全部选中，允许取消或手工补充。
- 所有工人可以查看全局余料数据并一键导出全部余料。
- Excel 一张余料一行，多个零件编号在同一单元格中以顿号连接。

## 解析分类顺序

分类器按以下优先级处理每条标准化文字证据：

1. 显式标签：继续支持材质、项目、零件等现有标签。
2. 材质片段：从括号或复合文字中提取 `Q` + 三位数字 + 字母质量等级/性能等级及可选后缀，例如 `Q345GJC-Z15`、`Q460GJB-Z25`。
3. 零件编号片段：提取至少同时包含字母和数字、由连字符分段的编号；支持数字开头及字母数字混合首段，例如 `3CB-3D-1`、`YL42-2`。
4. 短中文标注：标准化后完全匹配 2～3 个中文字符时忽略。
5. 项目标题：其余包含中文且不超过 128 字符的完整文字成为项目候选。
6. 普通尺寸、日期和说明文字：忽略，不产生绘图级 `UNRECOGNIZED_TEXT`。

材质优先于零件编号，避免 `Q345GJC-Z15` 被双重分类。复合文字可以同时产生材质和零件候选。候选继续按首次出现顺序去重并保留全部证据。

编码异常、未知显式字段标签、过长项目标题、多个材质和多个项目候选仍保留现有警告。普通未分类文字不再产生 `UNRECOGNIZED_TEXT`。

## 人工确认界面

- 材质保持单选，多个候选由工人从正式材质库选择；未建档牌号可以立即创建并使用。
- 项目标题保持单值，候选通过可搜索/可编辑的候选控件选择。
- 零件编号改用支持多选和自由输入的标签选择控件。
- 首次打开确认窗口时，如果尚未保存人工修正，全部零件候选默认选中。
- 保存时仍提交现有 `parts: string[]`，不改变后端确认契约和数据库结构。

## 全局余料列表

新增独立的“全部余料”页签。打开后立即查询，不要求材质和厚度。列表包含全部库存状态，并支持：

- 材质、厚度、状态、项目编号和零件编号筛选。
- 创建时间、厚度和状态排序。
- 服务端分页。
- 复用现有详情、预览、预留、释放、领用、编辑和归档操作。

精确的“材质 + 厚度”查料接口和界面保持原样。全局列表使用独立后端查询函数和路由，避免放宽现有接口的必填参数而产生兼容性变化。

## Excel 导出

新增所有余料用户可调用的全量导出接口。后端直接查询全部余料，不采用当前页面、分页或筛选条件。工作簿仅含一个“全部余料”工作表，冻结首行、启用筛选、设置可读列宽和表头样式。

列顺序固定为：

1. 余料编号（现有系统余料 ID）
2. 材质
3. 厚度(mm)
4. 项目编号
5. 零件编号
6. 库存状态
7. 原始图纸文件名
8. 导入人
9. 导入时间
10. 当前预留人
11. 预留时间
12. 领用人
13. 领用时间
14. 最后更新时间

状态输出中文名称，时间转换为北京时间并写成 Excel 日期值。没有对应状态的信息留空。文件名为 `余料库_YYYYMMDD_HHmmss.xlsx`。即使数据库无记录也返回包含表头的有效工作簿。导出成功写入审计日志。

生产导出由后端现有 Python/OpenPyXL 运行时生成，因为文件内容来自实时数据库且必须在部署环境内运行；测试会重新打开生成的工作簿，校验表名、表头、类型、中文、多零件合并和空数据行为。

## 数据与权限

- 不新增或修改数据库表。
- 全局查看和导出沿用 `can_use_remnants` 权限，所有已获余料库权限的工人可用。
- 人员名称通过现有 `sys_users` 外键查询。
- 全局列表和导出均只读取已确认形成的 `remnants` 数据，不包含尚待确认或失败的导入项。

## 验收标准

- 精武路示例格式能进入正确候选，短中文标注不报警。
- 多零件候选默认全部选中，工人可删除或补充后保存。
- 全局页无需查询条件即可显示所有状态的余料并可筛选、排序、翻页。
- 任一有余料库权限的工人可以下载全量 Excel。
- Excel 一张余料一行、字段完整、中文可读、时间与数值类型正确。
- 原有查料、导入、预览、库存状态流转和原图下载回归测试通过。
