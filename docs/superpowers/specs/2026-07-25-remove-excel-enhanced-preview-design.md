# 移除 Excel 增强预览设计

## 目标

完整移除基于 LuckyExcel 的客户端增强预览，只保留后端解析的快速 Excel 表格预览。

## 保留能力

- 打开 Excel 预览弹窗；
- 从权威文件存储读取后端预览数据；
- 多工作表切换；
- 内容感知列宽、数字格式和汇总行样式；
- 刷新、下载和关闭操作；
- 加载、空数据及接口错误反馈。

## 删除范围

- “快速预览 / 增强预览”模式切换控件和说明文案；
- LuckyExcel 脚本动态加载、Excel 文件二次下载和 Blob URL 管理；
- 增强预览状态、异步取消、错误回退和专用表格渲染；
- LuckyExcel 全局类型、数据模型、合并单元格及格式转换代码；
- `frontend/public/luckyexcel.umd.js` 静态资源；
- README 中对增强预览的描述。

后端 Excel 预览接口、文件下载接口、数据库结构和生产工作流均不修改。

## 页面行为

预览弹窗打开后直接加载快速预览，不再显示模式选择器。信息栏只显示当前工作表；标题继续显示文件名、总行数和工作表数量。

刷新操作只重新请求当前文件的快速预览。切换工作表继续调用后端预览接口。下载仍使用既有受控下载能力。

## 验证

1. 测试先证明当前源码和静态资源仍包含 LuckyExcel/增强预览。
2. 删除后，前端源码、公共资源和功能 README 不再出现 LuckyExcel 或“增强预览”。
3. Excel 快速预览模型测试、TypeScript 检查和生产构建通过。
4. 完整重启后前端构建产物为最新，健康检查和 SPA 托管正常。

## 完成标准

- 用户界面没有增强预览入口；
- 浏览器不再请求 `luckyexcel.umd.js` 或为预览二次下载 Excel；
- 快速预览、工作表切换、刷新和下载保持可用；
- 不包含未使用的 LuckyExcel 类型、转换代码和静态资源；
- 代码提交并推送到远程 `main`。
