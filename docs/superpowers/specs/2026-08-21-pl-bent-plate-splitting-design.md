# PL 折弯板拆板设计

## 目标

新增与 BH/BOX 运行路径隔离的 PL Python 核心，并由单独的 `steel-dxf-split-pl` 启动包提供命令：把 Tekla PL 折弯板投影视图转换为一块连续的 1:1 展开板，并逐件生成可审计的结果 DXF。

PL 核心使用 `ezdxf==1.4.4` 读写和变换原生 DXF 实体，使用 `Shapely>=2.1,<3` 重建、选择和验证二维轮廓。DWG 与 DXF 之间的转换继续使用仓库已有 `dwg2dxf`、`dxf2dwg` Stage；PL 工具本身不直接读取或写入 DWG。

## 已确认的业务规则

- 一个折弯 PL 原件展开后仍是一块连续板，不按折弯线拆成多块。
- K 因子固定为 `0.5`。
- 板材及任何需要补偿的转折区间都不允许缩短；只允许增加计算和十进制上取整所需的最小长度，不叠加任意余量。
- 不按整板总长统一缩放。每个转折分别测量，只在对应的长度区间内沿 X 方向等比拉伸，后续区间按累计增量整体顺移；板宽方向不缩放。
- 分段非等轴拉伸后的圆弧允许精确写为 DXF `ELLIPSE`。
- 每个正的转折补偿量和最终总长度都按小数点后一位严格向上取整，最小长度粒度为 `0.1 mm`；任何正余量都不得向下吸附。
- 结果零件标记带 `p=` 前缀，例如 `p=q4-b-181`。
- PL 单件输出沿用 BH/BOX 的生产图层命名：制造外轮廓位于 `PLATE_CUT`，零件标记位于 `PART_LABEL`。
- PL 不生成 BH/BOX 的“正常拆板/余量增长”双产物，也不执行焊接余量逻辑。

## 现有实现与复用边界

仓库现有 BH 与 BOX 核心已经提供以下可复用能力：

- `steel_dxf_split.dxf_io`：DXF 审计读取、CAD 文字传输解码、嵌套 `INSERT` 递归展开。
- BH/BOX writer：R2007、毫米单位、清洁制造图层、中文字体、保存后审计和确定性写图模式。
- `part_mark_layout`：在有效材料区域内放置零件标记。

现有统一 `pipeline.py` 只接受冻结分类 `BH` 或 `BOX`，并强制生成普通版与余量版配对结果。PL 的单板、单产物合同与该入口不兼容。本次不把 PL 塞入 BH/BOX 统一入口，不修改 BH/BOX 制造几何、余量、发布认证、后端工作流或现有合图脚本。PL 拆板核心位于 `steel_dxf_split/pl/`，命令由单独的 `Stages/steel_dxf_split_pl` 轻量启动包提供；原 BH/BOX `pyproject.toml` 和 `steel-dxf-split` 入口保持不变。

## 方案选择

### 方案 A：新增完全独立的 PL 拆板模块（采用）

在 `steel_dxf_split/pl/` 中隔离源图解释、几何展开和写图，不让 PL 规则进入 BH/BOX 核心。

优点是业务合同清楚、测试范围可控，并允许以后单独把 PL 接入生产工作流。代价是本次不会自动改变当前后端只接纳 BH/BOX 的路由。

### 方案 B：直接把 PL 加入统一 BH/BOX `pipeline.py`（不采用）

该方案会同时改变分类清单、source contract、双产物验收、后端持久化、选择性导出和前端展示。PL 当前没有焊接余量双产物，强行复用会制造错误合同。

### 方案 C：只按总长度统一缩放主视图（不采用）

该方案即使能得到正确总长，也会把增量错误均摊到无关直段。`q7-b-404` 证明参考结果保留前后直段，只增加中间斜转折的 X 投影并把后续几何整体右移，因此统一缩放不满足逐转折尺寸合同。

## 模块结构

新增模块保持职责单一：

- `pl/contracts.py`：冻结输入、源证据、展开结果和输出结果数据结构。
- `pl/source.py`：读取 DXF、展开图框块、提取文字、解析零件号及 `PL厚度*宽度`、建立单件源上下文。
- `pl/geometry.py`：把 `Part` 图层原生线弧转换为 Shapely 拓扑，识别主视图、折弯投影站点和剖面厚度带，建立剖面分段与主视图区间的唯一对应关系。
- `pl/development.py`：逐转折计算 K=0.5 中性层补偿、严格十进制上取整、累计站点及连续分段 X 映射，并在站点处切分跨区间实体。
- `pl/writer.py`：只从已验证的展开结果生成清洁 PL DXF，并执行保存后复核。
- `pl/compiler.py`：编排一个零件的源解释、展开、验证和写图事务。
- `pl/cli.py`：批量处理单张、合并图或输入目录，发布结果及拆板报告。
- `Stages/steel_dxf_split_pl`：只注册 `steel-dxf-split-pl` 命令并转发到 PL CLI，不导入 BH/BOX 入口。

## PL 源输入合同

### 文件格式

`steel-dxf-split-pl` 接受：

- 一张单零件 DXF；
- 一张由多个顶层图框 `INSERT` 组成的合并 DXF；
- 一个目录第一层中的多张 DXF。

输入与输出目录不能相同或互相嵌套。目录扫描在处理开始前冻结，只处理第一层 `.dxf` 文件，不把运行中新生成的文件重新当成输入。

### 单件边界

合并 DXF 中，每个能够独立证明零件号、PL 规格和制造视图的顶层图框块形成一个单件源上下文。单张 DXF 若没有这种顶层图框集合，则模型空间整体形成一个单件上下文。

所有嵌套 `INSERT` 使用 `recursive_virtual_entities()` 展开并应用完整实例变换。源实体句柄、容器块句柄、原始图层和文字坐标进入报告，用于追溯，但不进入结果制造图。

### 元数据

每个单件必须唯一提取：

- 规范化零件号；
- `PL厚度*宽度` 中的厚度和板宽；
- 材料表长度；
- `Part` 图层制造视图。

零件号字段若带 `p=`，解析时去掉前缀形成内部规范化编号；结果 `PART_LABEL` 再统一写回 `p=<编号>`。当前语料中的裸 `PartMark` 和图框块名可作为同一编号的交叉证据，但冲突时不按文件名猜测，直接拒绝该零件。

材料表存在多行 PL、多个不同长度或无法唯一绑定当前零件时，当前零件进入拒绝结果。

## 主视图与剖面识别

### Shapely 拓扑

只把源 `Part` 图层的制造线弧用于候选轮廓。尺寸、剖面标记、图框、图片、HATCH、`OtherObjectType` 和说明文字不参与制造边界。

原生 `LINE`、`ARC`、`ELLIPSE` 和多段线以最大 `0.01 mm` 弦高误差转换为 Shapely 线网。端点在 `0.1 mm` 内允许拓扑吸附；吸附只用于识别和验证，输出仍由源原生实体及精确变换生成。

每个连接分量执行 `polygonize_full`。内部折弯投影线可以把一个面分成多个子面，子面在同一连接分量内重新 `unary_union` 为材料区域；悬线、无法解释的切线和多余闭环保留为诊断，不进入结果外边界。

### 主视图

主视图候选必须同时满足：

- 存在唯一有效外轮廓；
- 横向实际跨度与 PL 名义板宽一致，误差不超过 `0.1 mm`；
- 具有明确的长度主轴；
- 外轮廓面积为正且无自交；
- 同一单件中没有第二个同等可信的板宽投影。

主视图长度轴规范化为从最小 X 到最大 X。当前版本不旋转任意方向的制造视图；若唯一主轴不是图纸 X 方向，拒绝并在报告中记录，避免改变已经确认的左端锚定合同。

完整内部折弯投影线不作为切割线。当前版本只自动发布唯一外轮廓；主视图存在孔槽、多个内轮廓或多个不连通板体时拒绝，不推断未被 21 组样例证明的孔槽展开规则。

### 剖面厚度带

主视图之外的 `Part` 材料区域用于寻找剖面厚度带。候选必须能够证明：

- 一个闭合、有效、恒定厚度的带状区域；
- 剖面 X 投影跨度与主视图投影跨度一致，误差不超过 `0.1 mm`；
- 材料面积为正且没有孔槽；
- 组成剖面的原生线弧及其拓扑吸附关系能够追溯。

真实语料中的剖面端部既有单条板厚边，也有斜切端和多段复合端链。因此端部不强制退化成两条长度恰好等于板厚的直线。若不存在唯一剖面、存在多个同等候选或路径断裂超过拓扑容差，则拒绝该零件。

### 转折站点和区间对应

剖面材料边界先分解为从左端到右端的两条可追溯板面路径。两条路径必须方向一致、没有 X 向回折，并能由端部链唯一配对。每个原生直线或曲线的端点形成候选转折；一对板面端点的厚度中点形成中性层站点。站点按 X 坐标排序，相邻站点形成一个剖面区间。

主视图站点序列固定以外轮廓的 `x_min` 开始、以 `x_max` 结束，中间站点证据来自外边界方向变化点及位于材料区域内、能够横贯板宽的折弯投影线。内部折弯投影线只用于区间定位，仍不写入 `PLATE_CUT`。剖面站点按相对 X 投影与主视图站点在 `0.1 mm` 内一一匹配；主视图可以含斜切端等额外外形节点，但这些节点不得被误认成折弯站点。

出现以下任一情况时拒绝当前零件，不退回整板统一缩放：

- 两条板面路径无法唯一配对；
- 剖面路径在 X 方向回折；
- 一个剖面转折对应零个或多个主视图站点；
- 相邻站点顺序或区间跨度不一致；
- 分段中性层长度之和与 `A_section / t` 的差超过 `0.1 mm`。

## K=0.5 展开长度

K=0.5 的中性层位于恒厚剖面的厚度中面。设剖面材料面积为 `A_section`、名义厚度为 `t`，中面长度为：

```text
L_K = A_section / t
```

对恒厚带，该式与两侧完整板面路径平均值 `(L₁ + L₂) / 2` 等价，同时不会把斜切端或复合端链误计为板面长度。`A_section` 由可追溯原生线弧以最大 `0.001 mm` 弦高误差建立的 Shapely 材料区域计算；该误差远小于最终 `0.1 mm` 上取整粒度，并在报告中记录证明方法。

对第 `i` 个已匹配剖面区间，设两侧板面在该区间内的原生路径长度为 `lᵢ₁`、`lᵢ₂`，中性层区间长度和 X 投影跨度分别为：

```text
nᵢ = (lᵢ₁ + lᵢ₂) / 2
pᵢ = xᵢ₊₁ - xᵢ
```

只对正的中性层差值形成转折补偿。每个补偿量独立使用十进制 `ROUND_CEILING` 向上取到 `0.1 mm`：

```text
eᵢ_raw = max(0, nᵢ - pᵢ)
eᵢ = 0                              if eᵢ_raw = 0
eᵢ = ceil(eᵢ_raw × 10) / 10         if eᵢ_raw > 0
```

实现必须使用 `Decimal(str(value))` 做十进制上取整，不设置向下吸附阈值。因此 `470.0` 保持 `470.0`，而 `470.0000001` 必须得到 `470.1`。

主视图投影跨度为 `L_projection`，材料表长度为 `L_bom`。分段补偿后的候选总长和最终目标为：

```text
L_segmented = L_projection + Σeᵢ
L_raw = max(L_segmented, L_K, L_bom)
L_target = ceil(L_raw × 10) / 10
```

由于每个正补偿量和最终总长各执行一次上取整，理论值之外的增加量严格小于“正补偿区间数量加一”乘以 `0.1 mm`。不再叠加切割余量、焊接余量或安全余量。

若 `L_target - L_projection` 大于 `Σeᵢ`，差额称为总长余量。总长余量全部加入最右侧的正补偿区间；若没有正补偿区间，则加入已确认站点序列的最右侧纵向区间。这样材料表或最终十分位要求不会再次改动已经量好的其他转折。站点序列本身存在歧义时按前述输入合同拒绝当前零件。

## 逐转折分段展开

主视图最左端 `x_min` 为固定锚点。设源站点为 `x₀...xₙ`，分配到第 `i` 个区间的最终增量为 `Eᵢ`，展开后站点递推为：

```text
x'₀ = x₀
x'ᵢ₊₁ = x'ᵢ + (xᵢ₊₁ - xᵢ) + Eᵢ
```

区间内部使用连续的局部等比 X 映射：

```text
scaleᵢ = ((xᵢ₊₁ - xᵢ) + Eᵢ) / (xᵢ₊₁ - xᵢ)
x' = x'ᵢ + (x - xᵢ) × scaleᵢ
y' = y
```

没有补偿的区间 `scaleᵢ=1`，其几何长度和形状保持不变，只接受前序增量产生的整体 X 平移。所有 `scaleᵢ >= 1`，所以任何区间都不会缩短。`q7-b-404` 的前部长直段和后部直段保持原尺寸，仅中间斜转折区间增加 X 投影，后部直段整体右移。

跨越站点的外边界实体必须先在精确站点处切分，再分别应用所在区间的仿射变换。`LINE` 片段仍为 `LINE`；局部非等轴缩放后的 `ARC` 或带 bulge 弧段写为精确 `ELLIPSE`；未拉伸的曲线保留原生类型。不把椭圆重新拟合成圆弧。站点上的公共端点只能生成一个一致坐标，不允许出现缝隙或重叠。

Shapely 以最大 `0.01 mm` 弦高误差复核变换后的闭合性、有效性和各站点区间尺寸。输出实体数量允许因站点切分增加，保存后验证以几何合同为准，不再要求与源实体一一同数。

## 单件结果 DXF

每个成功零件输出 `<零件号>.dxf`。输出是新建的 R2007、毫米、1:1 DXF，不复制源图框。

图层合同为：

| 图层 | 颜色 | 内容 |
|---|---:|---|
| `PLATE_CUT` | ACI 7 | 闭合制造外边界的 `LINE`/`ELLIPSE` 原生实体 |
| `PART_LABEL` | ACI 3 | 唯一 `TEXT`，内容为 `p=<零件号>` |
| `SPLIT_NOTE` | ACI 5 | 仅保留与 BH/BOX 相同的图层表兼容项，不写制造实体 |

`PART_LABEL` 使用现有 `SplitChinese` 样式，字高固定为 `30 mm`，并通过 `part_mark_layout` 放在材料区域内不与边界相交的位置。布局不得把字高放大；若 `30 mm` 标签无法完整放入材料区域，则拒绝当前零件，不输出越界标签。

结果不包含 `DrawingSheet`、`Z-DIMENSIONS`、`Section`、图片、尺寸、剖面、材料表、标题栏或完整折弯线。

保存前后均执行以下验证：

- 目标长度与保存后外轮廓 X 跨度差不超过 `0.001 mm`；
- 保存后板宽与源主视图板宽差不超过 `0.001 mm`；
- 左端位置差不超过 `0.001 mm`；
- 每个无补偿区间的源尺寸保持不变，每个补偿区间达到对应目标，误差不超过 `0.001 mm`；
- 边界闭合、有效、无自交且面积为正；
- `PART_LABEL` 恰好一个、文本完全匹配且字高为 `30 mm`；
- ezdxf 重新读取与 `audit()` 无错误；
- 不含 `REGION`、`XLINE`、`RAY` 或源图说明实体。

## 事务、覆盖和退出码

PL 拆板工具先在输出目录内的临时任务目录写入，完成重新读取和验证后再原子发布。默认不覆盖已有正式文件；显式 `--overwrite` 只允许替换工具拥有的精确目标文件，不能清空输出目录。

`steel-dxf-split-pl` 的退出码：

- `0`：全部单件成功并发布；
- `1`：至少一个单件被拒绝，但其余成功项和完整报告已发布；
- `2`：输入合同、目录边界或整个 DXF 无法读取，未形成可审计任务。

## 报告

拆板报告逐件记录：

- 零件号、厚度、板宽和材料表长度；
- 主视图及剖面候选数量和最终源句柄；
- `L_projection`、两条完整板面路径长度、`L_K`、`L_bom`、`L_segmented`、`L_raw`、`L_target`；
- 每个剖面区间的源站点、两侧路径长度、`nᵢ`、`pᵢ`、原始补偿、上取整补偿、主视图对应区间和最终累计站点；
- 每个区间的 `scaleᵢ`、总长余量接收区间、锚点、源实体与输出实体类型计数；
- Shapely 与 ezdxf 验收结果；
- 成功输出路径或明确拒绝代码及中文说明。

报告不保存源 DXF 字节，不把材料表或完整源文字复制到结果 DXF。

## 测试策略

实现遵循测试驱动流程，先运行并观察正确失败的测试，再写生产代码。

### 单元测试

- K=0.5 恒厚中性层：`L_K=A_section/t`，并验证它与两板面平均长度的等价关系。
- 分段补偿候选长、K 展开长和材料表长度三者取最大值。
- 已在十分位上的长度不增加；超过十分位的任意正余量只增加到下一个 `0.1 mm`。
- 严格禁止向下吸附：`470.0 → 470.0`，`470.0000001 → 470.1`。
- 两侧板面逐区间 K=0.5 计算、正补偿分别向上取整，并与 `A_section/t` 总证明交叉验证。
- 唯一站点匹配、歧义站点拒绝和 X 向回折剖面拒绝。
- `scaleᵢ >= 1`、左端固定、板宽不变；无补偿区间只平移不拉伸。
- 多转折轮廓只拉伸对应转折区间，后续站点按前序增量累计顺移。
- 跨站点直线或曲线正确切分；直线保持直线，局部非等轴拉伸后的圆弧成为精确椭圆。
- 唯一 `p=` 标签生成与规范化。
- 主视图、剖面、孔槽、多轮廓和歧义候选的接纳/拒绝边界。
