# PL 折弯板拆板设计

## 目标

新增与 BH/BOX 运行路径隔离的 PL Python 核心，并由单独的 `steel-dxf-split-pl` 启动包提供命令：把 Tekla PL 折弯板投影视图转换为一块连续的 1:1 展开板，并逐件生成可审计的结果 DXF。

PL 核心使用 `ezdxf==1.4.4` 读写和变换原生 DXF 实体，使用 `Shapely>=2.1,<3` 重建、选择和验证二维轮廓。DWG 与 DXF 之间的转换继续使用仓库已有 `dwg2dxf`、`dxf2dwg` Stage；PL 工具本身不直接读取或写入 DWG。

## 已确认的业务规则

- 一个折弯 PL 原件展开后仍是一块连续板，不按折弯线拆成多块。
- K 因子固定为 `0.5`。
- 板材总长不允许缩短；只允许增加覆盖投影、K=0.5 和材料表证据并完成一次十进制上取整所需的最小长度，不叠加任意余量。
- 不按整板总长统一缩放。每个转折区间都要测量，但全部总增量只加入自动识别出的唯一承载区间，后续区间整体顺移；板宽方向不缩放。
- 分段非等轴拉伸后的圆弧允许精确写为 DXF `ELLIPSE`。
- 只对最终总长度执行一次小数点后一位严格向上取整，最小长度粒度为 `0.1 mm`；任何正余量都不得向下吸附，逐段测量不再分别取整。
- 结果零件标记带 `p=` 前缀，例如 `p=q4-b-181`。
- PL 单件输出沿用 BH/BOX 的生产图层命名：制造外轮廓位于 `PLATE_CUT`，零件标记位于 `PART_LABEL`。
- PL 不生成 BH/BOX 的“正常拆板/余量增长”双产物，也不执行焊接余量逻辑。

## 现有实现与复用边界

仓库现有 BH 与 BOX 核心已经提供以下可复用能力：

- `steel_dxf_split.dxf_io`：DXF 审计读取、CAD 文字传输解码、嵌套 `INSERT` 递归展开。
- BH/BOX writer：R2007、毫米单位、清洁制造图层、中文字体、保存后审计和确定性写图模式。
- `part_mark_layout`：在有效材料区域内放置零件标记。

现有统一 `pipeline.py` 只接受冻结分类 `BH` 或 `BOX`，并强制生成普通版与余量版配对结果。PL 的单板、单产物合同与该入口不兼容。本次不把 PL 塞入 BH/BOX 统一入口，不修改 BH/BOX 制造几何、余量、发布认证、后端工作流或现有合图脚本。PL 拆板核心位于 `steel_dxf_split/pl/`，命令由单独的 `Stages/steel_dxf_split_pl` 轻量启动包提供；原 BH/BOX `pyproject.toml` 和 `steel-dxf-split` 入口保持不变。

## 方案选择

### 方案 A：新增完全独立的 PL 拆板模块（采用）

在 `steel_dxf_split/pl/` 中隔离源图解释、几何展开和写图，不让 PL 规则进入 BH/BOX 核心。

优点是业务合同清楚、测试范围可控，并允许以后单独把 PL 接入生产工作流。代价是本次不会自动改变当前后端只接纳 BH/BOX 的路由。

### 方案 B：直接把 PL 加入统一 BH/BOX `pipeline.py`（不采用）

该方案会同时改变分类清单、source contract、双产物验收、后端持久化、选择性导出和前端展示。PL 当前没有焊接余量双产物，强行复用会制造错误合同。

### 方案 C：只按总长度统一缩放主视图（不采用）

该方案即使能得到正确总长，也会把增量错误均摊到无关直段。现有参考集同时包含首段、中段和末段需要补偿的板件；例如 `q7-b-404` 只增加中间斜转折的 X 投影，而其他板件的补偿区间位于不同位置。因此统一缩放不能满足整批板件的逐转折尺寸合同。

## 模块结构

新增模块保持职责单一：

- `pl/contracts.py`：冻结输入、源证据、展开结果和输出结果数据结构。
- `pl/source.py`：读取 DXF、展开图框块、提取文字、解析零件号及 `PL厚度*宽度`、建立单件源上下文。
- `pl/geometry.py`：把 `Part` 图层原生线弧转换为 Shapely 拓扑，识别主视图纵向边界链、转折站点、唯一增量承载区间和剖面厚度带。
- `pl/development.py`：由整段 K=0.5 证明计算一次严格十进制总目标，把全部总增量映射到承载区间，并在站点处切分跨区间实体。
- `pl/writer.py`：只从已验证的展开结果生成清洁 PL DXF，并执行保存后复核。
- `pl/compiler.py`：编排一个零件的源解释、展开、验证和写图事务。
- `pl/cli.py`：批量处理单张、合并图或输入目录，发布结果及拆板报告。
- `Stages/steel_dxf_split_pl`：只注册 `steel-dxf-split-pl` 命令并转发到 PL CLI，不导入 BH/BOX 入口。

## PL 源输入合同

### 文件格式

`steel-dxf-split-pl` 接受：

- 一张单零件 DXF；
- 一张由多个顶层图框 `INSERT` 组成的合并 DXF；
- 一个目录第一层中的多张 DXF。

输入与输出目录不能相同或互相嵌套。目录扫描在处理开始前冻结，只处理第一层 `.dxf` 文件，不把运行中新生成的文件重新当成输入。

### 单件边界

合并 DXF 中，每个能够独立证明零件号、PL 规格和制造视图的顶层图框块形成一个单件源上下文。单张 DXF 若没有这种顶层图框集合，则模型空间整体形成一个单件上下文。

所有嵌套 `INSERT` 使用 `recursive_virtual_entities()` 展开并应用完整实例变换。源实体句柄、容器块句柄、原始图层和文字坐标进入报告，用于追溯，但不进入结果制造图。

### 元数据

每个单件必须唯一提取：

- 规范化零件号；
- `PL厚度*宽度` 中的厚度和板宽；
- 材料表长度；
- `Part` 图层制造视图。

零件号字段若带 `p=`，解析时去掉前缀形成内部规范化编号；结果 `PART_LABEL` 再统一写回 `p=<编号>`。当前语料中的裸 `PartMark` 和图框块名可作为同一编号的交叉证据，但冲突时不按文件名猜测，直接拒绝该零件。

材料表存在多行 PL、多个不同长度或无法唯一绑定当前零件时，当前零件进入拒绝结果。

## 主视图与剖面识别

### Shapely 拓扑

只把源 `Part` 图层的制造线弧用于候选轮廓。尺寸、剖面标记、图框、图片、HATCH、`OtherObjectType` 和说明文字不参与制造边界。

原生 `LINE`、`ARC`、`ELLIPSE` 和多段线以最大 `0.01 mm` 弦高误差转换为 Shapely 线网。端点在 `0.1 mm` 内允许拓扑吸附；吸附只用于识别和验证，输出仍由源原生实体及精确变换生成。

每个连接分量执行 `polygonize_full`。内部折弯投影线可以把一个面分成多个子面，子面在同一连接分量内重新 `unary_union` 为材料区域；悬线、无法解释的切线和多余闭环保留为诊断，不进入结果外边界。

### 主视图

主视图候选必须同时满足：

- 存在唯一有效外轮廓；
- 横向实际跨度与 PL 名义板宽一致，误差不超过 `0.1 mm`；
- 具有明确的长度主轴；
- 外轮廓面积为正且无自交；
- 同一单件中没有第二个同等可信的板宽投影。

主视图长度轴规范化为从最小 X 到最大 X。当前版本不旋转任意方向的制造视图；若唯一主轴不是图纸 X 方向，拒绝并在报告中记录，避免改变已经确认的左端锚定合同。

完整内部折弯投影线不作为切割线。当前版本只自动发布唯一外轮廓；主视图存在孔槽、多个内轮廓或多个不连通板体时拒绝，不推断未被 21 组样例证明的孔槽展开规则。

### 剖面厚度带

主视图之外的 `Part` 材料区域用于寻找剖面厚度带。候选必须能够证明：

- 一个闭合、有效、恒定厚度的带状区域；
- 剖面 X 投影跨度与主视图投影跨度一致，误差不超过 `0.1 mm`；
- 材料面积为正且没有孔槽；
- 组成剖面的原生线弧及其拓扑吸附关系能够追溯。

真实语料中的剖面端部既有单条板厚边，也有斜切端和多段复合端链。因此端部不强制退化成两条长度恰好等于板厚的直线。若不存在唯一剖面、存在多个同等候选或路径断裂超过拓扑容差，则拒绝该零件。

### 转折站点与增量承载区间

主视图外边界先按拓扑分解为从左到右的两条纵向边界链及连接两条边界链的端部链。纵向边界链可以由多条 `LINE`、`ARC` 或 `ELLIPSE` 组成；端部斜切、圆角和小凸台属于端部链，不得误当成长度承载区间。

站点序列固定以外轮廓 `x_min` 开始、以 `x_max` 结束。中间站点来自两条纵向边界链的方向变化、连接关系变化以及能够横贯材料宽度的内部折弯投影线。上下边界的转折端点因板厚、斜接或绘图表达可以有小范围 X 偏移，因此一个站点允许表示为包含两条边界端点的“站点带”；站点带的 X 宽度不得超过名义板厚加 `0.1 mm`。区间按拓扑顺序配对，不要求两个端点 X 完全相等。内部折弯投影线只用于定位，仍不写入 `PLATE_CUT`。

相邻站点带之间形成有序主体区间。承载区间按同一套特征规则自动选择：

1. 优先寻找两条纵向边界在同一 X 重叠范围内共同发生可复核 Y 方向变化的主体区间；两条边界各自的端点 Y 差绝对值都必须超过 `0.001 mm`。相邻的同一转折碎片合并为一个承载区间。
2. 若没有可见转向，则在排除端部链、小凸台和短收口后，选择 X 投影唯一最长的主体区间；最长与次长的差不超过 `0.1 mm` 时视为并列。
3. 只有一个纵向主体区间时，该区间自然成为承载区间。
4. 存在多个不相邻候选、最长区间并列或上下边界无法唯一配对时拒绝当前零件，不退回整板统一缩放，也不按零件号猜测。

当前 21 件验收语料必须都能由该规则得到唯一承载区间。该区间可以位于首部、中部或尾部；其他所有区间虽然不增长，仍必须逐段测量并在输出后验证尺寸保持。

## K=0.5 展开长度

K=0.5 的中性层位于恒厚剖面的厚度中面。设剖面材料面积为 `A_section`、名义厚度为 `t`，中面长度为：

```text
L_K = A_section / t
```

对恒厚带，该式与两侧完整板面路径平均值 `(L₁ + L₂) / 2` 等价，同时不会把斜切端或复合端链误计为板面长度。`A_section` 由可追溯原生线弧以最大 `0.001 mm` 弦高误差建立的 Shapely 材料区域计算；该误差远小于最终 `0.1 mm` 上取整粒度，并在报告中记录证明方法。

剖面只负责证明整块板的 K=0.5 中性层总长，不把两条偏置板面在局部站点处的长度差直接当成逐段补偿。板厚斜接会使相邻板面端点发生 X 偏移；逐段把正差截取并分别上取整会丢掉相邻负差的抵消关系，造成板材过长。

主视图投影跨度为 `L_projection`，材料表长度为 `L_bom`。最终目标只计算和上取整一次：

```text
L_raw = max(L_projection, L_K, L_bom)
L_target = ceil(L_raw × 10) / 10
E_total = L_target - L_projection
```

实现必须使用 `Decimal(str(value))` 和十进制 `ROUND_CEILING`，不设置向下吸附阈值。因此 `470.0` 保持 `470.0`，而 `470.0000001` 必须得到 `470.1`。`L_target` 相对三种长度证据最大值的增加严格小于 `0.1 mm`；不再叠加切割余量、焊接余量、安全余量或逐段取整余量。

`q7-b-404` 的已验证数据为 `L_projection=1154.065614 mm`、`L_K=1162.124078 mm`、`L_bom=1162.0 mm`，所以 `L_target=1162.2 mm`、`E_total=8.134386 mm`。逐段截取正差会错误得到约 `10.2 mm` 补偿，本设计明确禁止这种累计过长结果。

## 逐转折分段展开

主视图最左端 `x_min` 为固定锚点。唯一承载区间左侧的全部几何保持原坐标；承载区间右侧的全部几何统一平移 `E_total`。承载区间两条纵向边界链各自以左站点带为锚点，把自身 X 投影跨度增加同一个 `E_total`：

```text
scale_carrier = (carrier_span + E_total) / carrier_span
x' = carrier_start + (x - carrier_start) × scale_carrier
y' = y
```

上下边界因斜接可能具有略有差异的 `carrier_start` 和 `carrier_span`，两条链分别使用自己的源跨度，但右站点带的所有拓扑节点最终都增加同一个 `E_total`。连接同一站点带的短边、圆角或复合链作为一个节点组共同变换，不能产生厚度错位。

承载区间以外的每个转折跨度和形状保持不变：左侧既不拉伸也不平移，右侧只平移不拉伸。`q7-b-404` 因此只把中间斜转折的 X 投影增加 `8.134386 mm`，前后直段尺寸保持，后部整体右移同样的增量。

跨越站点带的外边界实体必须先在精确拓扑位置切分，再分别应用所在区域的仿射变换。`LINE` 片段仍为 `LINE`；局部非等轴缩放后的 `ARC` 或带 bulge 弧段写为精确 `ELLIPSE`；未拉伸的曲线保留原生类型。不把椭圆重新拟合成圆弧。站点带上的公共节点只能生成一个一致坐标，不允许出现缝隙或重叠。

Shapely 以最大 `0.01 mm` 弦高误差复核变换后的闭合性、有效性和各站点区间尺寸。输出实体数量允许因站点切分增加，保存后验证以几何合同为准，不再要求与源实体一一同数。

## 通用性与禁止样例特判

### 从一个样例归纳一类板件

`q7-b-404` 用于发现通用几何不变量，不作为坐标模板。它揭示的类特征是：整段剖面负责确定 K=0.5 总目标；主视图两条纵向边界链形成有序站点和主体区间；唯一承载区间吸收全部总增量；其右侧全部站点统一顺移。承载区间位于首部、中部或尾部，只是同一特征算法的不同数据，不是不同代码分支。

每张新图都先提取同一种区间特征：

```text
(区间顺序, 上下纵向边界片段, 站点带, X 投影跨度,
 Y 方向变化, 是否属于端部链, 主体跨度排名, 是否为承载区间)
```

随后仅根据这些拓扑和尺寸特征选择承载区间，再把 `E_total` 一次性加入该区间。算法不需要预先知道零件属于哪一张参考图，也不需要人为指定“该拉长第几段”。

所有区间、补偿量和累计站点必须从当前零件自己的主视图、剖面、板厚、材料表和 K=0.5 证据计算。生产模块禁止按零件号、文件名、块名、实体句柄、样例坐标或参考图增量建立条件分支或查找表。零件号只用于输出文件名、`p=` 标签和报告关联，不参与几何决策。

同一条处理链必须覆盖提供的全部 21 个板件，包括承载区间位于首部、中部、尾部以及只有一个纵向主体区间的情况。某个新输入若存在多个不相邻的同等承载候选或无法形成上述类特征，可以按输入合同拒绝；但当前 21 个验收板件不得因实现只支持 `q7-b-404` 的具体坐标或实体排列而跳过或降级为统一缩放。

参考结果只作为离线验收证据，用于确认每张板“哪些区间保持、哪些区间增长以及下游如何顺移”。参考坐标不得进入运行时代码；补偿数值仍由当前零件的 K=0.5、材料表和严格 `0.1 mm` 上取整规则决定。

## 单件结果 DXF

每个成功零件输出 `<零件号>.dxf`。输出是新建的 R2007、毫米、1:1 DXF，不复制源图框。

图层合同为：

| 图层 | 颜色 | 内容 |
|---|---:|---|
| `PLATE_CUT` | ACI 7 | 闭合制造外边界的 `LINE`/`ELLIPSE` 原生实体 |
| `PART_LABEL` | ACI 3 | 唯一 `TEXT`，内容为 `p=<零件号>` |
| `SPLIT_NOTE` | ACI 5 | 仅保留与 BH/BOX 相同的图层表兼容项，不写制造实体 |

`PART_LABEL` 使用现有 `SplitChinese` 样式，字高固定为 `30 mm`，并通过 `part_mark_layout` 放在材料区域内不与边界相交的位置。布局不得把字高放大；若 `30 mm` 标签无法完整放入材料区域，则拒绝当前零件，不输出越界标签。

结果不包含 `DrawingSheet`、`Z-DIMENSIONS`、`Section`、图片、尺寸、剖面、材料表、标题栏或完整折弯线。

保存前后均执行以下验证：

- 目标长度与保存后外轮廓 X 跨度差不超过 `0.001 mm`；
- 保存后板宽与源主视图板宽差不超过 `0.001 mm`；
- 左端位置差不超过 `0.001 mm`；
- 承载区间的 X 投影只增加 `E_total`，其余每个区间的源跨度保持不变，误差不超过 `0.001 mm`；
- 边界闭合、有效、无自交且面积为正；
- `PART_LABEL` 恰好一个、文本完全匹配且字高为 `30 mm`；
- ezdxf 重新读取与 `audit()` 无错误；
- 不含 `REGION`、`XLINE`、`RAY` 或源图说明实体。

## 事务、覆盖和退出码

PL 拆板工具先在输出目录内的临时任务目录写入，完成重新读取和验证后再原子发布。默认不覆盖已有正式文件；显式 `--overwrite` 只允许替换工具拥有的精确目标文件，不能清空输出目录。

`steel-dxf-split-pl` 的退出码：

- `0`：全部单件成功并发布；
- `1`：至少一个单件被拒绝，但其余成功项和完整报告已发布；
- `2`：输入合同、目录边界或整个 DXF 无法读取，未形成可审计任务。

## 报告

拆板报告逐件记录：

- 零件号、厚度、板宽和材料表长度；
- 主视图及剖面候选数量和最终源句柄；
- `L_projection`、两条完整板面路径长度、`L_K`、`L_bom`、`L_raw`、`L_target` 和 `E_total`；

## 测试策略

实现遵循测试驱动流程，先运行并观察正确失败的测试，再写生产代码。

### 单元测试

- K=0.5 恒厚中性层：`L_K=A_section/t`，并验证它与两板面平均长度的等价关系。
- 投影总长、整段 K 展开长和材料表长度三者取最大值，并且只对最终总长取整一次。
- 已在十分位上的总长度不增加；超过十分位的任意正余量只增加到下一个 `0.1 mm`。
- 严格禁止向下吸附：`470.0 → 470.0`，`470.0000001 → 470.1`。
- `q7-b-404` 数值回归：目标总长 `1162.2 mm`、总增量约 `8.134386 mm`，不得得到逐段正差累计产生的约 `10.2 mm`。
- 两条纵向边界链、站点带和主体区间的唯一拓扑提取；端部斜切、小凸台和圆角不误判为承载区间。
- 有共同 Y 方向变化时选择唯一转折主体；无可见转向时选择排除端部链后的唯一最长主体；多候选和并列候选拒绝。
- 左端固定、板宽不变；承载区间增加全部 `E_total`，左侧不动，右侧只平移不拉伸。
- 分别覆盖承载区间位于首部、中部、尾部和唯一主体区间的程序化测试，证明同一特征提取和站点算法能够由一个结构推广到整类板件，且不依赖零件号。
- 跨站点直线或曲线正确切分；直线保持直线，局部非等轴拉伸后的圆弧成为精确椭圆。
- 唯一 `p=` 标签生成与规范化。
- 主视图、剖面、孔槽、多轮廓和歧义候选的接纳/拒绝边界。
