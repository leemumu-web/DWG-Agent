# 删除 Excel Final RECT 业务设计

## 目标

Excel Final 不再计算、判断、输出或报告 RECT。规范六表中的 `part` 表继续保留“文件”列以兼容既有表结构，但所有数据行的该列固定为空。

## 范围

- 删除 `RectDecision`、普通板 RECT 推断、拆板 RECT 推断及 RECT 专属质量问题。
- 删除 part 候选和最终行模型中的 `file_value` 业务字段。
- writer 仍输出“文件”表头，数据单元格固定为空。
- 删除 RECT 专属测试，改为验证所有 part 行“文件”为空且报告中不存在 RECT 类别。
- 更新流程文档、GT 回归和对比报告规则，使其描述新的固定留空合同。

## 保留行为

RECT 删除不改变以下安全规则：

- 构件编号或身份冲突仍阻止不可信 part 输出。
- 拆板没有合法子板时仍不输出对应子板 part。
- 严重重量异常仍阻止对应 part 输出。
- 合法的普通板、扁钢和拆板子板仍进入 part；班组和图形字段维持现有来源规则。

这些规则从 RECT 决策中解耦，作为明确的 part 准入条件保留。

## 数据流

规范读取和分类 → 五金手册与重量核验 → 规范拆板 → part 准入与汇总 → writer 固定写空“文件”列。

处理报告只记录仍有效的输入、手册、重量、身份、拆板和聚合问题，不再产生 `RECT未证明` 或 `RECT证据冲突`。

## 验收

- 源码和文档中不存在生产 RECT 判断逻辑。
- 任意规范结果的 `part` 表“文件”列全部为空。
- 当前真实样本仍产生 485 条父件、46 个构件、527 条整理记录和 478 条 part。
- 当前真实样本原有 198 条 RECT 信息消失；无其他问题时处理报告为 0 条，质量状态为 `ok`。
- Stage、真实 GT、真实 MySQL 手册、后端导入和真实上传下载链路全部通过。
