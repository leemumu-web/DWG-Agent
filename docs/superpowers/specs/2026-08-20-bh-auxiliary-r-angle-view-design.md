# BH 制造视图与 R 角详图分离设计

## 目标

修复 ODA/DXF 中 R 角放大详图被误当成第二套制造视图的问题，同时明确可见线、隐藏线和引出线的语义，保持 BH 核心拆板、孔识别、余量和翼板长度判断不变。

## 已确认的源图语义

- `Part` 层的 `XKITLINE00`（颜色 4，蓝色）是可见制造轮廓。
- `Part` 层的 `XKITLINE04`（颜色 7，白色）是同一板件被遮挡的边/内侧 R 角证据，不独立生成板件边界。
- `Bolt` 层的圆和中心线仍由现有孔识别流程处理。
- `OtherObjectType` 与图层 `0` 中的引出线、文字和图框装饰是说明性图元，不参与板材轮廓。
- 183 ODA 转换结果中，图框外的 `*A52/*A55` 是 R 角放大详图，复制了主翼板/腹板的 Part 轮廓；它们不是新增板材。
- 图纸中的 `1:20` 是标注/打印比例，DXF 几何和 `$INSUNITS=4` 已经是制造单位，不能对制造几何再做视觉缩放。

## 方案选择

### 方案 A：放宽 Part 层，将所有蓝/白线一起 polygonize

不采用。会把隐藏边和详图线混入实体边界，正是当前错误的根源，且会改变 R 角、端部坡口和孔邻接关系。

### 方案 B：按固定坐标或固定视图数量删除详图

不采用。183 的详图位于图框外，但其它图纸的视图布局和上/下翼板长度会变化；固定坐标、固定长度或固定“两个视图”会过拟合。

### 方案 C：图框边界 + 几何等价的辅助视图判定（采用）

在 BH 视图区域构建完成后：

1. 从规范化后的 `DrawingSheet` 图元求图框包围盒。
2. 将 Part 视图分为图框内和图框外。图框内视图始终保留，不依赖长度、角色或视图数量。
3. 对每个图框外视图，仅当其 Part 几何在小于 0.01 mm 的几何容差内与一个唯一的图框内几何等价类对应时，标为 `auxiliary_detail`，不进入制造候选；不等价或存在多个可能对应类的视图继续走现有候选/审查流程，不静默丢弃。
4. 几何等价比较使用平移归一化后的线/弧类型、可见/隐藏语义、端点、圆心、半径和闭合属性；不比较源句柄、插入坐标或文字，因而不依赖某一张图的长度数值。角度的小数噪声通过端点/圆心的几何容差处理。
5. 被标记的辅助视图保留在 `RegionBuildResult.auxiliary_views` 和编译 trace 中，源 IR 仍完整保留；只有制造候选和 lowering 不消费它们。

## 数据流影响边界

- `solid_part_entities`、`source_arcs`、孔识别和余量逻辑不改规则；蓝色轮廓仍是实体来源，隐藏 R 弧仍只能在源边界证据匹配时恢复。
- `build_view_regions` 增加辅助视图分离结果；`materialize_lowering_ir`、假设求解和制造 IR 只读取过滤后的 `part_views`。
- 不引入上翼板、腹板、下翼板的固定长度关系；不同长度和不同端部坡口仍由各自图框内视图、尺寸标注及现有投影证据决定。
- 详图不参与图形关联中的制造视图节点；其源实体仍可审计，且 trace 明确记录被排除原因。

## 测试与验收

先写失败测试，再实现：

1. 183 ODA DXF：编译自动通过，制造候选恢复为主腹板/翼板两视图；辅助详图数量为 2；制造 IR 的板角色、长度、R 角弧段和孔数量与当前主图结果一致。
2. 195 原始 DXF：编译仍自动通过；腹板长度约 7790 mm、腹板 42 个孔、翼板 7790×300 mm、R=35 弧段和板角色不变。
3. 合成回归：两组图框内视图长度不同、图框外复制其中一组时，只排除复制组；另一组不因长度差异被合并或删除。
4. 运行现有 BH 相关 pytest，随后对 183/195 以及既有目标图纸做真实 CLI 回归；若出现非辅助视图的板数、孔数、角色、R 角或长度变化，停止并修正，不扩大修改范围。

## 非目标

本次不修改 BOX 算法、不修改前端/数据库/打包、不改变比例缩放策略、不重写孔距和余量规则，也不把说明性引出线转换成制造几何。
