# BH 制造视图与 R 角详图分离设计

## 目标

修复 DXF 中 R 角放大详图被误当成第二套制造视图的问题，同时明确可见线、隐藏线和引出线的语义，保持 BH 核心拆板、孔识别、余量和翼板长度判断不变。DWG/ODA 转换不属于本次范围。

## 已确认的源图语义

- `Part` 层的 `XKITLINE00`（颜色 4，蓝色）是可见制造轮廓。
- `Part` 层的 `XKITLINE04`（颜色 7，白色）是同一板件被遮挡的边/内侧 R 角证据，不独立生成板件边界。
- `Bolt` 层的圆和中心线仍由现有孔识别流程处理。
- `OtherObjectType` 与图层 `0` 中的引出线、文字和图框装饰是说明性图元，不参与板材轮廓。
- DXF 中的图框外或非制造区域的重复 Part 轮廓只能作为辅助几何；它们不是新增板材。
- 图纸中的 `1:20` 是标注/打印比例，DXF 几何和 `$INSUNITS=4` 已经是制造单位，不能对制造几何再做视觉缩放。

## 方案选择

### 方案 A：放宽 Part 层，将所有蓝/白线一起 polygonize

不采用。会把隐藏边和详图线混入实体边界，正是当前错误的根源，且会改变 R 角、端部坡口和孔邻接关系。

### 方案 B：按固定坐标或固定视图数量删除详图

不采用。183 的详图位于图框外，但其它图纸的视图布局和上/下翼板长度会变化；固定坐标、固定长度或固定“两个视图”会过拟合。

### 方案 C：图框边界 + 几何等价的辅助视图判定（采用）

在 BH 视图区域构建完成后：

1. 从规范化后的 `DrawingSheet` 图元求图框包围盒。
2. 将 Part 视图分为图框内和图框外。图框内视图始终保留，不依赖长度、角色或视图数量。
3. 对每个图框外视图，仅当其 Part 几何在小于 0.01 mm 的几何容差内与一个唯一的图框内几何等价类对应时，标为 `auxiliary_detail`，不进入制造候选；不等价或存在多个可能对应类的视图继续走现有候选/审查流程，不静默丢弃。
4. 几何等价比较使用平移归一化后的线/弧类型、可见/隐藏语义、端点、圆心、半径和闭合属性；不比较源句柄、插入坐标或文字，因而不依赖某一张图的长度数值。角度的小数噪声通过端点/圆心的几何容差处理。
5. 被标记的辅助视图保留在 `RegionBuildResult.auxiliary_views` 和编译 trace 中，源 IR 仍完整保留；只有制造候选和 lowering 不消费它们。

## 数据流影响边界

- `solid_part_entities`、`source_arcs`、孔识别和余量逻辑不改规则；蓝色轮廓仍是实体来源，隐藏 R 弧仍只能在源边界证据匹配时恢复。
- `build_view_regions` 增加辅助视图分离结果；`materialize_lowering_ir`、假设求解和制造 IR 只读取过滤后的 `part_views`。
- 不引入上翼板、腹板、下翼板的固定长度关系；不同长度和不同端部坡口仍由各自图框内视图、尺寸标注及现有投影证据决定。
- 详图不参与图形关联中的制造视图节点；其源实体仍可审计，且 trace 明确记录被排除原因。

## 翼缘两侧短差判定（本轮新增）

`0.5% * nominal_length` 不能作为“上下翼缘相同”的判据。对长度约
7790 mm 的图纸，它会吞掉 20--38 mm 的真实差异；`a1-4-cb-183` 的源课程为
`7790.001 / 7766.001`，`a1-4-cb-195` 为 `7790 / 7770`，二者当前都被错误合并。

采用以下小范围规则：

1. 只承认 `_source_backed_main_flange_side_spans` 找到的两条完整、同侧成对、
   有至少 80% 重叠的源课程；单条线、断线或孤立 R 角线不能产生板件。
2. 对已通过上述成对证明的两侧，使用固定的毫米级几何容差判断是否不同，
   不再按构件名义长度放大容差。容差取现有制造容差与 1 mm 显示/导出噪声的较大值。
   这允许把少量实际上相同的板拆成两个数量为 1 的板，但不允许把真实的 20--35 mm
   差异合并成数量为 2。
3. `select_flange_polygons` 已判定为 `projection_artifact` 的装配投影仍不作为
   平板长度证据；例如 `cb-117` 的 `7565` 是投影端部阶差，继续采用其已验证的
   `7600` 平板包络。该判断只依赖几何和源边界守恒，不依赖文件号或固定坐标。
4. 源课程证据与面选择冲突时，保留源实体和诊断，优先走现有审查/证明路径，
   不静默覆盖已有板件、孔或余量逻辑。

实现时同步替换 extractor 与 development 中的同一差异判据，避免前一阶段
“认定不等长”、后一阶段又按 `0.5%` 合并的分裂逻辑。

## 测试与验收

先写失败测试，再实现：

1. `a1-4-cb-183` DXF：两套翼缘目标长度分别约为 `7766 / 7790`，不再输出一个数量为 2 的翼缘。
2. 195 原始 DXF：编译仍自动通过；腹板长度约 7790 mm、腹板 42 个孔、翼板 7790×300 mm、R=35 弧段和板角色不变。
3. `cb-117` 回归：投影伪影仍不被当成短翼缘，平板长度保持约 `7600 / 7600`（即使内部数量表达被拆开也不得改变长度）。
4. 既有等长 `cb-61..66` 与已知不等长 `cb-27/29/55/56/68` 回归不退化。
5. 扫描 `/home/Creeken/Downloads/原DXF` 的可编译样本，列出所有从数量 2 变成两套翼缘的文件及长度；对 326 张 DXF 的输入结构和元数据阻断分别统计，不把缺表错误混入几何通过率。
6. 运行现有 BH 相关 pytest，随后对 183/195 以及既有目标图纸做真实 CLI 回归；若出现非目标视图的板数、孔数、角色、R 角或余量变化，停止并修正，不扩大修改范围。

## 非目标

本次不修改 BOX 算法、不修改前端/数据库/打包、不改变比例缩放策略、不重写孔距和余量规则，不处理 DWG/ODA 转换，也不把说明性引出线转换成制造几何。
