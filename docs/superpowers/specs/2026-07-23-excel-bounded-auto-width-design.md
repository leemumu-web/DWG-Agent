# Excel Final 有界自适应列宽设计

## 1. 目标

让 Excel Final 生成工作表根据实际表头和内容自动调整列宽，减少截断和拥挤，同时限制超长文本列的最大宽度，避免工作簿横向无限扩张。

## 2. 适用范围

自动调整以下生成表：

```text
清洗表
构件表
整理表
part
处理报告
```

`原表`不参与自动调整。其值、样式和列宽继续保持输入文件原样。

内部审计字段仍参与计算、核验和报告生成，但构件表的“来源sheet、行类型、小计来源行”以及整理表的“比重来源、净材利用率、重量核验”在最终 Excel 写出阶段物理删除。

平台处理时，同一 writer 在任务临时目录保存删除前的完整内部工作簿供后端入库；最终对象存储和下载文件只保存删列版本。内部副本不改变协议结果字段，不进入用户产物，并随任务临时目录清理。

## 3. 显示宽度计算

每个可见值按逐行文本计算显示宽度：

- 中文、全角字符及其他 East Asian Wide/Fullwidth 字符按 2 个宽度单位；
- ASCII、数字和普通半角字符按 1 个宽度单位；
- 多行文本取最长一行；
- `None`按空文本处理；
- 公式按公式文本参与宽度估算；
- 表头和所有数据行共同参与计算。

最终宽度为：

```text
内容最大显示宽度 + 2 个单位边距
```

然后限制在该列允许的最小值和最大值之间。

## 4. 宽度边界

默认生成列：

```text
最小宽度 8
最大宽度 32
```

`处理报告`中的“说明”和“建议操作”：

```text
最小宽度 16
最大宽度 48
```

这些长文本列启用自动换行和顶部对齐。其他报告列继续垂直居中。

列宽必须由内容决定，不能继续依赖少量固定列号。特殊边界按 sheet 名和表头名配置，不能按易漂移的列号配置。

## 5. 执行顺序

writer 完成所有内容、公式和质量样式后：

1. 对五张生成表计算有界自适应列宽；
2. 对报告长文本列设置自动换行；
3. 从最终构件表和整理表删除不展示的内部审计列；
4. 保存并继续执行公式缓存双模式校验。

自动宽度不得修改其余单元格值、公式、数字格式、质量颜色、冻结窗格或自动筛选。

## 6. 测试与验收

必须覆盖：

- 中文字符按双宽计算，宽度大于同字符数 ASCII；
- 短内容列不会小于 8；
- 普通超长内容不会超过 32；
- 处理报告“说明”和“建议操作”不会超过 48，并启用自动换行；
- 构件号、零件号和规格列随实际内容增长；
- 原表原有列宽保持不变；
- 整理表和构件表指定内部审计列不出现在最终表头；
- 真实结果的五张生成表没有使用旧固定列宽逻辑；
- 122 行 `part`、GT 对账、重量和后端导入/下载合同不受影响；
- Stage、真实 MySQL、ground truth、后端真实链路和全量回归通过。

## 7. 非目标

本次不：

- 修改原表列宽或样式；
- 根据操作系统字体做像素级测量；
- 自动调整行高；
- 新增 sheet；
- 修改 part 聚合、班组、重量或后端导入逻辑。
