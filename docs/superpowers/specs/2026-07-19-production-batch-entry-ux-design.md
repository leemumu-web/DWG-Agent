# 生产批次创建入口易用性设计

## 问题

当前页面主按钮写作“提交生产批次”，但点击后只是填写项目和名称；真正的创建动作位于抽屉右上角，远离表单。用户无法在操作前确认所需文件，也不清楚“创建”与“上传”的先后关系，窄屏下主操作更难发现。

## 确定方案

- 页面唯一主入口改为“新建并上传生产批次”，副文案直接说明“多个 DWG + 1 个 Excel，DXF 由服务器生成”。
- 创建抽屉使用三步预期：选择项目、确认批次名称、进入资料上传；不引入多页向导。
- 选择项目后自动建议 `<项目代码>-YYYYMMDD-生产批次`，用户修改过名称后不再覆盖。
- 创建表单底部提供完整宽度主按钮“创建批次，下一步上传文件”，旁边说明本步不会上传文件；抽屉右上角不再承担唯一提交入口。
- 无项目时入口仍可打开并解释阻塞原因，主按钮禁用并提供“先创建项目”。
- 提交期间禁用关闭、项目、名称和重复提交；失败保留输入，成功仍在同一抽屉进入上传。
- 桌面端保留页头入口，空列表使用同一文案；窄屏主按钮铺满可用宽度。

## 验收

- 用户无需寻找抽屉右上角即可完成创建。
- 页面和抽屉在创建前均明确文件要求与服务器生成 DXF 的边界。
- 自动名称可编辑且不会覆盖人工输入。
- Playwright 覆盖入口、自动命名、固定主按钮以及创建后原地上传。
