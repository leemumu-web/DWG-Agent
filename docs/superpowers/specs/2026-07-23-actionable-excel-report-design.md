# Excel Final 精炼人工处置报告设计

## 目标

`处理报告`只呈现核心问题和明确需要人工操作的事项，不再作为所有内部校验事件的完整流水账。

## 收录与合并

- 只收录警告、严重和致命问题。
- 信息级问题不进入工作簿报告或对外质量摘要。
- 按级别、类别、来源 sheet、来源行、构件编号和零件号分组。
- 同组的涉及字段和说明去重后合并，避免同一来源的同类问题占用多行。
- 内部原始问题仍用于单元格标红、质量判断和 part 隔离，不因报告合并而丢失安全行为。

## 固定列

`处理报告`固定为以下 8 列：

```text
级别, 类别, 来源位置, 构件编号, 零件号, 涉及字段, 说明, 建议操作
```

`来源位置`使用 `sheet!row`，例如 `原表!8`。多个字段和多个说明分别使用中文分号连接。

## 操作建议

建议按稳定类别映射生成：

- 五金手册查无：补充对应手册数据，或确认该规格无需理论重后重新处理。
- 源重量缺失：补齐涉及的源重量后重新处理。
- 几何/手册理论重偏差、净重大于理论重：复核规格、材质、数量和源重量，修正后重新处理。
- 关键字段缺失：补齐涉及字段后重新处理。
- 物理量非法、构件物理量非法：修正为合法有限数后重新处理。
- 构件编号冲突、导入零件身份冲突：统一冲突身份及几何数据后重新处理。
- 拆板几何异常：修正 BH/BOX/BT 截面尺寸后重新处理。
- 源重量链异常、净重大于毛重：核对单重、总重、数量及净毛重关系后重新处理。
- 其他警告或严重问题：复核该问题并修正源数据后重新处理。

## 空报告

没有人工处置项时：

- 保留 8 列表头；
- `处理报告!A2` 写 `无`；
- 其余数据单元格为空；
- 后端将该行识别为零问题哨兵，质量状态为 `ok`，各计数为 0。

## 整理表精简

`整理表`继续保留“比重来源”和“净材利用率”的值，以维持物理审计和后端导入合同，但这两列在输出工作簿中设置为隐藏。用户正常打开 Excel 时不显示；需要审计时可以手动取消隐藏。

## 统计一致性

Stage 返回值、工作簿报告和后端关系投影都使用合并后的报告行口径：

- `info_count` 固定为 0；
- `warning_count` 和 `severe_warning_count` 等于对应报告行数；
- `category_counts` 按合并后的报告行统计；
- `representative_messages` 使用合并后的说明。

## 验收

- 无问题的真实样本在 `A2` 显示 `无`，后端仍识别为 0 条问题。
- 同一来源同一类别的多个字段合并为一条报告。
- 信息级问题不出现在最终报告和对外摘要中。
- 每条报告都包含可执行的“建议操作”。
- `整理表`的“比重来源”和“净材利用率”列默认隐藏，取消隐藏后数据仍可读取。
- 警告和严重问题继续触发原有颜色、质量状态及 part 隔离。
- Stage、真实 GT、后端导入、真实上传下载和全量测试通过。
