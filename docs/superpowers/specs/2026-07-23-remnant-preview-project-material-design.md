# 余料图纸中文预览、完整项目编号与工人新增材质设计

## 背景

南京北站生产图纸暴露出三个关联问题：在线 SVG 预览把中文渲染成方框；解析器只把标题中的三位计划号当作项目编号；解析出的材质只有在目录已存在时才能自动选中，普通工人不能在确认流程中补建材质。

本设计延续现有“后端解析与渲染、网页确认”的架构，修正上述行为，不改变厚度由工人手工填写的既定流程。

## 已确认的业务规则

- 项目编号是图纸正文中的完整项目标题，不是标题里的三位计划号。
- 示例图纸的项目编号为：`北工大定位板及南京北站017计划天窗2批激光零件 2026-7-03`。
- 不使用文件名推断项目编号；没有可靠标题时留空，由工人填写。
- 材质使用完整牌号，例如 `Q355B`。
- 工人新增材质时只填写完整牌号；系统内部同时保存 `code=Q355B`、`family_code=Q355B`。
- 工人新建的材质立即进入正式材质库并可直接使用，不需要管理员审核。
- 材质的编辑、停用和别名维护继续只允许管理员操作。
- 中文字体不可用时仍生成 SVG；中文允许显示为方框，但几何图形和其他可渲染内容不能因此失效。

## 方案选择

采用服务端统一渲染方案：DXF 在后端生成安全 SVG，网页继续负责加载、缩放和平移。

未采用浏览器直接解析 DXF 的方案，因为当前需求不需要实体选择、测量或图层交互；浏览器 CAD 渲染会扩大前端依赖、增加工位性能差异，并要求把完整 DXF 交给浏览器。

## 1. 中文在线预览

### 根因

当前 `ezdxf` SVG 后端把文字转为路径。南京北站 DXF 的中文文字样式引用 `arial.ttf`，运行容器没有覆盖中文字形的字体，因此生成的路径是方框。已有 SVG 会按渲染器版本缓存，单纯安装字体不会刷新旧缓存。

### 设计

- 后端运行镜像安装开源 Noto CJK 字体包。
- 预览渲染前遍历模型空间和块中的 `TEXT`、`MTEXT`、`ATTRIB`、`ATTDEF`。
- 对包含 CJK 字符的实体应用仅用于内存渲染的中文字体样式；不修改或回写用户 DXF。
- 拉丁文字、SHX 几何和不含中文的文字样式保持原样。
- SVG 继续把文字转成路径，不引入外部字体链接或活动内容。
- 提升 `PREVIEW_RENDERER_VERSION`，使旧的乱码/方框缓存自动失效并重新生成。
- 若中文字体文件不存在或字体注册失败，记录警告日志并按原样继续渲染；接口仍返回 SVG，不抛出字体专用错误。

## 2. 完整项目编号解析

- 对无标签文字，只有符合可靠项目标题特征的完整文字才进入项目候选；本次生产规则要求标题包含 `计划` 且包含中文正文。
- 候选值保存规范化后的完整标题，不再截取三位数字。
- 多个不同标题候选时保留全部候选并产生冲突警告，后端不自动写入 `corrected_project_no`。
- 恰好一个标题候选时自动写入完整 `corrected_project_no`，确认窗口直接显示，工人仍可修改。
- 没有可靠标题时项目编号为空，不从原始文件名或 DXF 文件名兜底。
- 数据库现有 `project_no` 最大长度为 128；解析器和 API 在写入前按该边界校验，超长候选不得静默截断。

## 3. 材质自动填写与工人新增材质

### 已存在材质

- 解析得到唯一材质候选后，后端继续通过标准牌号及别名解析正式材质。
- 唯一匹配时直接写入导入项的 `corrected_material_id`。
- 确认窗口优先使用 `material_id`，因此打开时自动选中对应材质。

### 未建档材质

- 确认窗口显示检测到的完整牌号，并提供“新建并使用 `<牌号>`”操作。
- 新增专用的“解析或创建材质”接口，普通余料库用户可调用；现有管理员材质维护接口权限不变。
- 接口规范化完整牌号，并以相同值写入 `code` 与 `family_code`。
- 创建成功后记录创建人和审计日志，返回正式材质及 `created` 标志。
- 并发创建同一牌号时只保留一个数据库记录；后到请求返回已经存在的记录，前端不显示冲突失败。
- 前端收到材质后刷新材质查询缓存、将新材质加入下拉框并立即选中，当前厚度、项目编号和零件编辑内容保持不变。
- 多个材质候选时不自动创建或选中，由工人选择一个候选或手工输入要新建的完整牌号。

## 4. 界面行为

确认窗口字段顺序保持为厚度、标准材质、项目编号、零件编号：

- 厚度始终由工人填写。
- 标准材质存在唯一正式匹配时自动选中。
- 未匹配时在材质控件附近展示候选牌号和“新建并使用”按钮。
- 项目编号显示完整图纸标题；没有可靠标题时保持空白。
- 自动填写的项目编号、材质和零件编号均允许工人确认前修改。
- 新建材质网络失败时保留整个表单状态并允许重试。

## 5. 权限与审计

- 拥有余料库使用权限的普通工人可以调用专用材质解析/创建接口。
- 该接口只允许创建启用状态的新材质，不允许修改、停用或维护别名。
- 管理员现有材质目录、修改和别名接口保持原权限。
- 每次真正创建新材质均写入 `remnants.material.create` 审计记录；命中已有材质不重复记录创建审计。

## 6. 错误与边界处理

- 中文字体缺失：记录警告，继续生成 SVG，允许出现方框。
- 无项目标题：项目编号留空，由工人填写。
- 多项目候选：不自动填写，展示候选和冲突警告。
- 多材质候选：不自动选中或创建。
- 重复材质：返回已有正式材质并立即使用。
- 新建材质请求失败：保留确认表单，不清空其他字段。
- 超长项目标题：作为可恢复的解析警告处理，不写入超出数据库约束的数据。

## 7. 测试与验收

### 自动测试

- 解析器测试：完整项目标题、无标题不使用文件名、多标题冲突、128 字符边界。
- 预览测试：提供可用中文字体时输出不是重复方框路径；字体缺失时仍生成合法安全 SVG。
- 缓存测试：渲染器版本变化后旧预览不复用。
- 后端测试：已存在材质自动解析；普通工人可创建；重复和并发创建返回同一材质；普通工人仍不能编辑或停用材质。
- 前端测试：已有材质自动选中；未建档候选可新建并选中；创建失败保留表单；完整项目标题进入输入框。

### 真实样本验收

- 使用南京北站 DXF 和原始 DWG 转换结果验证在线预览中文可阅读。
- 指定样本项目编号完整等于 `北工大定位板及南京北站017计划天窗2批激光零件 2026-7-03`。
- 已建档 `Q355B` 自动填入材质栏。
- 删除或换用一个未建档测试牌号后，普通工人可在确认窗口创建并立即使用。
- 11 张样本的材质和 38 个零件号保持稳定；含可靠标题的样本输出完整项目标题，其余样本保持项目编号为空。

## 非目标

- 不实现浏览器端 DXF/CAD 引擎。
- 不增加实体点击、测量或图层显隐功能。
- 不从文件名推断项目编号或厚度。
- 不开放普通工人编辑、停用材质或维护别名的权限。
