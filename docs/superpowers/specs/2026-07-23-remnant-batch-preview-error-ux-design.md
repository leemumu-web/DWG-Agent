# 余料库批量处理与预览体验改进设计

## 背景与目标

在现有余料导入确认、全局余料列表、在线 DXF 预览和材质管理基础上，改善窄屏操作、批量归档、历史数据筛选、预览空间、新材质录入及工人可见错误信息。

本次中文化范围限定为整个余料库，不扩展到文件转换、任务等其他业务模块。

## 界面与交互

### 解析确认

- 为表格设置明确列宽和横向滚动，操作列固定在右侧，保证“预览、编辑”始终完整显示。
- 图纸完全没有材质候选时，仍显示“手动填写完整牌号并新建使用”入口。
- 工人新建的材质立即进入正式材质库、默认启用，并自动选中用于当前图纸确认。

### 全部余料

- 增加行选择与“批量归档”按钮，本期不增加其他批量状态操作。
- 工人只能归档自己导入且当前状态为“可用”的余料；管理员可归档任意“可用”余料。
- 批量操作允许部分成功：符合条件的记录归档，失败记录保留选中并逐条显示中文原因。
- 增加“显示历史余料”开关，默认关闭。关闭时查询“可用、已预留”，打开后查询全部状态，包括“已使用、已归档”。
- 现有材质、厚度、项目、零件和排序筛选保持不变；切换历史开关后回到第一页并立即刷新。

### 在线预览

- 移除左下角英文状态文字和右侧图形统计、实体构成、图层数据栏。
- 画布占满弹窗主体宽度，背景改为与项目一致的浅灰蓝色。
- 初始加载和“适合窗口”按容器尺寸重新居中适配图纸。
- 放宽拖动边界，避免缩放后可拖动显示范围过小；保留放大、缩小、适合窗口、重新加载和下载源文件。

### 材质管理

- 状态列的胶囊开关改为可交互控件。
- 切换前显示中文确认提示，提交期间仅锁定当前操作，成功后刷新材质列表，失败时恢复原状态并显示中文原因。
- 现有操作列中的重复“启用/停用”按钮移除，编辑入口保留。

## 接口与数据流

### 批量归档接口

- 新增 `POST /api/v1/remnants/bulk-archive`。
- 请求体：`remnant_ids: number[]`，至少 1 条、最多 200 条，后端保持首次出现顺序并去重。
- 响应包含：
  - `archived`: 成功归档的余料编号列表。
  - `failed`: 失败明细列表，每项包含 `remnant_id`、稳定内部 `code` 和中文 `message`。
- 后端逐条锁定、校验并处理，不因单条失败回滚其他合法记录。
- 每条成功记录继续写独立的 `remnants.archive` 审计日志，记录操作者、原状态和新状态。
- 单张归档接口及其权限规则保持不变。

### 材质创建

- 继续复用 `POST /api/v1/remnant-materials/resolve-or-create`。
- 无候选、候选未建档两种场景均允许工人输入完整牌号。
- 新建材质的 `family_code` 默认等于规范化后的完整牌号，管理员之后可在材质管理中调整系列和别名。
- 已停用的同名材质不自动重新启用，提示联系管理员启用。

### 历史数据开关

- 不新增查询参数。前端关闭开关时向现有全局列表接口发送 `available,reserved`；打开时发送 `available,reserved,used,archived`。
- Excel 全量导出保持导出所有状态，不受页面开关影响。

## 中文错误规范

- 余料库后端所有 `AppHTTPException.message` 改为中文；稳定错误代码继续用于日志、测试和程序判断。
- 前端不得直接向工人显示 `REMNANT_*` 或解析器警告代码，统一通过余料库中文映射转换。
- 批量确认至少覆盖：
  - `REMNANT_THICKNESS_REQUIRED`：请填写余料厚度。
  - `REMNANT_MATERIAL_REQUIRED`：请选择或新建材质。
  - `REMNANT_PROJECT_REQUIRED`：请填写项目编号。
  - `REMNANT_PARTS_REQUIRED`：至少填写一个零件编号。
  - `REMNANT_DXF_REQUIRED`：缺少可用于确认的 DXF 图纸。
  - `REMNANT_IMPORT_ITEM_NOT_READY`：该图纸当前不能确认，请刷新后重试。
- 解析警告使用中文标题与现有中文说明；未知代码使用“图纸存在需要人工确认的问题”，内部代码仅写入开发日志。
- 余料库所有 mutation 补齐 `onError`，通过统一错误描述器显示网络、权限、校验、冲突、下载和服务异常。
- Pydantic 参数校验错误由前端转换为中文字段名和中文原因，不展示 `must not be blank` 等英文原文。

## 验收标准

- 窄屏或长字段情况下，解析确认的操作列仍可见且按钮不越界。
- 批量归档覆盖全部成功、部分成功、全部失败、重复编号、不存在编号、越权、非可用状态和超过 200 条；成功项均有审计记录。
- 历史开关默认关闭且仅显示可用、已预留；打开后显示全部状态。
- 无材质候选时可手工创建材质并自动用于当前确认；已停用同名材质不能绕过管理状态。
- 缺少厚度、材质、项目或零件时，工人只看到明确中文提示。
- 材质启用开关可操作，确认、加载、成功刷新和失败恢复行为正确。
- 在线预览无左下状态文字和右侧数据栏，使用浅色背景；缩放、拖动、适合窗口、重载和下载正常。
- 余料库后端单元/API 测试、前端生产构建及余料库 Playwright 端到端测试全部通过。

## 兼容性与约束

- 不修改数据库结构，不新增迁移。
- 单张归档、原图下载、Excel 导出和现有查询接口保持兼容。
- 批量归档以数据库事务中的逐条保存点隔离失败，支持现有多进程 API/Worker 部署，不依赖进程内共享状态。
