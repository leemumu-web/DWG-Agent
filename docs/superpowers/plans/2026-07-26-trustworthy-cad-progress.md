# CAD 转换真实进度与安全诊断实施计划

> 项目明确禁止子代理；全部实施、验证和发布由主代理在当前仓库完成。

**目标：** 修正 DWG→DXF 及所有 Job 进度展示的含义，提供不泄漏后端细节的任务诊断，并交付可直接部署的完整加密镜像。

**架构：** MySQL Job/JobStep 继续作为唯一事实源。后端登记可确认里程碑和 ODA 分片结果；前端批次条按终态数量计算，并通过共享 Job 进度展示读取阶段文案。诊断接口对白名单字段做只读投影。
