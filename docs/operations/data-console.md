# 数据管理台使用说明

## 使用入口

登录平台后打开 `/data-console`。页面只保留两个与现有后端数据直接对应的工作区：

- **生产任务**：查看生产项目、当前阶段、进度和后台处理任务；进入项目继续操作；查看明确错误；管理员可取消允许取消的任务，并重试后台允许重试的失败任务。
- **文件存储**：按中文存储区和目录查看对象及其数据库登记状态；管理员可上传、下载、更改已登记文件路径或软删除文件。

页面不提供通用数据库行编辑、消息队列控制、自动修复或每日归档入口。生产阶段只能在所属生产项目中推进；拆板任务失败后也必须回到所属项目处理，不能绕过工作流直接重试。

管理员和超级管理员在数据管理上的可见范围相同，可查看全部登记数据；普通账号只看到自己上传的文件和自己产生的流转记录。原始 MySQL 与对象目录只向管理员开放。身份、角色、权限和登录安全表即使对管理员也只读，账号状态、角色和密码必须在“用户管理”中操作。系统只有一个受保护的超级管理员，不能删除、禁用、降级、转授或由其他账号重置密码。

## 数据来源

| 页面内容 | 后端事实源 |
|---|---|
| 生产项目、阶段、进度 | `/api/v1/workflows` 与生产流程模板 |
| 处理任务、错误、取消、重试 | `/api/v1/workflows/jobs` 的任务状态机 |
| 数据库与文件存储状态 | `/api/v1/data-admin/overview` |
| 目录、对象与登记关系 | `/api/v1/data-admin/objects/tree` 和 `files` 登记 |
| 上传、下载、路径变更、软删除 | 现有文件与 data-admin 业务接口 |

未知任务类型会同时显示后端原始任务标识，不会被伪装成已知生产步骤。页面的操作按钮还会根据账号权限和任务状态收敛；后端仍会再次校验权限、状态、引用关系和并发变化。

## 文件操作规则

- 上传由后端根据文件类型自动选择存储区，不会写入当前正在浏览的任意目录。
- 删除是数据库软删除，底层对象按保留与审计规则处理；冻结输入或无权文件会被后端拒绝。
- 更改路径只针对已登记文件。系统复制并校验目标、更新登记后再处理源对象；冲突或补偿失败会返回具体错误。
- 未登记对象只用于发现异常，不显示删除、移动或下载按钮，避免绕过文件登记与权限。
