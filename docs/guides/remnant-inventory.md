# 余料库使用说明

本说明面向现场工人、材质管理员和系统运维人员，介绍如何把实际 DWG/DXF 余料图纸导入全厂共享余料库，以及如何查询、预占、领用、归档和导出库存。上线、备份、灰度和故障恢复要求见[余料库上线与运行手册](../operations/remnant-inventory.md)。

## 1. 启用与权限

余料库默认关闭。管理员完成数据库迁移、材质目录和真实样本验收后，在后端或 Compose 环境设置：

```dotenv
REMNANT_INVENTORY_ENABLED=true
```

服务重启后，具有以下角色的账号可以进入网页“余料库”：

| 角色 | 可以执行的操作 |
|---|---|
| `remnant_worker` | 查询、预览、导入和确认图纸；预占、释放和领用；归档、删除本人导入的余料；启用或停用材质 |
| `admin` / `super_admin` | 拥有工人能力；可维护材质代码、系列和别名；可处理其他工人的导入批次和库存 |

所有变更操作都会写入审计日志。原始 DWG/DXF 的下载仍受文件权限控制。

## 2. 余料字段

一张正式余料占库存列表一行，主要字段如下：

| 字段 | 是否必填 | 来源 |
|---|---|---|
| 厚度 | 是 | 普通批量导入由工人填写；自动导入从 `GG` 解析后可修改 |
| 材质 | 是 | 图纸候选或 `CZ`；工人最终确认 |
| 项目编号一 | 是 | 工人选择识别候选或手工填写 |
| 项目编号二 | 否 | 工人单行或批量填写 |
| 库存位置 | 否 | 工人单行或批量填写 |
| 备注一、备注二 | 否 | 工人手工填写 |
| 零件编号 | 至少一个 | 图纸解析，可保留多个并手工增删 |

批量填写附加信息时，必须先勾选“更新项目编号二”或“更新库存位置”。系统只修改明确勾选的字段；勾选后留空提交表示清空该字段，未勾选字段保持原值。

## 3. 普通批量导入

普通批量导入适用于格式不统一或需要人工判断的余料图纸：

1. 进入“余料库 → 批量导入”。
2. 选择或拖入多张 `.dwg`、`.dxf` 图纸，不要上传 ZIP。
3. 点击“批量导入”。DWG 会先转换为解析用 DXF；DXF 直接进入解析。
4. 等待每张图纸显示“待确认”。单张失败不会阻塞同批其他图纸，可按行重试或移除。
5. 默认选中所有待确认图纸，可批量填写厚度、项目编号二和库存位置。
6. 点击“编辑”核对厚度、材质、两个项目编号、库存位置、备注和多个零件编号。
7. 点击“确认选中项”。有效图纸进入正式库存，字段不完整的图纸保留在批次中继续修改。

刷新页面不会丢失批次，URL 中的 `batch` 参数用于恢复当前进度。

## 4. 自动导入与文件夹导入

自动导入适用于包含统一 `offcut_zh_cn` 块的图纸：

1. 进入“余料库 → 自动导入”。
2. 选择多张图纸，或选择/拖入一个文件夹。
3. 文件夹会递归收集 `.dwg`、`.dxf`，保留相对路径；顶层文件夹名作为项目编号一的预填值。
4. 工人确认或修改批量项目编号后开始解析。
5. 系统自动填写厚度、材质和零件编号；工人可以预览并逐行编辑。
6. 默认选中全部有效项，点击“一键导入选中的有效项”完成入库。异常项继续保留，不回滚已经成功的图纸。

单批最多导入 100 张图纸。同批重复文件和已经入库的源图会按行提示，不阻塞其他文件。

### 4.1 标准块格式

图纸必须包含唯一的 `offcut_zh_cn` 块，并提供：

| 属性 | 示例 | 说明 |
|---|---|---|
| `GG` | `-28 × 3200 × 1500` | 厚度 × 长 × 宽；接受 `x`、`X`、`×` 和空格，厚度取绝对值，三项必须大于零 |
| `CZ` | `Q355B` | 完整材质牌号，不截断后缀 |
| `YLBH` | `J1-001-1` | 余料或零件编号 |

缺少块、存在多个同名块、规格非法或属性不完整时，系统显示中文告警并等待工人补充，不使用文件名或普通文字猜测标准字段。

## 5. 材质管理

- 自动导入识别到未建档的完整牌号时，系统自动创建并立即使用。
- 命中已停用材质时，系统自动重新启用并写审计。
- 工人在解析确认中可以输入完整牌号并“新建并使用”。
- 余料工人可以显示已停用材质并切换启用状态。
- 只有管理员可以修改材质系列和别名。
- 材质不提供物理删除，避免破坏历史库存引用。

## 6. 查询和库存状态

“余料检索”要求按材质和厚度精确查询，可选择包含同系列材质。“全部余料”支持分别按以下字段筛选：

- 材质、厚度和状态；
- 项目编号一、项目编号二；
- 库存位置；
- 备注一、备注二；
- 零件编号。

默认显示“可用”和“已预占”。打开“显示历史余料”后显示“已使用”和“已归档”。

库存主要状态流转：

```text
可用 -> 已预占 -> 已使用
  \-> 已归档 -> 删除库存记录
```

- 预占采用并发条件更新，同一张余料同时只能被一名工人成功预占。
- 只有预占人或管理员可以释放或标记使用。
- 只有可用余料可以编辑或归档。
- 工人只能归档和删除自己导入的余料；管理员可以处理其他工人的余料。
- 删除只允许作用于已归档余料，保留源文件、导入账本和审计日志。
- 删除后的同一源图可以再次提交并形成新的正式余料记录。

## 7. 预览、原图和 Excel 导出

- “预览”显示系统生成的 DXF/SVG 图形，可缩放和拖动。
- “下载原图”返回实际上传的 `.dwg` 或 `.dxf`；DWG 转换产生的 DXF 只用于解析和预览。
- “导出全部余料”生成一张余料一行的 `.xlsx`，包含材质、厚度、两个项目编号、库存位置、两个备注、多个零件编号、状态和操作人信息。
- 导出文本始终按普通文本写入，避免以 `=、+、-、@` 开头的内容被 Excel 当成公式。

## 8. Worker 与常见问题

余料库使用两个专用 Celery 队列：

| 队列 | 默认并发 | 用途 |
|---|---:|---|
| `remnant_convert` | 2 | 批量调用 ODA 将 DWG 转换为 DXF |
| `remnant_parse` | 4 | 独立子进程解析每张 DXF，默认超时 120 秒 |

常见页面提示及处理方式：

| 中文提示 | 处理 |
|---|---|
| 请填写余料厚度 | 填写大于 0、最多三位小数的厚度 |
| 请选择或新建材质 | 从启用材质中选择，或输入完整牌号新建 |
| 请填写项目编号 | 填写项目编号一；文件夹名只是预填值 |
| 至少填写一个零件编号 | 保留识别结果或手工补充编号 |
| 同一张源图纸已存在 | 使用现有库存；若旧库存已归档且确需重导，先按权限删除旧库存 |
| 图纸解析失败 | 核对原图，检查 ODA/解析 Worker 后重试或移除该行 |

页面只向工人显示中文原因；内部稳定错误代码和 request ID 用于日志排查。关闭 `REMNANT_INVENTORY_ENABLED` 只会停止功能入口，不会删除库存、源文件或审计记录。
