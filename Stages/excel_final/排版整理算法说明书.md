# Excel Final 排版整理算法说明书

适用对象：负责核对、拆板、汇总和下料准备的排版人员。

本文只说明 Excel 怎样整理、怎样计算、怎样判异常，不涉及平台操作和技术实现。

## 1. 算法要完成什么

算法把 Tekla 构件零件清单整理成一份可追溯、可复算的六表 Excel。核心目标是：

1. 保留原始数据，不用人工经验偷偷改值。
2. 统一零件身份、规格、数量和重量口径。
3. 板材按几何计算，标准型材按唯一五金手册计算。
4. BH、BOX、BT 按固定截面规则拆成腹板和翼板。
5. 只把身份、尺寸和重量关系可信的板件汇入 `part`。
6. 把必须人工处理的问题集中写入 `处理报告`。

完整处理顺序如下：

```text
识别原表和题头
→ 恢复构件、零件和构件小计关系
→ 清理工作值并保留原值
→ 识别零件类别
→ 查询五金手册或采用板材密度
→ 计算理论重量
→ 核验源重量关系
→ 拆分 BH/BOX/BT
→ 生成整理表
→ 按完整参数生成 part
→ 汇总人工处理报告
```

## 2. 五条基本原则

### 2.1 原表优先

原始 Tekla 值是追溯依据。算法不会自动：

- 把长度减 1 mm；
- 给 BH、BOX、BT 增加 5、10 或 20 mm 余量；
- 补写 Z15、Z25、Z35 等材质等级；
- 交换板材厚度和宽度；
- 根据历史结果猜班组、图形或人工再编号。

需要这些信息时，应在有依据的上游数据中明确提供，不能从旧结果反推。

### 2.2 物理量必须说得通

数量、单重、总重和构件数必须满足基本乘法关系。算法允许正常舍入误差，但不允许用理论值掩盖源重量错误。

### 2.3 五金手册只有一个可信来源

标准型材、扁钢、圆钢和螺纹钢只查当前唯一五金手册库。手册没有的数据保持“查无”，手册同一规格有不同答案时标记“冲突”，不自行估算或任选一条。

### 2.4 参数不同就不是同一组

零件号相同，但规格、宽度、下料长度、材质、内部类别或班组任一项不同，都分别保留，不能为了减少行数强行合并。

### 2.5 警告与严重问题分开处理

- `警告`：数据仍保留，通常不阻止合法板件进入 `part`，但需要人工确认。
- `严重`：相关来源行、构件或冲突零件不进入 `part`。
- `致命`：输入无法唯一解释，或五金手册服务不可用，本次不能形成可信结果。

## 3. 原始数据怎样被识别

### 3.1 必需身份

每条生产零件至少需要：

- 构件编号；
- 零件号；
- 规格；
- 长度；
- 材质；
- 数量；
- 构件数。

缺少任一关键身份时，原行仍保留在审计表中并标红，但不查询手册、不拆板、不进入 `part`。

明确属于 M 系列螺栓、螺母、螺套或 TT 的行，可以没有规格；这类连接件按“理论重量留空”处理。`D19` 等不能仅凭零件号猜成螺栓。

### 3.2 题头和构件关系

算法不假定题头固定在第几行，而是在表格前部寻找唯一、字段最完整的题头。若有两处同样像题头，或同一业务字段出现两个无法区分的列，算法停止处理，不自行选择。

Tekla 清单中的构件起始信息、零件明细和构件小计会被合并成同一个构件记录：

- 构件编号、构件数等身份优先取构件起始信息；
- 重量、面积、构件长宽高优先取构件小计；
- 两处同时有值但相互冲突时，按严重问题处理。

### 3.3 原值与工作值

- `原表`完整保留输入值、空格和样式。
- 后续判断使用清理后的工作值：去除半角/全角空格，把数字之间的 `x`、`X`、`×`统一理解为乘号。
- 这项清理只用于识别，不改变 `原表`，也不改变规格的书写顺序。

## 4. 规格怎样分类

| 原规格或身份 | 算法认定 | 理论重量依据 | 是否进入 `part` |
|---|---|---|---|
| `PL厚度*宽度` | 板材 | 密度 7.85 | 是 |
| `PL6*30` | 扁钢 | 五金手册线重 | 是 |
| `FB/FLAT/扁钢/扁铁 厚度*宽度` | 扁钢 | 五金手册线重 | 是 |
| 裸 `厚度*宽度` | 先按扁钢查询；明确查无后才按板材 | 手册或密度 7.85 | 是 |
| `BH H*B*tw*tf` | 焊接 H 形组合件 | 拆板几何和密度 7.85 | 拆成子板后进入 |
| `BOX H*B*tw*tf` | 箱形组合件 | 拆板几何和密度 7.85 | 拆成子板后进入 |
| `BOX H*B*t` | 等壁厚 BOX，`tw=tf=t` | 拆板几何和密度 7.85 | 拆成子板后进入 |
| `BT H*B*tw*tf` | 焊接 T 形组合件 | 拆板几何和密度 7.85 | 拆成子板后进入 |
| 工字钢、H型钢、T型钢、槽钢、角钢、钢管、方管、方钢、W型钢、高频焊 | 标准成品型材 | 对应五金手册线重 | 不进入 |
| `D直径` + HRB 材质 | 螺纹钢 | 螺纹钢手册 | 不进入 |
| `D直径` + HPB/Q235B/Q355B 材质 | 圆钢 | 圆钢手册 | 不进入 |
| 螺栓、螺母、螺套、TT | 连接件 | 不查手册，理论重量留空 | 不进入 |
| HA、RECT 或无法确定类别的规格 | 未分类 | 标记查无，不猜类别 | 不进入 |

特别注意：

- `PL`后第一个数始终按厚度理解，第二个数按宽度理解，不交换。
- `PL6*30`按已确认业务规则作为扁钢查手册，不按普通板材计算。
- 裸 `厚度*宽度`只有在扁钢手册明确查无时才回退为板材；若手册数据冲突，不回退。
- RECT 没有任何专用计算或拆分规则。

## 5. 五金手册怎样使用

当前唯一可信来源是原始《五金手册.xls》。手册库只保存源表中真实存在的记录，不加入源表以外的公式值或经验值；每条查询记录都能追溯到原工作表和行号。

### 5.1 “比重”列的实际含义

`整理表`沿用“比重”这个列名，但不同类别的物理含义不同：

- 板材及 BH/BOX/BT 子板：`7.85`，是钢材密度计算系数；
- 扁钢和标准型材：手册给出的每米重量，单位为 kg/m；
- 螺栓、螺母、螺套、TT：留空；
- 未命中：显示红色“查无”；
- 同一手册键存在不同重量：显示红色“冲突”。

因此，不能把型材“比重”直接当成板材密度使用。

### 5.2 按类别隔离查询

五金手册查询严格执行以下顺序：

```text
先根据规格和材质确定唯一类别
→ 生成该类别唯一允许的查询键
→ 只在该类别的手册数据中做精确相等查询
→ 汇总该键对应的全部可信源行
→ 判断命中、查无或冲突
```

禁止先拿一个规格遍历所有手册表，也禁止在本类别查无后改查另一个相似类别。

查询键先做统一清理：

- 删除半角和全角空格；
- 英文字母转为大写；
- 数字之间的 `x`、`X`、`×`统一为 `*`；
- 数字去除无意义的尾随零，例如 `60.0`按 `60`查询；
- 只转换下表明确列出的图纸别名，不做模糊匹配。

| 已确定类别 | 图纸规格示例 | 实际手册查询键 | 查询说明 |
|---|---|---|---|
| 扁钢 | `PL6*30`、`FB6*30` | `6*30` | 按完整“厚度*宽度”精确查扁钢线重 |
| 圆钢 | `D24` + `Q355B` | `24` | 材质先确认走圆钢，再按直径查圆钢重量列 |
| 螺纹钢 | `D24` + `HRB400` | `24` | 材质先确认走螺纹钢，再按公称直径查螺纹钢 |
| 方钢 | `方钢20`、`方钢20*20` | `20` | 只接受单边长或两边相等的方钢 |
| 工字钢 | `HI14` | `I14` | `HI`单向转为手册的 `I`键；原 `I`规格保持 |
| H型钢 | `HN450*200*9*14` | `H450*200*9*14` | `HN/HW/HM/HT`单向转为 `H`键 |
| T型钢 | `TN50*100*6*8` | `T50*100*6*8` | `TN/TW/TM`单向转为 `T`键 |
| 槽钢 | `C14A` | `[14A` | `C`单向转为手册的 `[`键 |
| 角钢 | `L70*5` | `L70*5` | 按清理后的完整规格精确查询，不改尺寸 |
| 钢管 | `PIP60*14` | `φ60*14` | `PIP/IP/P/Φ/D`单向转为 `φ外径*壁厚` |
| 方管 | `方管100*100*5` | `□100*5` | 正方管压成“边长*壁厚”手册键 |
| 矩形管 | `矩形管100*50*4` | `□100*50*4` | 长边、短边、壁厚均保留 |
| 高频焊 | `HFW100*50*2.3*3.2` | `LH100*50*2.3*3.2` | `HFW`单向转为 `LH`；`LH`绝不查H型钢 |
| W型钢 | `W4*13`、`W100*19.3` | 原规格 | 同时在手册的美标键和中文键中精确匹配 |

材质参与查询的边界也固定：

- D 系列必须同时看材质。HRB 只能进入螺纹钢类别；HPB、Q235B、Q355B 只能进入圆钢类别。
- D 系列材质缺失或不属于上述范围时，不发起圆钢/螺纹钢查询，直接标记“D系列材质不足”。
- HRB 在螺纹钢手册查无时，不能借用同直径圆钢重量；圆钢查无时也不能借用螺纹钢。
- 扁钢及其他标准型材当前按“类别+规范规格”查询，材质不用于跨表寻找另一个重量。

Excel 中仍显示图纸原规格。查询键只是为了与唯一源手册的原有写法准确对应，不能反向改写图纸数据。

### 5.3 命中、查无、冲突

- `命中`：精确查询至少返回一条可用源行，且所有返回行的线重相同；采用该唯一线重计算理论重量。
- `同值重复`：同一查询键在源手册出现多次，但重量完全相同，仍视为一次有效命中，并保留全部源行追溯关系。
- `查无`：查询成功，但该类别中没有与查询键完全相等的可用行；理论重量留空并进入 `处理报告`。
- `冲突`：同一查询键返回多个不同线重；理论重量留空，报告全部冲突来源，不任选一条。
- `故障`：连接失败、手册结构不符、查询失败，或返回非数值、非正数、超过 2000 kg/m 的异常线重；整次处理停止，不能伪装成“查无”。

手册查询不包含以下行为：

- 不用钢管外径、壁厚公式补算查无规格；
- 不用板材密度补算查无扁钢；
- 不按源毛重反推手册线重；
- 不从相邻规格、近似尺寸或其他钢种插值；
- 不对查无结果填写 0。

唯一例外是没有类别前缀的裸 `厚度*宽度`：它本来就存在“扁钢候选或板材”两种业务含义。只有扁钢查询得到明确的零行“查无”时，才按原书写顺序解释为板材；查询冲突或查询故障时均不得回退。

H 型钢和 T 型钢同一手册行存在多个标准版本重量时，按 `2010版 → 2005版 → 98版`的顺序取第一个非空值，不根据源毛重反向选择“最接近”的版本。出现偏差时，由人工确认项目采用的标准版本。

### 5.4 手册结果怎样核对

对任意型材行，按以下四步核对：

1. 先用原规格和材质确认类别是否正确，尤其检查 D 系列。
2. 按上表手工写出唯一查询键，确认没有交换尺寸或错误改前缀。
3. 在 `整理表`查看“比重”：命中时应为 kg/m，查无或冲突时应为红字。
4. 命中后验证：

```text
理单重 = 手册线重 × 长度(mm) ÷ 1000
理总重 = 未舍入理单重 × 总数
```

若手册线重本身正确，但源毛重与理论重偏差超过阈值，应转入“标准版本或源重量口径”核验，不能擅自改手册查询结果。

## 6. 整理表各数量和重量怎样计算

### 6.1 数量口径

| 字段 | 含义 | 计算 |
|---|---|---|
| 原数量 | Tekla 中单个构件内该父零件的数量 | 原值 |
| 数量 | 当前整理行的数量；普通件等于原数量，拆板件含腹板/翼板倍数 | 原数量 × 拆板倍数 |
| 构件数 | 同类构件的数量 | 原值 |
| 总数 | 整个批次中当前整理行的数量 | `构件数 × 数量` |
| 总长 | 当前整理行的模型长度合计 | `长度 × 总数` |

拆板后“原数量”仍保留父零件原值，“数量”才是子板数量。核对 `part` 时应使用“总数”，不能直接使用“原数量”。

### 6.2 长度口径

```text
下料长度 = 长度 - 左进 - 右进
```

当前输入没有可靠的左右进字段，因此：

- 左进、右进保持空白；
- Excel 公式把空白按 0 处理；
- 当前下料长度等于源长度；
- 不自动减 1 mm，也不自动加加工余量。

当前“总长”按模型长度计算：

```text
总长 = 长度 × 总数
```

它不是另行计算的“下料长度合计”。当前左右进为空，所以两者数值相同。

### 6.3 板材理论重量

```text
理单重(kg)
= 厚度(mm) × 宽度(mm) × 长度(mm) × 7.85 ÷ 1,000,000
```

### 6.4 扁钢和标准型材理论重量

```text
理单重(kg)
= 五金手册线重(kg/m) × 长度(mm) ÷ 1,000
```

### 6.5 理论总重

```text
理总重 = 未舍入理单重 × 总数
```

理单重和理总重最终都显示三位小数。理总重使用未舍入的计算基础，不是拿屏幕上已经四舍五入的理单重再乘总数，因此人工乘算时末位可能相差 0.001 kg，这是正常的显示舍入，不是数量错误。

### 6.6 源重量和表重量

源表四种重量的口径固定为：

```text
单净重 × 原数量 ≈ 总净重
单毛重 × 原数量 ≈ 总毛重
表净重 = 总净重 × 构件数
表毛重 = 总毛重 × 构件数
```

必须特别区分：

- `总净重/总毛重`：一个构件内该零件全部原数量的重量；
- `表净重/表毛重`：再乘构件数后的项目或批次重量。

算法不使用理论重量回填缺失的源净重或源毛重。表面积也保留源值，不重新计算。

### 6.7 Excel 公式痕迹

最终 Excel 中以下计算保留公式：

- 下料长度；
- 总数；
- 总长；
- 理单重；
- 理总重；
- 表净重；
- 表毛重；
- `part`汇总。

点击相应单元格，可以在公式栏看到计算关系。修改最终 Excel 只能改变当前文件显示，不能重新执行分类、拆板、合并和质量判定；源数据有误时应修正源表后重新整理。

## 7. 源重量怎样核验

### 7.1 基础合法性

以下情况为严重问题：

- 构件编号、零件号、规格、长度、材质、数量或构件数缺失；
- 长度、数量或构件数小于等于 0；
- 重量或面积为负数；
- 数值不是有效有限数；
- 构件起始信息与构件小计的身份互相冲突；
- 构件尺寸、数量或重量不符合基本合法性。

相关数据保留用于追溯，但不进入 `part`。构件级严重问题会隔离整个构件。

### 7.2 单重与总重链

算法分别核对：

```text
总净重 是否约等于 单净重 × 原数量
总毛重 是否约等于 单毛重 × 原数量
```

绝对误差不超过 `0.1 kg`，视为可接受的累计舍入；超过 `0.1 kg`，判为严重并排除相关 `part`。

### 7.3 净重与毛重

分别核对单重和总重：

```text
净重 ≤ 毛重
```

净重比对应毛重高出不超过 `0.1 kg`，按舍入误差接受；高出超过 `0.1 kg`，判为严重。

### 7.4 理论重与源毛重

先看绝对误差，再看相对误差：

| 条件 | 结果 |
|---|---|
| 单重绝对误差 ≤ 0.01 kg | 通过 |
| 总重绝对误差 ≤ `0.01 kg × 原数量` | 通过 |
| 或相对误差 ≤ 0.5% | 通过 |
| 相对误差 > 0.5% 且 ≤ 2% | 警告 |
| 手册型材相对误差 > 2% | 严重 |
| 板材、BH、BOX、BT 几何理论重相对误差 > 2% | 警告 |

标准型材的每米重应与手册一致，因此超过 2% 时按严重处理。板材和焊接组合件可能受轮廓、切割毛坯或模型口径影响，几何矩形重量只能提示复核，不能仅凭偏差超过 2% 就删除板件。

### 7.5 净重与理论毛坯重

- 净重低于理论毛坯重：符合材料去除的物理含义，直接通过。
- 净重超过理论重，但绝对差 ≤ 0.01 kg 或相对差 ≤ 0.5%：按舍入接受。
- 超过上述范围：警告人工复核，但只要净重没有超过毛重，就不因此排除 `part`。

### 7.6 源重量缺失

源净重或毛重缺失时：

- 保持空白；
- 不拿理论重量补齐；
- 记录警告；
- 若其他身份、尺寸和硬门禁均通过，板件仍可进入 `part`。

连接件本来就不计算理论重量，不因预期空白产生缺失警告。

## 8. BH、BOX、BT 怎样拆板

规格统一按以下含义解释：

```text
H  = 截面总高
B  = 截面总宽
tw = 腹板厚度
tf = 翼板厚度
N  = 原数量
```

| 类型 | 腹板规格和数量 | 翼板规格和数量 |
|---|---|---|
| BH | `tw × (H-2tf)`，数量 `N` | `tf × B`，数量 `2N` |
| BOX | `tw × (H-2tf)`，数量 `2N` | `tf × B`，数量 `2N` |
| BT | `tw × (H-tf)`，数量 `N` | `tf × B`，数量 `N` |

导入零件号固定增加类型后缀，例如：

```text
原零件号：P1
拆板后：P1-BH腹、P1-BH翼
```

拆板规则还包括：

- BH、BT 必须有 `H*B*tw*tf` 四个参数；
- BOX 可使用四参数，也可用 `H*B*t` 表示等壁厚；
- 所有尺寸必须为正，且扣除翼板后的腹板宽度必须大于 0；
- 非法几何不勉强拆板，保留父行、报告严重问题、不进入 `part`；
- 父件的原规格不被改写；
- 每个子板按自己的厚度、宽度、长度计算理论重量；
- 全部子板理论重量之和必须等于父组合截面的理论重量。

### 8.1 拆板后的重量核对口径

父件的源净重和源毛重只显示在腹板或主行，翼板行保持空白，避免重复累计。

拆板后不能直接比较：

```text
主行的父单毛重  vs.  主行的一块腹板理单重
```

两者代表的物体不同。正确核对方法是：

```text
同一父件全部子板理总重之和
vs.
主行表毛重
```

父源重量的质量判定在拆板前已经按“腹板贡献 + 翼板贡献”的完整父截面完成。

## 9. `part`怎样生成和合并

### 9.1 哪些零件进入

`part`只接收：

- 普通板材；
- 扁钢；
- BH、BOX、BT 拆出的腹板和翼板。

标准成品型材、圆钢、螺纹钢、螺栓、螺母、螺套、TT、未分类件不进入 `part`。这不是漏项，而是当前下料表的明确范围。

### 9.2 构件号怎样保留

- BH、BOX、BT 子板：保留导入构件编号，在各自构件内汇总。
- 普通板材和扁钢：导入构件编号留空，允许相同板件跨构件汇总。

这是为了让主组合件后续仍能追溯到构件，同时减少普通同类板件的重复行。

### 9.3 合并键

只有以下属性全部相同才合并：

```text
导入构件编号（仅 BH/BOX/BT 使用）
导入零件号
规格
宽度
下料长度
材质
内部类别
班组
```

任一属性不同，都输出为不同 `part` 行。最终 Excel 删除“类型”列，但算法合并时仍使用内部类别，不会把不同物理类型混在一起。

同一构件内，同一个 BH/BOX/BT 导入零件号若同时对应不同规格、宽度、长度或材质，属于严重身份冲突；相关零件全部排除，不能任取一种。

### 9.4 汇总数量

每条 `part`的汇总量来自对应 `整理表`行的“总数”：

```text
part汇总 = 所有完整属性相同且通过严重门禁的整理表总数之和
```

`part`汇总使用 Excel 求和公式，明确引用贡献它的整理表行。参数不同的行不会混入。

### 9.5 当前留空字段

- 班组：源数据没有可靠班组时留空；
- 图形：没有可靠来源时留空；
- 备注：固定留空；
- 文件：固定在 K 列并留空。

当前 `part`是未分班组的基础数量表。后续分班组时，应以 `整理表`保留的构件级来源和 `part`总量为数量基准，不能改变项目总数。

## 10. 六张表分别代表什么

| 工作表 | 算法作用 | 主要核对内容 |
|---|---|---|
| 原表 | 原始证据，不改值 | 确认问题是否来自 Tekla 源数据 |
| 清洗表 | 一条父零件一行，显示规范分类 | 核对构件、零件、原规格、材质、数量和源重量 |
| 构件表 | 一个构件一行，合并构件起始和小计 | 核对构件数、构件重量、面积和外形尺寸 |
| 整理表 | 父件或拆板子件的完整计算台账 | 核对身份、拆板、总数、理论重和源重量链 |
| part | 通过门禁后的未分班组下料汇总 | 核对完整参数分组和汇总数量 |
| 处理报告 | 只列需要人工处理的问题 | 按来源位置修正或确认 |

最终 `整理表`删除“类型、比重来源、净材利用率、重量核验”等内部审计列，但分类、手册查询、利用率判断和重量门禁仍然执行；需要人工处理的结果统一体现在样式和 `处理报告`中。

## 11. 怎样逐行核对

建议始终按以下顺序，不要先看 `part`再猜原因。

### 第一步：先看处理报告

- `无`：当前算法没有发现需要人工处置的问题。
- 有警告：逐项确认，但不要默认删除板件。
- 有严重：对应数据已被隔离，不能直接把 `part`当作完整项目数量使用。

报告可能把相同问题合并，并只列前三个代表来源；出现“等 N 行”时，应按类别筛选相应来源，不要只处理显示的三行。

### 第二步：回到原表确认源值

按报告中的“来源位置、构件编号、零件号”找到原始行，先确认：

- 是否确实缺字段；
- 长度、数量和材质是否与源表一致；
- 人工结果中的 1 mm 调整、材质后缀或余量是否有独立依据。

### 第三步：核对清洗表和构件表

- 清洗表：确认父零件身份和分类是否正确；
- 构件表：确认构件数、小计重量和构件尺寸是否属于同一构件。

### 第四步：核对整理表公式

最终整理表中最关键的列为：

| 列 | 字段 | 核对 |
|---|---|---|
| L | 长度 | 应等于源长度 |
| M、N | 左进、右进 | 当前应为空 |
| O | 下料长度 | `L-M-N` |
| S | 总数 | `构件数×数量` |
| T | 总长 | `长度×总数` |
| U | 比重 | 板材为7.85，型材为手册kg/m，或查无/冲突 |
| V、W | 理单重、理总重 | 按几何或手册公式 |
| X～AC | 源净重、源毛重及表重量 | 按单重、原数量、构件数核对 |

### 第五步：核对拆板守恒

对每个 BH、BOX、BT：

1. 检查腹板和翼板尺寸公式；
2. 检查子板“数量”是否含倍数；
3. 检查“总数=数量×构件数”；
4. 把全部子板理总重相加；
5. 与主行表毛重和源表口径比较。

### 第六步：核对 part

对每条 `part`：

1. 用导入零件号、规格、宽度、下料长度、材质筛选整理表；
2. BH/BOX/BT 还必须同时筛选导入构件编号；
3. 排除报告中的严重来源行；
4. 相加整理表“总数”；
5. 结果应等于 `part`的 G 列“汇总”。

若同名零件因 1 mm、材质或规格不同而分成多行，应先确认源数据，不能直接合并。

## 12. 三个可手算示例

### 12.1 普通板材

条件：

```text
规格 PL10*200
长度 6000 mm
原数量 2
构件数 3
```

计算：

```text
规格 = 10
宽度 = 200
总数 = 2 × 3 = 6
理单重 = 10 × 200 × 6000 × 7.85 ÷ 1,000,000 = 94.200 kg
理总重 = 94.2 × 6 = 565.200 kg
```

若源单毛重为 94.2 kg，则一个构件内的源总毛重应约为：

```text
94.2 × 原数量2 = 188.4 kg
```

项目表毛重应约为：

```text
188.4 × 构件数3 = 565.2 kg
```

没有严重问题时，`part`汇总为 6。

### 12.2 手册型材

条件：

```text
规格 L70*5
手册线重 5.397 kg/m
长度 1000 mm
原数量 2
构件数 3
```

计算：

```text
理单重 = 5.397 × 1000 ÷ 1000 = 5.397 kg
总数 = 2 × 3 = 6
理总重 = 5.397 × 6 = 32.382 kg
```

该角钢在整理表中用于重量核验，但当前规则不把成品角钢写入 `part`。

### 12.3 BOX 拆板

条件：

```text
规格 BOX100*80*10
长度 1000 mm
原数量 1
构件数 2
```

三参数 BOX 表示腹板、翼板厚度都为 10 mm：

```text
腹板：10 × (100-2×10) = 10 × 80，数量2
翼板：10 × 80，数量2
```

每块子板理单重：

```text
10 × 80 × 1000 × 7.85 ÷ 1,000,000 = 6.280 kg
```

一个 BOX 父件理论单重：

```text
6.28 × 2 + 6.28 × 2 = 25.120 kg
```

两个构件的子板理论总重：

```text
25.12 × 构件数2 = 50.240 kg
```

整理表中腹板总数为 `2×2=4`，翼板总数也为 `2×2=4`；两行理总重各 25.120 kg，合计 50.240 kg。

## 13. 问题等级与人工动作速查

| 问题 | 等级 | 是否影响 part | 人工动作 |
|---|---|---|---|
| 关键字段缺失、数值非法 | 严重 | 是 | 修正源字段后重新整理 |
| 构件身份或构件小计冲突 | 严重 | 整个构件 | 统一构件信息 |
| 单重×原数量与总重差 > 0.1 kg | 严重 | 是 | 核对单重、总重和数量 |
| 净重比毛重高 > 0.1 kg | 严重 | 是 | 核对净毛重口径 |
| BH/BOX/BT 几何不合法 | 严重 | 是 | 修正规格 |
| 同构件主零件号对应不同参数 | 严重 | 冲突零件 | 统一身份或编号 |
| 手册型材与源毛重偏差 > 2% | 严重 | 是；成品型材本身不进part | 确认规格和标准版本 |
| 板材或组合件几何理论偏差 | 警告 | 否 | 抽查轮廓和毛坯口径 |
| 净重大于理论重但未大于毛重 | 警告 | 否 | 复核模型轮廓和理论口径 |
| 源重量缺失 | 警告 | 否 | 补齐源重量，不用理论值代填 |
| 五金手册查无或冲突 | 警告 | 否 | 核对唯一手册；理论重量留空 |

## 14. 最终核对清单

交付或进入下一步分班组前，至少确认：

- [ ] `处理报告`已逐项处理；严重问题的数量影响已知。
- [ ] 材质、长度和规格没有被无依据地人工改写。
- [ ] 普通件“总数=原数量×构件数”。
- [ ] BH/BOX/BT 子板数量符合拆板倍数。
- [ ] 板材比重为7.85；型材比重按 kg/m 理解。
- [ ] 查无和冲突没有被人工随意填值。
- [ ] 源单重、总重、原数量的误差不超过0.1 kg。
- [ ] `part`同名不同参数没有被误合并。
- [ ] BH/BOX/BT 的 `part`保留构件号，普通板材和扁钢构件号为空。
- [ ] `part`汇总能由整理表“总数”逐行相加得到。
- [ ] 班组、图形、备注、文件的空白没有被误认为算法漏填。

## 15. 一句话判断规则

```text
先信原表，再看物理关系；
板材按7.85，型材查唯一手册；
参数不同不合并，严重问题不进part；
人工余量、班组和材质后缀没有依据就不猜。
```
