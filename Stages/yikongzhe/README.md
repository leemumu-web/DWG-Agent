# yikongzhe — DXF板件图形分类

对拆板后的DXF文件进行批量分类，根据每块板的外轮廓形状、内部孔洞、折弯特征判断其类别（8种）。

## 分类规则

| 类别 | 外轮廓 | 孔洞 | 折弯 |
|------|--------|------|------|
| 方 | 矩形 | 无 | 无 |
| 异 | 不规则 | 无 | 无 |
| 方孔 | 矩形 | 有 | 无 |
| 异孔 | 不规则 | 有 | 无 |
| 方折 | 矩形 | 无 | 有 |
| 异折 | 不规则 | 无 | 有 |
| 方孔折 | 矩形 | 有 | 有 |
| 异孔折 | 不规则 | 有 | 有 |

## 快速开始

```bash
uv sync
uv run python -m yikongzhe <DXF目录> -o 输出.xlsx
```

## 输入文件要求

- DXF 版本：AC1032（AutoCAD 2000）及以上
- 板件名称存在于 TEXT 实体中，格式 `p=项目号_板类型`
- 几何实体：LINE / CIRCLE / ARC / LWPOLYLINE / REGION
- 板件名称含"腹"为腹板，含"翼"为翼板
