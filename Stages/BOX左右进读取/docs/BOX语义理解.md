# BOX 语义理解（鲁棒版）

## 1. BOX 截面与板件

BOX（箱型截面）由**四块板**围成矩形箱体（命名与拆板 `PhysicalPlateRole` 对齐）：

| 拆板角色 | 输出名 | 说明 |
|---|---|---|
| `FLANGE_TOP` | 上翼 | 顶部水平板 |
| `FLANGE_BOTTOM` | 下翼 | 底部水平板 |
| `WEB_LEFT` | 上腹 | 一侧腹板（主视图正面投影与下腹重叠） |
| `WEB_RIGHT` | 下腹 | 另一侧腹板 |

**腹板合并规则（与拆板 writer 一致）**：上腹 + 下腹成对（左右进相同）时合并输出 `腹板`（×2）；只有左右腹板左右进不同才分别输出 `上腹`/`下腹`。当前读取器默认输出合并 `腹板`（绝大多数 BOX 左右腹板同长）。

截面规格：`BOX H × W × tw × tf`
- `H` = 深度（上/下翼外表面间距，主视图高度）
- `W` = 宽度（上/下腹板外表面间距，俯视图高度）
- `tw` = 腹板厚（**第 3 个数字**）
- `tf` = 翼板厚（**第 4 个数字**）

> 关键：BOX 规格第 3 数字是**腹板厚**、第 4 数字是**翼板厚**，与 BH 的 `H×B×tw×tf` 一致，不是 `tf×tw`。

## 2. 图纸布局（Tekla 单零件图）

模型空间只有 `INSERT`，几何全在匿名块 `*A1..*A18`。每张图**恰好 2 个 Part 层块**：

- **主视图（front）**：高度 ≈ 深度 `H`，长度 = 名义长度。从正面看，显示上翼（顶部水平条）、下翼（底部水平条）、左右腹板（中间投影重叠）。
- **俯视图（top）**：高度 ≈ 宽度 `W`。从顶部看，显示左右腹板（两侧竖条）与上下翼（投影）。

**主视图内线距边 = tf**（翼板厚）；**俯视图内线距边 = tw**（腹板厚）——用于验证规格顺序。

## 3. 主视图判定

1. **品红剖面标识（Section 层 A-A 剖切符号）对应的是剖面视图，不是主视图**；
2. **带零件标识（PartMark 层零件号引线）的视图是主视图**（PartMark 紧贴主视图下方）；
3. 几何上主视图高度 ≈ `H`，俯视图高度 ≈ `W`；
4. 方形 BOX（`H == W`）两视图高度相同，靠 PartMark 锚定区分；
5. **一块多视图**（罕见，如 h-4 系列）：同一匿名块内含主视图 + 其他视图，用"y 差 ≈ H/W 的长水平线对"分割，分割候选的高度用区域边界（`[lo, hi]`）而非线段 bbox。

## 4. 板件识别（源边归属，鲁棒规则）

每块板的左右边界 = 该板**自己的源边轮廓**的极值，绝不因邻近板的过渡线/圆弧"穿过带"而移动边界：

1. **材料区间**：上翼 = 顶线骨架（长水平线），下翼 = 底线骨架；翼板内线（`顶线−tf` / `底线+tf`）辅助；
2. **端部封口**：材料区间端点外 `max(2·tf, 40mm)` 窗口内、与该板带重叠的封口线（竖线/斜线/圆弧）把边界推向外侧；
3. **裁剪到带**：封口线只取它在**本板带 y 范围内**的 X 极值（`clip_x_to_band`），绝不用整条斜线/圆弧的全局极值——这是变截面箱梁（右端斜切）正确读取的关键；
4. **Primitive 级判定**：圆弧作为整体参与归属（避免离散段误判）；
5. **腹板**：中间竖板源边（排除翼板内表面水平线），端部无线时回退到主视图骨架端；
6. **连接线排除**：中心超出翼板骨架（长水平线并集）且跨越主视图高度的大斜线 = 多视图块到相邻视图的连接线，不是板件边。

## 5. 端部形式

BOX 端部可能：

- **齐平**：四块板右端一致，左右进 = 0；
- **斜切/台阶**：上翼或下翼端部短（如 h-4-cb-37 右端上翼 10078.8、下翼 9877.4，下翼右进 ≈ 201）；
- **倒角圆弧**：端部小圆角（R ≈ tf），板件边界取**直线轮廓端点**（顶线/内线），**不取倒角圆弧的极值**（用户确认 h-9-cb-72 上翼左进 = 505，即顶线端点 2836.3 − 主视图左端 2331.2）；
- **变截面（梯形）**：上下翼长度不同（如 2b1-cb-92 下翼左端短 901）。

## 6. 左右进定义

```text
左进 = 板件最左 X − 主视图最左 X
右进 = 主视图最右 X − 板件最右 X
```

- 主视图最左/最右 X = **所有板件源边边界的并集**（不含倒角圆弧极值、不含连接线）；
- 始终全局水平 X 差，不旋转、不沿斜边测距；
- 统一 mm，**严格向下取整**（`13.999999 → 13`）；
- `$INSUNITS` + BOX 深度双重验证单位，无法验证即停止输出。

## 7. 输出角色（Excel 适配）

| 输出角色 | 板件 | Excel 数量倍率 |
|---|---|---|
| `上翼` | 顶部翼板 | ×1 |
| `下翼` | 底部翼板 | ×1 |
| `腹板` | 左右腹板（主视图投影合并） | ×2 |

左右进为 `left_safe` / `right_safe` 非负整数，`下料长度 = 长度 − 左进 − 右进`。
