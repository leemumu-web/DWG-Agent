# BOX 左右进读取器

版本：`0.1.0`

使用 **uv + Python 3.12** 管理的 DXF 几何读取程序，用于从 BOX 构件图中读取上翼、下翼、左右腹板的水平左进、右进。

## 固定三步流程

1. **定位主视图**：找到带零件标识（PartMark）的纵向主视图，取得全局水平 `X_left`、`X_right`。
2. **识别实体板件**：识别上翼、下翼、左右腹板；主视图上左右腹板投影重叠，输出合并腹板。
3. **逐板读取左右进**：只读取水平 X 差值，统一输出毫米。

```text
左进 = 板件最左 X - 主视图最左 X
右进 = 主视图最右 X - 板件最右 X
```

程序不旋转构件，不沿斜边测距。坡口和斜切端使用实体轮廓中最靠外的水平 X 点。圆弧轮廓保留弧段扫过的 0°/90°/180°/270° 极值点。

## BOX 语义

BOX 截面由四块板围成箱型：**上翼板、下翼板、左腹板、右腹板**。

- **规格**：`BOX H*W*tw*tf` —— 第 3 个数字是**腹板厚 tw**，第 4 个数字是**翼板厚 tf**（与 BH 的 `H*B*tw*tf` 一致）。
- **主视图**（正面）：高度 ≈ 深度 H，长度 = 名义长度。显示上翼（顶部水平条）、下翼（底部水平条）、左右腹板（中间投影重叠）。翼板内线距边 = `tf`。
- **俯视图**：高度 ≈ 宽度 W。显示左右腹板（两侧竖条）与上下翼（投影）。

## 主视图判定

- **品红剖面标识（Section 层 A-A 剖切符号）对应的是剖面视图，不是主视图**；
- **带零件标识（PartMark 层零件号引线）的视图是主视图**（PartMark 紧贴主视图下方）；
- 几何上主视图高度 ≈ BOX 深度 H，俯视图高度 ≈ BOX 宽度 W；
- 少数图"一块多视图"（同一匿名块内含主视图 + 其他视图，如 h-4 系列）：用 y 差 ≈ H/W 的长水平线对分割。

## 板件识别（源边归属）

每块板的左右边界 = 该板**自己的源边轮廓**的极值，绝不因邻近板的过渡线/圆弧"穿过带"而移动边界：

1. 关键水平线骨架：顶线（上翼）、底线（下翼）及内线（`顶线−tf` / `底线+tf`）决定板件材料区间；
2. 端部窗口扩展：材料区间端点外 `max(2·tf, 40mm)` 窗口内、与该板带重叠的封口线（竖线/斜线/圆弧）把边界推向外侧；
3. Primitive 级判定：圆弧作为整体参与归属（避免离散段误判），圆弧极值点保留；
4. 腹板：中间竖板源边材料区间 + 端部扩展。

## 单位与安全取整

- `$INSUNITS` 决定坐标单位；标题栏 `1:20` 等只是出图显示比例；
- 单位由 `$INSUNITS` + BOX 深度（主视图高度）双重验证，无法验证时停止输出；
- 最终结果统一为 `mm`，**严格向下取整**（避免下料偏短）：`13.999999 → 13`。

## 环境与运行

```bash
uv python install 3.12
uv sync
uv run box-reader /path/to/dxf_directory \
  --config config/default.toml \
  --output outputs/BOX左右进结果.xlsx \
  --json outputs/BOX左右进诊断.json \
  --measurements outputs/box-measurements.json \
  --visual-dir outputs/校验图
```

支持多个文件、目录或通配符（含绝对路径通配符）。`--no-visuals` 关闭 PNG；`-q/--quiet` 关闭进度与写入提示，仅保留最终汇总（脚本化使用）。

## 输出与 Excel 适配

BOX 有四块板（与拆板 `PhysicalPlateRole` 对齐）：**上翼(FLANGE_TOP)、下翼(FLANGE_BOTTOM)、上腹(WEB_LEFT)、下腹(WEB_RIGHT)**。

**输出与拆板完全同步**（上下板件左右进相同则合并、不同则区分，对应拆板 equivalence 的成对合并）：

| 输出角色 | 触发条件 | Excel 数量倍率 |
|---|---|---|
| `翼` | 上翼+下翼左右进相同（合并） | ×2 |
| `上翼` / `下翼` | 上下翼左右进不同（区分） | ×1 |
| `腹` | 上腹+下腹左右进相同（合并） | ×2 |
| `上腹` / `下腹` | 上下腹左右进不同（区分） | ×1 |

上腹/下腹（WEB_LEFT/WEB_RIGHT）从俯视图两侧条带读取（主视图正面投影重叠无法区分）；俯视图不可靠时回退主视图腹板带源边（合并"腹"）。诊断 `top_webs` 始终提供上腹/下腹各自边界。

`--measurements` 输出 **BOX 测量合同**（`schema: box_setback_measurements/v1`），字段与 BH 的 `bh-measurements.json` 对齐：每张图 `{file_name, part_number, specification, status, warnings, measurements[{role, left_safe, right_safe, left_raw, right_raw}]}`。

该合同可直接被主流程 Excel 第二阶段的整理表/part 表深化消费：`下料长度 = 长度 − 左进 − 右进`，规格三方核对用 `BOX H×W×tw×tf`（第 3 数字=腹板厚、第 4 数字=翼板厚）。

## 已知限制与人工处理

- **折线（多段弯折）构件**（如 h-4-cb-37/38）：主视图为整条折线路径（块高被斜段拉大），
  读取器输出 `ERROR_CRANKED_UNSUPPORTED`（含诊断），**Excel 第二阶段自动走"读取失败需补录"
  标红路径由人工处理**，绝不出错误读数。折线板件的完整读取（截面线对→四链追踪）已有
  原型验证（416/0、0/391、0/394 可达），留作未来可选项。
- **小坡口（18-58mm）上下腹区分**：拆板对"web_left 端部坡口"（如 w4e 系）判定拆分、
  对"翼板内表面台阶端"（如 3t1 系）判定合并；两者在主/俯视图竖线结构上信息论不可区分
  （已由独立审查确认），读取器保守合并（与拆板"两块相同"的图一致）。w4e/6b5 系 7 张
  与 2b1-cb-91/92 的 18-38mm 腹板坡口读取为 0（拆板为 18-38）。
- 端部竖线统一模型（web_left=内侧竖线/web_right=外侧竖线）曾实现后被回滚：它在真实拆分
  图（2b1-cb-86 477/332、h-9-cb-133 1000、h-9-cb-94 866）上正确，但在 3t1 系等台阶端
  图上误拆分（58/28/43），属过拟合，回滚后 3t1 系保持与拆板一致（0/0）。

## 测试

```bash
uv run python -m unittest discover -s tests -v
```

真实数据目录用 `BOX_READER_PRE_DXF_DIRECTORY` 覆盖（默认指向 BOX 拆板前目录）。253 张
真实 BOX 图回归（244 OK + 9 单位验证失败 + 2 折线标红），全部生成校验 PNG。对照拆板
（`tools/verify_against_splitter.py`，拆板 report.json 93 张）：腹板对齐 80/93、翼板对齐
87/93，差异集中于上述已知限制。独立核验（`tools/verify_independent.py`）交叉核验板件边界。

