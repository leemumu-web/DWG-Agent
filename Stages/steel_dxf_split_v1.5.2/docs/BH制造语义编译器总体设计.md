# BH 制造语义编译器总体设计

## 1. 问题定义

输入不是一个已经拆好的板件模型，而是一张用于人类阅读的钢结构深化图。图纸同时包含：

- 一个物理 BH 构件的多个正交投影；
- 材料表、零件号、截面、长度、材质和数量；
- 可见轮廓、隐藏轮廓、中心线、孔符号、尺寸和剖面；
- 图框、标题栏和其他无关图形。

输出要求是制造对象：腹板、两块翼缘板及其真实切割特征。投影线、尺寸线和中心线不能进入生产轮廓。

因此问题不是普通图层提取，而是：

```text
二维绘图语言 → 工程语义 → 物理装配体 → 制造板件
```

## 2. 编译器类比

| 编译器概念 | BH 拆板系统 |
|---|---|
| 源语言 | DXF 标签、块、图层、实体、文字和投影约定 |
| 词法/语法分析 | DXF 读取、INSERT 展开、实体分类、文字空间分组 |
| AST / Source IR | 带来源的块、实体、文字、变换和可见性 |
| 类型系统 | BH 截面、腹板/翼缘板角色、孔/开口特征类型 |
| 语义分析 | 视图角色、投影关系、板件身份和特征归属 |
| 优化/求解 | 完整构件假设、硬约束、软证据、最小修复 |
| 中间代码 | Manufacturing IR |
| 代码生成 | 清洁 DXF R2007 |
| 静态检查 | 几何、物理、来源和输出不变量 |
| 测试 | 人工拆板监督回归 |

## 3. 分层信息模型

### 3.1 Fact IR：只陈述观察事实

Fact IR 不回答“这是不是腹板”，只记录：

- 模型空间存在某个 INSERT；
- INSERT 的插入点、缩放和旋转；
- 展开后存在某个 LINE/ARC/CIRCLE；
- 实体位于某个图层并使用某种线型；
- 某段文字位于某个坐标；
- 实体来自哪个块和哪个源句柄。

原则：**事实不因后续判断而丢失。**

### 3.2 Geometry IR：只陈述几何关系

- 端点和交点；
- 连通边链；
- 闭合面；
- 面邻接；
- 内外包含；
- 平行、共线、圆周拟合；
- 纵向和横向投影。

原则：**几何结构与工程角色分离。**

### 3.3 Semantic IR：声明可验证的工程解释

- 某个表格行解释为 BH 元数据；
- 某个块解释为腹板投影；
- 某个块解释为翼缘投影；
- 某个面解释为腹板；
- 某个圆解释为属于某块板的切割孔；
- 两个翼缘是否共享同一制造几何。

所有解释都应携带：

```text
来源
得分
证据
备选解释
置信度
修复代价
```

### 3.4 Manufacturing IR：唯一可写出的制造事实

只有通过完整约束检查的对象才能进入 Manufacturing IR：

```text
Plate
├── physical identity
├── role
├── quantity
├── thickness
├── closed outer contour
├── circular cuts
├── shaped openings
├── canonical label
└── provenance
```

## 4. 完整构件假设

局部判断可能正确，也可能因为复杂投影而错误。因此系统不再执行：

```text
选主视图 → 不可撤销
```

而是执行：

```text
候选视图对
→ 完整重建腹板
→ 完整重建翼缘
→ 分配切割特征
→ 生成制造装配
→ 验证所有硬约束
→ 计算软证据代价
```

候选只有完成制造降级后才具有可比性。

## 5. 硬约束与软证据

### 5.1 硬约束

硬约束代表违反后不能生产：

- 主视图和翼缘视图不能是同一投影；
- 必须得到一个腹板；
- 必须得到两块物理翼缘板；
- 板厚、翼缘宽度和数量必须匹配截面；
- 所有轮廓必须合法闭合；
- 孔和开口必须完整位于所属板内；
- 切割特征不得重复或重叠；
- 每块板必须具有来源链。

### 5.2 软证据

软证据用于在多个合法解释之间排序：

- 投影尺寸与 `L×H`、`L×B` 的拟合；
- 材料表和零件标记一致；
- 孔标记和实际孔径一致；
- 几何修复次数和精度松弛量；
- 展开长度相对于名义长度的合理性；
- 证据覆盖率。

尺寸文字和孔标记不会直接覆盖真实几何，而是作为独立通道验证。

## 6. 几何恢复策略

### 6.1 可见面优先

可见 `Part` 实线首先用于节点化和面域重建。

### 6.2 隐藏线只作为受控证据

隐藏线不能直接进入制造轮廓。只有满足严格条件时才用于：

- 补齐位于外包边界的小型端面；
- 将短弦链恢复为有完整端点和圆周证据的精确圆弧；
- 区分重叠翼缘中的孔归属。

### 6.3 最小修复原则

候选解释可以执行：

- 端部面补全；
- 小毛刺形态学修复；
- 精度网格调整；
- 投影路径展开。

每项修复都进入代价函数。系统优先选择不需要修复或修复最少的完整合法解释。

## 7. 切割特征归属

切割特征是板件的子对象，不属于“整个构件”。

归属流程：

1. 识别真实物理切割实体；
2. 根据投影视图和面包含关系列出候选板；
3. 若候选唯一，直接归属；
4. 若投影重叠，使用边视孔符号、板件长度和侧向关系消歧；
5. 无法唯一归属时拒绝，而不是复制到多块板。

## 8. 语义图

语义图包含：

- `component`；
- `profile`；
- `hypothesis`；
- `rule`；
- `view`；
- `plate`；
- `cut`；
- `opening`；
- `annotation`；
- `source_block`。

典型关系：

```text
component --has_profile--> profile
component --selected_as--> hypothesis
hypothesis --interprets--> source_block
hypothesis --evaluated_by--> rule
component --has_plate--> plate
plate --generated_by--> hypothesis
plate --derived_from--> view
plate --has_cut--> cut
component --supported_by/contradicted_by--> annotation
```

该图使错误定位从“结果不对”提升为：

- 元数据解释错误；
- 视图角色错误；
- 面域候选错误；
- 特征归属错误；
- 某项工程规则冲突；
- 输出后端错误。

## 9. 质量门

### 9.1 置信度分解

```text
confidence =
  0.35 × projection model fit
+ 0.35 × semantic rule quality
+ 0.20 × hypothesis separation
+ 0.10 × independent evidence coverage
```

该公式不替代硬约束。硬约束失败时置信度直接为 0。

### 9.2 处置

```text
confidence ≥ review threshold
    → auto_accept

minimum threshold ≤ confidence < review threshold
或候选分差太小/证据覆盖不足
    → review_required

confidence < minimum threshold
或硬约束失败
    → reject
```

## 10. 20 组语料体现的能力维度

现有样本不是 20 个独立特例，而是以下能力的组合：

- 等高与变高度；
- 直线、斜切、折线和错层；
- 相同翼缘与不同翼缘；
- 无孔、腹板孔和翼缘孔；
- 圆孔和异形内开口；
- 可见圆弧和隐藏精确圆弧证据；
- 完整面和端部分裂面；
- 干净拓扑和亚毫米毛刺。

代码禁止出现样本名称分支。回归测试检查所有 `_拆板前` 文件名不得出现在 `bh_*.py` 中。

## 11. 仍需扩展的真实语义

### 11.1 关联尺寸图

当前能够读取尺寸文字，但尚未完整关联尺寸界线、定义点和被测边。未来应构造 `DimensionGraph`。

### 11.2 焊缝装配图

当前输出板件，但尚未显式表示腹板与翼缘之间的焊缝、坡口和装配基准。

### 11.3 质量守恒

当材料表提供单重时，应将面积、厚度和钢材密度形成独立质量约束。

### 11.4 多构件图纸

需要先建立 `MemberContext`，根据 PartMark、局部视图邻近性和投影对齐将整张图分割为多个构件编译单元。

## 12. 失败优先原则

制造系统的目标不是“尽量输出一个结果”，而是：

```text
证据充分 → 自动输出
证据冲突 → 明确复核
语义不完整 → 拒绝生成
```

这比用高容差、凸包或默认矩形掩盖未知情况更安全，也更具泛化能力。
