# BH 视图统一度量比例设计

## 目标

在不改变现有 1:1 BH 判断与制造产物的前提下，使编译器能够依据独立证据识别并恢复腹板、翼缘视图共同存在的等比例缩放。当前目标样本为 `a1-3-cb-234`、`a1-3-cb-258`、`a1-3-cb-414`。

## 单流程架构

比例解析属于每个腹板/翼缘候选的度量坐标框架，不是失败后的第二次拆板。候选生成时先计算源图比例证据；只有非 1:1 比例得到完整证明时，才给该候选附加一个统一换算系数。随后候选只执行一次几何降低、一次约束验证和一次制造 IR 冻结。

现有 1:1 候选使用恒等变换，保留原候选排序、轮廓提取和证明逻辑。正常图不因缺少孔标而新增拒绝条件。

## 比例证明

每个候选产生以下四组几何换算系数：

- 构件长度 / 腹板纵向跨度；
- 梁高 / 腹板横向跨度；
- 构件长度 / 翼缘纵向跨度；
- 翼缘宽 / 翼缘横向跨度。

物理圆孔通过来源 ID 与所属视图的孔标关联，产生：

- 标注孔径 / 源圆孔直径。

仅当几何四项相互收敛、至少一项孔径证据与其收敛、X/Y 为等比、腹板与翼缘使用同一系数，并且该系数明显偏离 1 时，才授权比例恢复。比例文本不参与计算，不硬编码 `0.5/1.5/2`。证据不足或冲突时不恢复，仍由现有流程保持拒绝或人工复核。

## 几何变换

比例恢复在候选工作副本中执行，源 DXF、事实 IR 和来源 ID 均保持不变。一个统一矩阵同时作用于：

- Part 线和圆弧；
- Bolt 圆孔、线孔和辅助符号；
- PartMark/BoltMark 遮罩；
- 候选降低所见的其他运行时实体。

变换后的候选继续调用原 `lower_bh_assembly`，不新增另一套板件算法。

## 证明与追溯

候选报告记录模式、换算系数、每项观测值、期望值、相对离散度和来源 ID。新增关键证明义务用于声明非 1:1 变换是否得到授权；原投影对应、装配重建、制造几何和来源完整性证明继续生效。

## 验收

- 三张目标图均通过比例准入并进入原制造约束。
- 对非等比、腹板/翼缘比例冲突、孔径冲突、缺少孔标的非 1:1 图保持拒绝。
- 现有 178 张自动通过 BH 的制造几何与语义指纹不变。
- BOX 代码路径和 BOX 黄金样例保持只读且不受影响。
