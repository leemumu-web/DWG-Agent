# BOX 独立多视图拆板设计

## 1. 决策

BOX 拆板采用独立的领域算法。BH 只提供以下工程模式参考：

- 事实、证据、候选、完整解和输出逐层分离；
- 保留多个视图解释，完成制造几何降级后再选择；
- 硬约束与软证据隔离；
- 证据不足、多解或未知图型时 fail-closed；
- 完整批次通过质量门后原子写出。

BOX 正式路径不得调用 `extract_box_assembly()`、`parse_metadata()` 或任何
`bh_*` 领域模块。允许复用的只有中性基础设施，包括 DXF 文件读取、基础输出
数据结构、通用 validator、layout 和 writer。中性能力若当前位于 BH 模块中，
必须先提取到无领域含义的模块，BOX 不得反向依赖 BH。

最终数据流为：

```text
DXF
→ BoxSourceFactsV1
→ BoxMetadataEvidence
→ BoxGeometryIR
→ BoxViewIR
→ BoxReconstructionHypothesis
→ BoxCompleteSolution
→ BoxManufacturingIR
→ 制造合同
→ SplitAssembly 适配
→ 原子写出和回读验证
```

`SplitAssembly` 只是通过质量门后的中性输出容器，不参与 BOX 的事实解释、
候选生成、角色分配或几何授权。

## 2. 目标和适用范围

目标是处理采用二维正投影视图表达的焊接 BOX 板件详图，包括原图不存在四块
现成闭合板轮廓、只有主视图、俯视图、剖视图及其投影线的情况。

算法面向制造板件重建，而不是通用三维实体重建。它应恢复：

- 两块翼缘板和两块腹板；
- 每块板的二维切割外轮廓；
- 可证明的内轮廓和孔；
- 板厚、角色、数量和标签；
- 每条重建边、每个孔和每项元数据的来源证据。

已证明适用范围由监督样例和通用性测试共同界定。系统不得把 20 组样例的通过
包装成对所有 CAD 来源、所有制图规范和所有 BOX 表达方式的无限保证。未知或
歧义图型应稳定进入 `manual_review` 或 `reject`。

## 3. 非目标

- 不迁移 AutoLISP、COM/VLA、活动文档、选择集、爆炸块或 WBLOCK。
- 不依赖 DXF handle、实体遍历顺序、文件名白名单或固定图纸坐标。
- 不假设图纸左、右、上、下的固定视图角色。
- 不把某个图层名、块名或线型作为几何成立的唯一证据。
- 不允许 BOX 截面文字单独生成四个矩形。
- 不从拆板后 DXF 读取几何参与生产运行。
- 不为了提高通过率而放宽唯一解、孔归属或来源追踪门禁。

## 4. 来源事实与元数据

`BoxSourceFactsV1` 是确定性、有限输入、只读的 DXF 快照。它保留：

- 标准化的 LINE、ARC、CIRCLE、LWPOLYLINE；
- 有限展平的 HATCH 边界及闭合状态；
- 原始和规范化文字；
- 块实例路径、插入变换和来源作用域；
- 图层、线型、闭合状态和诊断信息；
- 不包含 handle 的稳定 `source_key`；
- 对规范化内容计算的 SHA-256 fingerprint；
- 最大实体数、文字数、点数、块深度和坐标绝对值限制。

新增 `BoxMetadataEvidence`，独立解析：

- 构件号和零件号；
- `BOX H*B*T1*T2` 截面；
- 名义长度；
- 材质、数量和重量；
- 图纸比例和单位；
- 每个字段的来源文字、作用域、置信度和冲突诊断。

20 组拆板前后样例用于验证 `H/B/T1/T2` 在当前制图规范中的真实含义。任何
宽高或板厚映射在冻结前都只是待验证假设。

文字可以约束身份、尺寸、截面和排序，但 `can_authorize_geometry` 永远为
`False`。没有图元或视图拓扑证据时，文字不能创建板件 Polygon、关闭轮廓或
决定孔归属。

## 5. 几何 IR

`BoxGeometryIR` 将全部受支持图元变换到统一二维坐标，并保留来源。它负责：

- 弧和 bulge 的有界误差离散；
- 自适应精度网格和端点吸附；
- 端点连通区域、noding 和 polygonize；
- 直接闭合区域、开放投影链、平行线组和剖面闭环；
- 外轮廓、内环、孔证据及辅助几何分类；
- bbox、质心、最小旋转矩形、主轴和拓扑邻接；
- 所有修复、拒绝和容差的诊断账本。

bbox 只允许用于空间索引和预筛。最终区域关系必须使用 Shapely
`covers`、`contains`、`intersection`、边界距离和面积比例证明。

候选必须保留真实 `Polygon` 或可追踪的开放投影链，不能只保留长、宽和面积。

圆只有在不属于标注通道时才是强孔证据。标注层圆必须记录
`ambiguous_annotation_circle` 并阻断自动制造。HATCH 不以层名证明辅助性质：
边界必须进入 Source Facts；只有其填充与每个候选投影视图区域分离，或边界被同一
来源作用域且已进入角色视图的物理投影线完整覆盖时才能忽略；标注线不能授权 HATCH，
否则拒绝。

## 6. 视图 IR 与跨视图配准

新增 `BoxViewIR`。视图发现首先按来源作用域和端点拓扑形成局部几何簇，再为
每个簇计算：

- 主轴和局部坐标；
- 长度方向站位 `s`；
- 横向坐标 `u`；
- 长度跨度、横向跨度和边界复杂度；
- 闭环、开放链、平行线和剖面特征；
- 实体、隐藏、中心、尺寸和未知可见性证据；
- 与元数据尺寸的残差。

系统枚举而不是预先绑定视图角色：

- 纵向高度投影；
- 纵向宽度投影；
- BOX 剖面投影；
- 辅助或未知视图。

不同纵向视图使用同一 DXF 单位下的归一化站位 `s`。站位增量默认是物理标量，只在
目标视图自己的局部纵轴中传播。若要使用纸面轴换算，必须找到至少 3 个紧残差站位
对应，其中至少 1 个是内部站位，匹配跨度覆盖不少于两侧共同站位跨度的 80%，且两侧
纵轴方向兼容。方向接近或端点跨度接近本身都不能证明两个视图共享纸面坐标。配准不
依赖绝对纸面平移，每个候选记录 station scale、offset、最大匹配残差、匹配数量、
内部匹配数量、覆盖率、参与来源和是否获得纸面换算资格。

topology fallback 不按图层组合枚举，而按几何长度种子、邻接端点和连通分量形成候选；
单个闭合 LWPOLYLINE 也可作为完整可见轮廓形成分量。图层只保存为来源证据。候选域
必须有明确的 facts、单分量和候选组预算，超限直接拒绝。
同一角色有多个候选时不得用 `view_id` 决胜；只有第一、第二候选达到明确安全分差时，
才可删除被支配候选，否则全部保留给有限域求解。

## 7. 板件重建

重建提供两种来源模式。

### 7.1 `direct_contour`

当原图存在有效、非退化且来源完整的闭合制造轮廓时，直接形成板件候选。
图层和文字只能辅助分类，Polygon 本身必须由物理图元拓扑证明。

### 7.2 `multi_view_reconstruction`

当只有投影线时，程序组合：

- 一个或多个纵向视图的长度边界；
- 另一投影视图或剖面的横向跨度；
- 剖面中的四板组成和板厚关系；
- 长度站位上的端点、折点、缺口和圆弧对应；
- 孔在不同投影视图中的站位和横向坐标。

输出 `BoxReconstructionHypothesis`。每个假设包含：

- 制造 Polygon 和内轮廓；
- 候选角色族；
- 使用的视图和配准；
- 边级 provenance；
- 孔投影及归属证据；
- 几何修复账本；
- 尺寸、投影和质量残差；
- 硬拒绝原因和软证据。

任一生成边都必须来自：

1. 直接物理图元；或
2. 两个已配准投影约束的交集；或
3. 物理投影边加上已证明的剖面横向跨度。

截面文字不能成为唯一的边生成来源。

## 8. 孔和内轮廓

孔处理遵守证据通道隔离：

- 真实 CIRCLE 或闭合物理孔轮廓是切割证据；
- 中心线、十字线、隐藏线和孔标注只能辅助匹配；
- 孔先转换为所在视图的 `s/u` 事件，再跨视图恢复制造坐标；
- bbox 预筛后，使用 Shapely 材料区域覆盖和边界净距验证；
- 一个孔只能归属一个物理板件实例；
- 投影重复孔必须确定性去重并保留全部来源；
- 多归属、无归属或跨视图匹配不唯一时不得自动输出。

## 9. 完整四板有限域求解

求解变量为四个固定角色：

- `upper_flange`
- `lower_flange`
- `left_web`
- `right_web`

候选域来自直接轮廓和多视图重建假设。一个已证明的板件原型可以按 BOX 物理
拓扑实例化为对称的两个角色，但数量关系必须由截面装配规则证明，不能为了凑
齐四块而复制任意候选。

硬约束包括：

- 四个角色完整；
- 每个制造 Polygon 有效、闭合、正面积；
- 翼缘/腹板厚度和横向尺寸与已证明截面拓扑一致；
- 长度站位及跨视图投影一致；
- 四板装配后的截面尺寸闭合；
- 每条生成边和每个孔来源完整；
- 孔唯一归属且位于材料区域；
- 未分类物理几何不会改变成品轮廓；
- 单位和比例明确；
- 四板批次制造合同完整。

软证据包括：

- 文字身份和标注一致性；
- 重量和面积残差；
- 投影配准残差；
- 最小几何修复；
- 独立证据覆盖率。

软证据不能挽救任何硬约束失败。

上/下翼缘或左/右腹板的纯对称交换归一化为同一制造解。若归一化后不存在完整
解则 `reject`；存在完整解但多个非等价方案差距不足则 `manual_review`；只有
唯一或充分分离的完整解才允许 `pass`。

## 10. 制造 IR、质量门和输出

`BoxManufacturingIR` 是 solver 的权威结果，包含：

- 四个角色及其 Polygon；
- 板厚、标签、孔和内轮廓；
- 候选、视图、事实 fingerprint 和边级 provenance；
- 求解残差、风险和拒绝过的竞争方案；
- 生产授权状态。

`BoxManufacturingIR` 通过合同后才适配为 `SplitAssembly`。制造合同必须直接
验证 solver 产出的几何，不再把新 solver 与旧 extractor 生成的 assembly
相互比较。

所有目标 DXF 和 JSON 报告先写入同盘临时目录，全部保存、回读、审计成功后
统一提升。任一失败不得留下部分正式输出。

## 11. 通用性合同

生产算法禁止使用样例文件名、零件号白名单、固定坐标、handle、固定块名、
固定实体数量或验收集答案。

以下等价变换不得改变物理制造结果：

- 整图平移和旋转；
- 视图重新排布；
- 实体遍历顺序变化；
- handle 和块名变化；
- 等价块嵌套或展开；
- 当前实现只接受明确毫米单位（`$INSUNITS=4`）；其他可换算单位属于后续扩展，
  在建立全链路单位换算与变形测试前必须 fail closed；
- 标定范围内的端点扰动；
- 增加不改变物理拓扑的尺寸线、中心线和重复辅助线。

这些要求使用 metamorphic tests 验证。变化后的事实 fingerprint 可以因真实
表达变化而改变，但制造语义 fingerprint 和归一化成品几何必须一致。

## 12. 20 组监督样例

权威根目录为：

```text
D:\DevData\BOX拆板前后数据
```

拆板后 DXF 只用于离线真值比较。样例先按结构类型分层，再形成校准集和冻结
验收集，至少区分：

- 等截面直板；
- 斜端、折线或偏置；
- 变截面；
- 有孔和无孔；
- 两块同形板；
- 同形但孔不同；
- 辅助线污染和多候选。

校准阶段确定视图配准、端点吸附、轮廓比较、孔中心和半径容差。验收阶段不得
再调整这些阈值。每对样例必须输出逐板 verdict、轮廓偏差、孔偏差、角色匹配、
来源覆盖和失败原因。

20 组全部通过只能证明当前制图分布。最终报告必须分别列出已证明范围、未知
图型、拒绝边界和仍需新增样例的结构类型。

## 13. 实施顺序

1. 写架构测试，禁止 BOX 正式路径和监督路径导入旧 extractor 或 `bh_*`。
2. 建立 BOX 独立元数据证据，摆脱旧材料表解析。
3. 扩展几何 IR，使开放投影链与闭合区域同为一等证据。
4. 实现 `BoxViewIR` 和与纸面位置无关的视图候选。
5. 实现跨视图站位配准和板件重建假设。
6. 重写完整四板 solver，保留 Polygon、孔和边级 provenance。
7. 建立 `BoxManufacturingIR`、制造合同和 `SplitAssembly` 适配。
8. 将 BOX pipeline 切换为新 compiler 的权威输出。
9. 进行 20 组结构普查、校准、冻结验收和通用性变形测试。
10. 更新 CAD Agent 只读迁移矩阵和最终验证报告。

## 14. 验收标准

- BOX 运行时代码不导入或调用旧 extractor 和任何 `bh_*` 领域模块。
- 文字证据不能在空几何上产生板件。
- 直接闭合轮廓和多视图投影均可进入统一完整解求解。
- solver 选择的 Polygon 直接成为最终板件轮廓。
- 每条重建边和每个孔可追溯到 BOX source facts。
- 多解、孔多归属、视图配准失败和未知物理几何稳定 fail-closed。
- 平移、旋转、视图重排、handle 变化和实体重排不改变归一化制造结果。
- 校准集与冻结验收集没有数据泄漏。
- 保存后 DXF 四板完整、轮廓闭合、孔清洁且无辅助线污染。
- 20 组样例具有逐对 verdict；未通过项阻止生产门冻结。
- CAD Agent 目录在任务前后没有因本项目产生任何修改。
