# BH 二十组监督回归：端部拓扑补全与圆弧证据

## 1. 本轮目标

v0.9.0 不增加按文件名分支，而是用 6 组新增人工拆板结果检验 v0.8 的 BH 语义编译器。新增样本暴露了两类可泛化缺陷：

1. 投影线将真实板件端部切成“主体面 + 狭长端面”；
2. 可见轮廓用短弦近似圆弧，而精确 ARC 位于隐藏线中。

本轮将它们分别建模为：

```text
Boundary Completion Pass
Arc Evidence Recovery Pass
```

并用全部 20 组 BH 数据执行监督回归。

## 2. 信息流

```text
DXF/INSERT
  → Source IR（实体、图层、线型、来源）
  → Geometry IR（节点化边、面域、邻接、源圆弧）
  → Semantic IR（主视图、翼缘视图、板件角色、切割特征）
  → Candidate Solver（主体面、端部补全面、圆弧证据链）
  → Manufacturing IR（板件、数量、厚度、孔、内开口、来源）
  → DXF Backend
  → Invariant + Manual Supervision
```

## 3. 纵向端部面拓扑补全

### 3.1 问题

长构件投影中，端部可能被另一投影视线切开。polygonize 后得到：

```text
主体面 P
端部窄面 E
```

若只选择面积最大或包含孔的面，最终长度会偏短。

### 3.2 候选条件

端部面只有在以下条件全部成立时才能合并：

- 位于主体长轴的最小端或最大端；
- 与主体面接触或在精度容差内相接；
- 横向投影重合达到规定比例；
- 横向跨度覆盖主体板高的主要部分；
- 长轴尺寸显著小于主体长度；
- 合并后没有异常增加板高；
- 合并后仍为单一合法 Polygon；
- 面积和包围盒变化符合工程尺寸约束。

算法不会因为一个面“靠近端部”就自动合并，也不会使用构件号或固定坐标。

### 3.3 选择来源

补全候选来自两套面域：

```text
solid faces       可见 Part 实线
solid+hidden faces 包含隐藏 Part 边的证据面
```

隐藏边只帮助确认端部边界，不直接写入生产 DXF。

## 4. 微拓扑正则化

重复投影线和亚毫米错位可能制造细长毛刺。v0.9 使用受约束的形态学开闭运算：

```text
P' = buffer(buffer(buffer(P, -ε), 2ε), -ε)
```

仅当以下条件同时满足才接受：

- 相对面积变化不超过 `1e-4`；
- 包围盒最大变化不超过 `0.02 mm`；
- 输出仍为单一合法面；
- 不删除真实孔或内开口。

这不是任意平滑，而是带守恒检查的微拓扑修复。

## 5. 隐藏 ARC 作为制造圆弧证据

### 5.1 问题

某些导出文件将可见圆角拆成多条短 LINE，但保留一条隐藏 ARC。若只读取可见圆弧，输出会变成折线近似。

### 5.2 证据规则

隐藏 ARC 不能直接替换任意折线。只有当一段连续折线链满足：

- 链首尾分别落在同一源 ARC 的两个端点附近；
- 链方向与 ARC 扫掠方向一致；
- 中间节点到圆的径向误差受限；
- 链的最大弦高小于阈值；
- 使用的是完整连续链，而不是单一偶然弦段；

才将该链恢复为一个 bulge 圆弧段。

这避免把普通斜边或局部折线误判成圆弧。

## 6. 翼缘展开回归保护

端部正则化后，几何对象可能不再与原面 `equals()`。若仅用对象精确相等排除腹板面，腹板可能误进入翼缘路径计算。

v0.9 改用覆盖率判定：

```text
area(face ∩ buffer(web, 0.25)) / area(face) ≥ 0.98
```

从而稳定排除腹板面，同时保留变高度构件的两条不同翼缘展开路径。

## 7. 监督与制造不变量

每组数据必须同时满足：

- 人工板件数量一致；
- 归一化外轮廓 Hausdorff 距离 ≤ 0.15 mm；
- 孔心差 ≤ 0.01 mm；
- 孔径差 ≤ 0.01 mm；
- 异形内开口数量和形状一致；
- DXF audit errors = 0；
- LINE/XLINE/RAY = 0；
- 所有板件轮廓闭合；
- 所有孔和开口归属于具体板件。

## 8. 二十组覆盖范围

语料覆盖：

- 等高和变高度 BH；
- 直梁、折线梁、错层梁；
- 相同和不同翼缘；
- 无孔腹板；
- 多孔径混合；
- 腹板孔和翼缘孔；
- 圆角内开口；
- R10/R35/R45 等圆弧与锁口；
- 投影重叠；
- 端部被切分的多面拓扑；
- 可见短弦 + 隐藏精确 ARC。

监督数据不是运行时模板。运行时算法只读取源 DXF；人工拆板文件只用于测试和验收。
