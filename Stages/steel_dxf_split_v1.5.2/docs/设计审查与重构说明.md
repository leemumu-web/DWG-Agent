# v0.3.0 → v0.4.0 设计审查与重构说明

## 结论

v0.3.0 的四块主体板尺寸和质量结果基本正确，但输出层混入了不应存在的十字辅助线；同时，多处算法是“刚好适配当前实体顺序”，不是可靠的几何识别。v0.4.0 保留已验证的尺寸结果，重写轮廓与栓钉识别，并将切割输出和人工复核输出彻底分离。

## 发现的问题

### 1. 人工生成十字线

旧版 `_add_plate()` 为每个栓钉生成：

```text
1 个 CIRCLE + 2 个 LINE
```

B7 文件因此产生：

```text
160 个圆 + 320 条十字线
```

这些线不是板件切割轮廓，也不是源图真实的切割孔。CAM 或后续几何聚类程序可能把它们误认为开放轮廓、刻线或待处理特征。

### 2. 源栓钉符号被误解

源文件中的主要栓钉符号不是“圆加十字”，而是两个同心八边形，每个符号由 16 条短线组成。旧程序读取中心后又重新画了十字，改变了原始表达。

### 3. 依赖实体顺序

旧算法按每连续 16 条线分组：

```python
for start in range(0, len(lines), 16):
    group = lines[start:start + 16]
```

DXF 实体顺序一旦被 CAD 保存、审计、炸开或重排，分组就可能失效。

新版通过端点拓扑寻找闭合小环，再把同心环中心聚类为一个语义栓钉点；将实体列表逆序后仍得到相同的 40 个中心。

### 4. 凸包不等于真实外轮廓

旧版以所有较长 `Part` 线端点的凸包作为外轮廓。凸包会：

- 吞掉凹口；
- 跨过缺口；
- 把内部辅助线带来的极值点误纳入轮廓；
- 无法证明边之间真实相连。

新版使用 `edgeminer + edgesmith` 从端点连接关系直接查找闭合环，再按实际长度、截面宽度和面积选择候选。

### 5. 内轮廓存在多个合法闭环

L5 的腹板视图中存在多个宽度均为 518 mm 的闭环。其中一个长度约 5607 mm，但包含右端局部结构；真实腹板长度约 5291 mm。

因此新版不在几何阶段武断选择“最大内环”，而是：

```text
枚举所有满足净宽的内环
+ 平行内边线重建候选
+ 计算四块板理论质量
+ 与材料表单重比较
```

最终自动选中重量误差 0.1628% 的 5291 mm 方案。

### 6. 物理厚度与图纸缩放混合

旧版 `Plate.scaled()` 同时缩放轮廓、板厚和栓钉直径。板厚是物理属性，不应因为生成 1:20 复核图而变成 1.4 mm。

新版使用 `scaled_geometry()`：只缩放绘图坐标；板厚和材料质量语义保持实际值。

### 7. 仅用包围盒检查栓钉

旧版检查中心是否在矩形包围盒内。对斜切、凹形或异形板件，位于包围盒内不等于位于板内。

新版使用点在多边形内判断，并检查整个 D19 圆是否距离板边至少 9.5 mm。当前 B7 最小边距约 22 mm。

### 8. 输出验证没有检查十字线

旧版只检查 DXF 审计和实体数量，没有禁止 `STUD_MARK:LINE`。

新版对每个输出文件执行：

```text
生成图层上的 LINE/XLINE/RAY 数量必须为 0
清洁图 STUD_REFERENCE 实体必须为 0
复核图 STUD_REFERENCE 只能是 CIRCLE 或 POINT
PLATE_CUT 必须恰好为 4 个闭合 LWPOLYLINE
CUT_HOLE 必须为 0
```

## 新输出分层

### 清洁 1:1

只包含：

- 4 个闭合 `PLATE_CUT`；
- 4 个零件标签；
- 说明文字。

不包含栓钉图形、十字线或源辅助线，适合继续交给 CAM 或排版模块。

### 复核 1:1

在清洁图基础上，可选：

- `circle`：每个栓钉只生成一个圆；
- `point`：每个栓钉只生成一个 POINT；
- `none`：不显示。

任何模式都不会生成十字线。

### 图纸比例复核图

保留图框、材料表和标题栏；新板件按原比例排布。栓钉默认用圆复核，不生成十字线。

## 几何结果与旧版对比

四块板切割轮廓没有被错误改变：

- L5 最大坐标差约 `1.64e-7 mm`；
- B7 最大坐标差约 `2.05e-12 mm`。

变化仅发生在语义分层、栓钉显示和验证机制。
