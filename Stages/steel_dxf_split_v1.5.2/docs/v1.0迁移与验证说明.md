# v1.0 迁移与验证说明

## 迁移目标

v0.9 已经在 20 组人工监督数据上验证制造几何。v1.0 的目标是提升信息组织、可解释推理、候选恢复能力和质量门，而不是重新改动已验证的几何后端。

## 保持不变的生产链

以下文件与 v0.9 SHA-256 一致：

- `bh_geometry.py`
- `bh_writer.py`
- `bh_compare.py`
- `bh_models.py`
- `bh_validator.py`

`bh_extractor.py` 只增加来源实体数量、句柄和实体类型，不修改轮廓和切割特征计算。

## 视图选择稳定性

v0.9 的 20 组报告中：

- 最小视图对分差大于 1.08；
- v1 新增的实体复杂度弱惩罚上界小于 0.04；
- 候选前沿窗口为 0.45。

因此全部语料仍只有原先选中的视图对进入完整制造降级，几何后端输入不变。

## 输出等价

包内 20 份生产 DXF 与 v0.9 已验证输出逐文件 SHA-256 相同。v0.9 的完整运行验证包括：

- 20/20 人工监督通过；
- 73/73 自动化测试通过；
- DXF audit errors 全部为 0；
- `LINE/XLINE/RAY` 全部为 0；
- 最大人工轮廓差 0.140693 mm。

## v1 新增验证

- Python 3.12 语法解析；
- 语义核心独立单元测试；
- 样本名称不得进入算法源码；
- 知识库和权重显式化；
- 完整构件假设和规则报告；
- 语义图；
- 自动接受/复核/拒绝质量门；
- 后端源码等价和输出哈希等价审计。

详细机器可读报告：`output/v0.9_to_v1.0_semantic_migration_audit.json`。
