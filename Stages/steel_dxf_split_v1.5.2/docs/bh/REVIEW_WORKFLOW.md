# 人工复核流程

`manual_review` 表示任务没有满足自动生产发布条件。它可能来自领域核心证据不足、余量处理失败、双文件审计失败或孔洞几何/颜色不一致。

## 复核顺序

1. 打开 `<任务名>_report.json`，查看 `paired_output.failure_stage`、`error_type`、`error` 和领域诊断码。
2. 确认同名任务不在 `auto_accepted` 中；若同时存在，视为发布事务异常，不得使用任何一份结果。
3. 若有 `*_normal_candidate.dxf`，它只用于诊断，不是可制造文件。
4. BH/BOX 领域识别或几何证据不足时，回到对应的来源契约与权威前后样例分析，不得手工改写报告为通过。
5. 修复输入或程序后，从原输入目录重新运行统一命令；不要把复核目录作为输入。

## 孔洞颜色复核

- 对唯一横向镜像圆孔对，左孔必须为显式 ACI 1，右孔必须为显式 ACI 7；
- 中线、无配对或歧义孔必须保持 ACI 7；
- 非圆形内孔必须保持 ACI 7；
- 普通版与余量版的全部 `CUT_HOLE` 几何和颜色必须逐项一致。

不能仅靠图层外观判断颜色，应读取实体显式 ACI 值。

## 余量复核

逐板检查余量报告中的：

- `before_main_length_mm`；
- `allowance_mm`；
- `after_main_length_mm`；
- `after = before + allowance` 是否闭合；
- 孔洞、标签、实体数量和图层数量是否保持不变。

规则允许短板余量为 `0 mm`。只有当该板的长度区间确实规定为零时才可接受；不得为了“看见伸长”而强行修改规则。

## 证据边界

BOX 几何冲突必须比较只读的 20 对前后 DXF 权威样例。人工参考只用于离线判断，不能在生产运行时影响候选选择、证明或路由。
