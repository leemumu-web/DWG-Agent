# steel-dxf-split v1.5.2

v1.5.2 正式发布 Tekla 新旧 DWG/DXF 表示的方言语义修复。本补丁不改变 BH 几何语义
中的板件、斜边、孔、展开授权和焊接余量规则，只让经过证据确认的等价源表示进入同一
SourceIR、候选搜索、ManufacturingIR 和保存后验证链。

## 根因与语义修复

- 旧导出用 `Part/XKITLINE04` 表示隐藏投影边，部分 AutoCAD 2018/AC1032
  DWG→DXF 转换改用 `Part/DOT2`。旧编译器把 `DOT2` 当作物理边，隐藏线参与 noding
  后把完整腹板和翼缘面切成大量碎面。
- `BHDialectProfile` 现在统一负责角色到可见性的分类，并把新旧线型降低为同一个
  `VisibilityClass.HIDDEN`。SourceIR 保留原始图层、线型和来源 ID；`PartBlock` 与
  runtime instance 共用规范化 seam，几何内核不再认识导出器线型名字。
- 新版导出把尺寸文字/点保留在 `Z-DIMENSIONS`，把尺寸线拆到
  `Z-DIMENSIONS-LINES`。二者现在共享尺寸角色；未映射的相似图层仍为 UNKNOWN，
  继续由候选宇宙关键证明失败关闭。

规则没有构件号、文件名、绝对坐标、固定长度或孔数分支。`Continuous` 和
`XKITLINE00` 仍为物理边，未验证的 `HIDDEN2` 不会被猜测性排除，
`Z-DIMENSIONLESS-GEOMETRY` 也不会被误当尺寸层。

## 版本与兼容合同

- 编译器版本升级为 `1.5.2`；制造 IR、报告和 manifest schema 保持
  `BH-MANUFACTURING-IR-1.1`、`BH-COMPILATION-REPORT-1.4`、
  `BH-BATCH-MANIFEST-1.4`、`BH-WELD-ALLOWANCE-MANIFEST-1.0`。
- 生产 DXF 继续使用 R2007 毫米、闭合 `LWPOLYLINE`/`CIRCLE`、ASCII
  `\U+XXXX` 中文传输和 Windows `simsun.ttc`，不恢复 ACIS REGION/SAT。
- 余量仍只平移正向端部链；孔、内切、标签和负向端不移动，斜端方向和 bulge 不变。
