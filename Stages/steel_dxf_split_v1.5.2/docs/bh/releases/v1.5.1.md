# steel-dxf-split v1.5.1

v1.5.1 重发以 Windows CAD 原生闭合曲线传输为基础，并补全 Tekla 新旧 DWG/DXF
表示之间的隐藏投影线与尺寸层方言。制造轮廓、孔、证明处置和焊接余量规则不变；
变化集中在 SourceIR 到几何 lowering 之间的语义规范化边界。
本补丁不改变 BH 几何语义中的板件、斜边、孔和展开授权规则，只让等价的源表示进入
同一既有语义。

## 2026-07-21 方言语义补丁

- 旧导出的 `Part/XKITLINE04` 与 AC1032 转换后的 `Part/DOT2` 被定义为同一个
  `hidden projection` 角色。原始拼写和来源 ID 保留在 SourceIR，轮廓视图与运行时
  实例在进入几何内核前统一规范化，隐藏线不再切碎连续实体边形成的闭合板面。
- `Z-DIMENSIONS-LINES` 与 `Z-DIMENSIONS` 共同归入尺寸角色；其他未知层仍失败关闭，
  候选宇宙完整性证明没有放宽。
- 新增 11 张 Tekla→DWG→DXF BH 图均为 `auto_accept`，保存后原生闭合曲线 DXF
  11/11 可重新读取、审计 0 错误、15 项 writer/MIR 闭包全通过；冻结 20 图逐板尺寸、
  板厚、孔/开口及 18/2/0 路由保持不变。
- release evidence 的方言指纹新增隐藏投影线型集合；固定能力产物重新绑定为
  `8220e245bf0da86a0e6a66cfaf5fbeb71a27134f31b70f36bc3a184ea8c4c48c`。

## 兼容性结论

- Tekla 单构件 BH profile、八阶段编译链和 `18 auto_accept / 2 review_required /
  0 rejected` 的 20 图可信基线不变；
- 微斜边、斜端、MIF/旧 cp936 孔标、中文显示文本、Windows `simsun.ttc` 标签和
  保存后证明不变；生产制造轮廓改为原生闭合 `LWPOLYLINE`/`CIRCLE`，不再交付
  ACIS REGION/SAT；
- 焊接余量仍只平移正向端部链，孔、内切、标签、端部方向与直接拆板结果不动；
- schema 保持 `BH-COMPILATION-REPORT-1.4`、`BH-BATCH-MANIFEST-1.4` 和
  `BH-WELD-ALLOWANCE-MANIFEST-1.0`，消费者只需把编译器版本校验更新为 `1.5.1`。

## 代码与资源生命周期

生产包 58 个模块均确认具有入口或调用方，`vulture src scripts --min-confidence 80`
没有高置信度生产候选。唯一确认的僵尸代码是一处无用途测试常量导入，已删除；动态
CLI、兼容层、诊断与发布验证模块均保留。

Pillow 预览测试改为上下文管理图片文件，消除 `ResourceWarning`。BH pipeline 的大型
ezdxf 文档仍在不再需要时主动释放，但控制流改成静态分析可证明的赋空形式。Ruff
进入锁定开发依赖，完整 pytest 以 warning-as-error 运行。

新增统一健康入口：

```bash
uv run python scripts/check_repository_health.py
```

它依次执行锁文件、依赖闭包、当前解释器强制 `compileall -f`、Ruff、
`pytest -W error` 和 `git diff --check`，首项失败即返回原状态码。

## 原子工件与批次可观测性

共享 JSON 工件写入器在目标目录创建临时文件，使用 UTF-8、拒绝 NaN，刷新并
`fsync` 后通过 `os.replace()` 提升。直接拆板和余量 manifest 每项结束后均使用该
路径 checkpoint，再同步父目录固定目录项；序列化失败会清理临时文件并保留旧 manifest。

余量批次 stderr 现在输出逐项开始、完成/失败类型、板数和耗时，stdout 只输出最终
manifest JSON。每项增加 `duration_seconds`，根级增加 `batch_wall_seconds`。只把
已知余量处理错误和 I/O 错误记为单项失败，编程错误继续显式失败。

推荐 `weld_allowance/run_projects.sh` 增加固定路径、参数/依赖/输入预检、非阻塞
`flock`、共享 `--check-inputs-only` 完整 pair 校验和受控清理：只有环境 frozen 同步、
DXF/报告层级、非符号链接与身份唯一性全部成功后才清空固定
`weld_allowance/results/`；`project_results/` 及其 PNG 永远不在清理范围内。脚本运行
摘要进入 stderr，stdout 只保留一个最终 manifest JSON。
