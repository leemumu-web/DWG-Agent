# BH 十四组监督回归与多板特征算法

## 1. 目标

人工拆板后 DXF 是监督标签，不参与自动结果生成。算法只从拆板前图纸中的材料表、`Part`、`Bolt`、投影视图和几何拓扑重建板件，再与人工结果进行独立比较。

## 2. 总体流水线

```text
读取和审计 DXF
→ 展开匿名 INSERT
→ 解析 BH 截面、长度、材质和零件号
→ 识别腹板主视图与翼缘投影视图
→ Part LINE/ARC 节点化和 polygonize
→ 腹板候选选择与边界补全
→ 翼缘种子、端部扩展与重叠投影共识
→ 每块板独立分配圆孔/内开口
→ 恢复 ARC bulge
→ 局部坐标归一化与排布
→ 写出清洁 DXF
→ 逐板人工监督比较
→ DXF 审计与辅助线检查
```

## 3. 腹板重建

### 3.1 主体面选择

按名义长度和截面高度筛选大面。有圆孔时优先选择单独覆盖全部腹板孔的面；无圆孔时选择面积最大的可信面。

### 3.2 纵向端部扩展

相邻面只有满足以下条件才并入：

1. 延长当前纵向最小端或最大端；
2. 与当前横向区间具有足够重合；
3. 拓扑上相接；
4. 合并后横向尺寸不异常增加；
5. 合并结果保持单一有效 Polygon。

### 3.3 隐藏线桥接

隐藏线只用于构造小型外边桥接面。桥接面必须近矩形、位于横向外边、与主体接触且不改变包围盒。内部隐藏线和孔中心线不参与。

## 4. 翼缘重建

### 4.1 种子面

从翼缘视图中选择横向尺寸接近 `B` 的闭合面，得到一到两个全宽种子。

### 4.2 端部分离面

对每个种子执行纵向端部扩展，解决端板投影将真实轮廓切成多个面的情况。

### 4.3 重叠投影共识

连接面合并不是无条件执行。只有两个独立种子在端部扩展后收敛到几乎同一外包络，才允许继续合并连接面。这样：

- `3b2-cb-86` 的重叠投影可以恢复完整长翼缘；
- `2b1-cb-18` 的两块真实独立翼缘不会被吸收成一块超长板；
- `2b1-cb-26` 的短翼缘不会错误扩展成腹板长度。

### 4.4 第二翼缘保留

若原种子面积足够大，且与主包络的对称差显著，则保留为第二块不同翼缘；小碎片和投影交叠残面被过滤。

## 5. 孔和内开口归属

### 5.1 圆孔来源

只有 `Bolt/CIRCLE` 进入切割特征。`Bolt/LINE`、`XLINE`、`RAY` 永不写入结果。

### 5.2 视图分区

圆孔先按腹板主视图和翼缘投影视图的空间包围盒分区，再检查孔心是否被对应板件多边形包含。

### 5.3 重叠翼缘消歧

若一个圆孔同时落在两个重叠翼缘候选内，则读取主视图中仅由 `Bolt/LINE` 表达的边视孔符号：

1. 判断符号位于腹板中心线的哪一侧；
2. 从主视图窄长翼缘面得到该侧的实际长度；
3. 将孔分配给长度最接近的翼缘板。

线符号只充当语义证据，不成为输出实体。

## 6. 圆弧和资源管理

外轮廓和异形内开口通过源 `ARC` 端点、圆心、半径和方向恢复为 LWPOLYLINE bulge。

监督比较与验证阶段直接数学展开 bulge，不再为每个轮廓创建临时 ezdxf `Drawing`，降低大批量回归的循环对象和峰值内存。测试矩阵按模块进程隔离，确保 Windows/Linux 批处理稳定退出。

## 7. 监督指标

逐块比较：

- 几何数量；
- 外轮廓 Hausdorff 距离；
- 包围盒与面积；
- 圆孔数量、中心和半径；
- 异形内开口；
- 切割特征所属板件。

默认限制：

```text
轮廓/尺寸误差 ≤ 0.15 mm
孔心/孔径误差 ≤ 0.15 mm
面积相对误差 ≤ 0.035%
```

## 8. 安全失败

以下情况停止输出：

- 截面或名义长度无法解析；
- 主视图和翼缘视图无法可靠区分；
- 孔位不属于任何候选板；
- 重叠翼缘孔无法消歧；
- 板件物理数量不是一腹板加两翼缘；
- 圆孔越界或半径大于边界净距；
- 人工监督超差；
- 输出含 `LINE/XLINE/RAY`；
- DXF 审计失败。
