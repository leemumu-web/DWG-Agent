# BH 左右进读取器

版本：`1.2.7`

这是一个使用 **uv + Python 3.12** 管理的 DXF 几何读取程序，用于从 BH 构件图中读取腹板和翼板的水平左进、右进。

## 固定三步流程

1. **定位主视图**：找到纵向主视图，并取得全局水平 `X_left`、`X_right`。
2. **识别实体板件**：识别腹板、上翼板、下翼板；翼板可为一块或多块。
3. **逐板读取左右进**：只读取水平 X 差值，统一输出毫米。

```text
左进 = 板件最左 X - 主视图最左 X
右进 = 主视图最右 X - 板件最右 X
```

程序不旋转构件，不沿斜边测距。坡口和斜切端使用实体轮廓中最靠外的水平 X 点。

圆弧轮廓会保留弧段扫过的 0°、90°、180°、270°极值点；若位于等比旋转块中，还会保留变换后全局 X/Y 的极值点，不以固定角度采样的近似点替代物理最外包络。非等比块变换会把圆弧转为当前未支持的椭圆，程序拒绝输出而不以不完整几何猜测左右进。

## 工程语义

### 翼板

一块翼板由“完整翼厚材料沿 X 连续存在”确定：

- 内部竖线、焊缝线、腹板投影、加劲板边线不会把翼板分成两块；
- 只有翼板材料在构件中部真实断开，才形成多个实体板件；
- 上、下翼每一对应分段的左右边界、首尾高差及完整纵向轮廓都在容差内一致时，合并为 `翼-1`、`翼-2` 等；完整轮廓以去除首尾直线趋势后的多点残差比较，避免把“端点相同但中段折弯不同”的板件合并；任一对应分段不同则分别输出 `上翼-*`、`下翼-*`；
- 分板仍由完整翼厚材料的连续区间、实体封口和共享线外侧材料检查决定。分出每块实体板后，左右边界直接读取该板端部原始轮廓的 bounding box `minX/maxX`；倒角、圆弧和斜封口的尖端不得被“第一个完整翼厚截面”截短。中间多段板仍先用实体封口切分，不会把跨过缺口的共享轮廓线算入相邻板；
- 多翼板不再跳过。

### 腹板

腹板端点必须来自横向切断边：

- 端边需跨越足够的腹板净高；
- 端边应为竖直或较陡斜边；
- 变截面 BH 的长斜翼缘边即使穿过腹板核心区，也不能作为腹板端点。
- 腹板端边通过净高和陡度检查确认归属后，左右边界取该原始边实体完整 bounding box 的 `minX/maxX`；不能先裁到“腹板核心区”再计算，否则斜端会被系统性截短。
- 腹板端边仍须位于构件端部窗口内。只有一条远离端部、跨越腹板净高的竖线时，几何无法区分它是腹板端边还是内部加劲线；程序不会把它外推成大进尺，而是保守按齐平处理，需人工实体语义或真值补充。

`2b1-cb-40` 的错误即由这一规则修复：腹板右端位于构件右端之前，原始右进约 `235.076 mm`，安全输出 `235 mm`。

## 单位与比例

- `$INSUNITS` 决定 DXF 模型空间坐标单位；
- 标题栏 `1:10`、`1:20` 等只是出图显示比例，不参与坐标换算；
- `$INSUNITS`、BH 截面尺寸、标题栏名义长度共同校验单位；
- 单位无法验证时停止输出；
- 最终结果统一为 `mm`。

## 安全取整

为避免下料偏短，最终左右进严格向下取整：

```text
13.999999 -> 13
235.075758 -> 235
14.000000 -> 14
```

```bash
uv python install 3.12

```

```text
.python-version = 3.12

```

## 运行

```bash
uv run bh-reader /path/to/dxf_directory \
  --config config/default.toml \
  --output outputs/BH左右进结果.xlsx \
  --json outputs/BH左右进诊断.json \
  --visual-dir outputs/校验图
```

支持多个文件或通配符：

```bash
uv run bh-reader a.dxf b.dxf "drawings/*.dxf" -o outputs/results.xlsx
```

输入输出流使用专用目录隔离：目录输入只扫描 `.dxf/.DXF`，重复解析路径只处理一次；生成物不得与原始 DXF 同层混放，可位于专用输出子目录。读图前拒绝重名源文件、路径或硬链接覆盖、生成物相互包含；请求图片时任一图失败都返回失败码。

`auto` 后端优先使用 ezdxf，失败时回退到内置 ASCII DXF 解析器。两条路径均支持 `LINE`、`LWPOLYLINE` 和旧式 `POLYLINE` 轮廓；后者由 ASCII 回退路径完整重建 `VERTEX ... SEQEND` 顶点序列。两类多段线的 group-code `42` bulge 会按有向圆弧展开，并精确保留扫过的水平极值，不能退化成端点直弦而把圆弧端帽误读为左右进。非法、非有限或绝对值过大的 bulge、非等比变换后的椭圆源几何、材料层的未支持实体及非默认 OCS 均会停止输出并给出 `ERROR_DXF_PARSE_INCOMPLETE`；标题栏等非材料层的未支持图元不会阻断有效 BH。

## 输出命名

```text
零件号+腹
零件号+翼                  # 上下翼相同
零件号+上翼 / 零件号+下翼  # 上下翼不同
零件号+上翼-1 / 上翼-2     # 多块翼板
零件号+下翼-1 / 下翼-2
```

## 当前回归

对三批给定的 199 张 DXF（20 + 67 + 112）进行正式回归：

- ezdxf、ASCII 两条入口均为 199/199 `OK`；状态、板件角色、原始左右进、安全左右进和置信度逐项一致；
- 共输出 420 条板件结果，199/199 单位验证为毫米；修正后边界与形状一致的上下翼按既有规则合并去重；
- 非有限数值：0 次，缺失板件证据：0 次。唯一授权例外是 `5t1-cb-50` 的 `141.9999999999991 mm` 按理论整值吸附为 142 mm；
- 80 项自动测试通过，其中覆盖全部 199 张真实图和双后端全交付字段一致性；另有 432 个确定性有效 BH 组合（含 32 组斜腹板），以及局部翼板内表面裁剪、零散线归属、块变换、OCS、畸形 DXF 和输入输出失败关闭回归；
- 最终 199 张图全部重新生成，并生成 50 张汇总图。图片仅保留主视图、左右进标注、单位校验和 legend；Excel 同时保留每张校验图路径。`3t1-cb-4` 中曾被误高亮的腹板斜线和零散短线已不再归入翼板轮廓。
